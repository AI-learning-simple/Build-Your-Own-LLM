# 8. AI × 零售与消费：从购物助手到商业 Agent

零售可能是普通人最容易直接感受到 AI 变化的行业之一。

因为我们每天都在做大量消费决策：

```text
买什么？
在哪里买？
什么时候买？
买多少？
哪个更划算？
```

传统互联网已经解决了一部分问题。

搜索引擎帮助我们：

> 找商品。

电商平台帮助我们：

> 看商品、比价格、下订单。

推荐算法帮助我们：

> 猜测我们可能喜欢什么。

而 Agent 出现之后，整个模式可能发生进一步变化：

> **消费者不再自己搜索商品，而是把消费目标交给 Agent。**

---

# 7.1 从“搜索商品”到“表达目标”

传统电商的交互方式是：

```text
用户
 ↓
搜索关键词
 ↓
商品列表
 ↓
筛选
 ↓
比较
 ↓
购买
```

例如用户搜索：

> “跑鞋。”

系统返回几千个商品。

用户还需要继续：

```text
价格筛选
品牌筛选
尺寸筛选
评价筛选
功能筛选
```

这意味着：

> 很多决策工作仍然由用户完成。

---

```text

+

+
```

然后执行：


```text

原因：……
```

这比传统搜索更接近：

# 8.5 为什么推荐算法还不等于 Shopping Agent

推荐算法通常回答：

> “你可能喜欢这个。”

它依赖：

```text
历史行为
+
用户画像
+
商品特征
```

而 Shopping Agent 更进一步：

> “为了完成你的目标，我应该帮你找到什么？”

例如：

```text
推荐系统：
“你可能喜欢这款咖啡机。”

Shopping Agent：
“根据你每天两杯咖啡、办公室空间有限、预算 300 美元，我建议购买这台。它体积更小，而且维护成本较低。”
```

前者是：

> Prediction。

后者是：

> **Reasoning + Planning + Action。**

# 8.38 行业实践：Rufus、Operator 与意图经济的开端

“页面经济走向意图经济”听起来像预言，但它已经开始发生。

第一个数字来自 Amazon 的 Rufus。这个 2024 年上线的购物 Agent 到 2025 年交出的成绩是：

```text
约 120 亿美元的年化增量销售
使用 Rufus 的会话，购买完成率提升约 60%
```

到 2026 年，Amazon 进一步把购物助手整合进 Alexa（Alexa for Shopping），支持自动比价、降价提醒和跨平台购买——购物入口正在从搜索框迁移到对话。

第二个信号来自模型厂商。OpenAI 在 2025 年初发布 Operator，Agent 可以代替用户浏览电商网站、加购物车、完成下单；随后 ChatGPT 接入 Instant Checkout。这背后是新的支付与结算协议（ACP，由 OpenAI、Stripe 等推动）——正如当年 HTTPS 与 PayPal 催生了电商，Agent 商务需要自己的协议层。

为什么传统电商软件做不到？

因为传统电商的一切优化都发生在“页面”上：

```text
搜索排序 → 商品详情页 → 加购 → 结算
```

每一步都在等用户点击。而 Agent 购物把决策链路压缩成：

```text
用户表达意图 → Agent 比较、谈判、下单
```

页面不再被“看”，而是被“调用”。这对零售业是根本性的渠道迁移。

受影响的人群：

* 消费者：从“逛”变成“委托”，购物时间下降但被推荐的权力让渡给 Agent；
* 卖家与品牌：SEO 时代让位给 AEO（Agent Engine Optimization），商品信息必须对机器可读、可信赖；
* 导购与客服：商品咨询类岗位最先被压缩；
* 平台：从流量分发者变成 Agent 的能力提供方。

零售的启示：当购买决策由 Agent 代理，零售竞争的单位从“页面转化率”变成“Agent 对你的信任度”。
