# 13. AI × 医疗与健康：从医疗 Copilot 到 Healthcare Agent Network

> **研究更新日：2026-11-25。** 本章讨论产品与研究证据，不提供诊疗建议。文书生成、临床决策支持和自主诊疗不是同一种能力，也不能共享同一套安全结论。

## 13.1 为什么文书成为重要入口

医生、护士需要将诊疗活动转成结构化记录，衔接检查、随访、编码和收费。大量时间花在查资料、整理对话和重复录入，而非直接面对患者。

Ambient AI scribe 等产品尝试将医患交流整理成记录草稿。这种任务有明确使用者和工作流入口，但“只是写病历”并不意味着风险很低：错误记录可能影响后续判断、用药信息、交接、编码和收费。

## 13.2 2026 年产品进展：Dragon Copilot 扩展到更多角色

Microsoft 于 **2026-03-05** 的 HIMSS 公告介绍 Dragon Copilot 的护理和放射科场景。[1]

| 场景 | 公告时的能力 | 公告时的可用状态 |
|---|---|---|
| 护理 | 床旁对话转结构化记录、摘要、信息检索 | 美国已提供 |
| 放射科 | 配合 PowerScribe One，辅助既往报告回顾与报告流程 | 美国预览阶段 |

这些是发布时的状态，不能直接当作 2026-11-25 在所有地区的可用范围。本文采用 Dragon Copilot 这一产品名称，但下述历史试验测试的是当时的 DAX，不能把两个版本等同。

该进展说明产品正从单一文书助手扩展到角色化工作流，不证明临床决策可以无监督执行。

## 13.3 研究证据：效果应按产品和指标区分

UCLA 的研究新闻稿于 **2025-11-26** 发布，介绍《NEJM AI》的随机试验：**238 名医生、14 个专科、约 72,000 次就诊**，比较 Nabla、Microsoft DAX 与常规记录。[2][3]

本次期刊和 UCLA 页面访问受限，数据实际核验自 UCLA 经 Newswise 发布的研究新闻稿，未直接复核论文全文统计细节。

| 指标 | 可读研究新闻稿的结果 | 限制 |
|---|---|---|
| Nabla 文书时间 | 每份从 4 分 30 秒降至 3 分 49 秒 | 组内减少 41 秒，不全是净干预效果 |
| 对照组文书时间 | 从 4 分 22 秒降至 4 分 04 秒 | 同期也减少 18 秒 |
| Nabla 相对对照 | 记录时间约减少 9.5%，有统计学显著性 | 不能与组内绝对节时混为同一估计 |
| DAX 相对对照 | 时间改善未达统计学显著性 | 不等于所有 DAX 或后续产品永远无效 |
| 安全 | 偶有临床意义错误，报告 1 起轻度患者安全事件 | 仍需医生主动审核与修改 |

研究开展于单一医疗中心的较短时期，不能直接证明长期安全或所有专科收益。职业体验改善、文书时间减少和临床结果改善，也应分别判断。

## 13.4 医疗 AI 市场不能只按融资排序

融资额、估值、部署机构数、实际使用医生数和付费留存，是不同的指标。产品签下一家医疗系统，也不意味着该系统所有医生都在稳定使用。

本次不沿用缺少统一统计边界的“文书赛道融资近 10 亿美元”，也不把个别融资轮次写成临床验证。选型更需要比较：

- 支持的语言、专科和就诊方式；
- EHR 集成方式及写回权限；
- 患者知情与拒绝机制；
- 音频和文本的保存、删除与访问控制；
- 编辑负担、遗漏与错误，以及具体产品版本。

## 13.5 可靠医疗 Copilot 的闭环

建议将工作流设计为：明确使用范围与授权 → 采集最小必要信息 → 生成有标记的草稿 → 对原始记录与关键字段核查 → 责任人员确认 → 写回系统 → 持续抽检。

重点不是让系统给每句话一个未经校准的“置信度”，而是确保重要信息可以追溯，遗漏可以发现，医护可以有效修改。

对药物、剂量、否定表达、时间、对象与过敏信息，应设计专门校验。没有听到的信息不能按常识补全；模糊之处应保留不确定性而不是生成确定记录。

## 13.6 Healthcare Agent Network 的边界

预约、文书、检查状态和随访任务可以由不同服务协作，但一个环节的工具调用成功，不表示临床任务完成。

跨服务需要患者身份匹配、最小权限、来源和版本管理，以及中断恢复。更不能因为“另一 Agent 已审核”就取消责任医护的必要判断。

本章把医疗 Agent Network 视为工作流整合方向，而不是已经验证的无人医疗模式。直接影响诊疗的能力需要独立、适用场景明确的临床评价。

## 13.7 商业价值与下一步观察

买方包括医院、诊所和医疗软件平台。应核算每次就诊的文书总时间、下班后记录负担、编辑率、错误、患者拒绝率、持续使用和集成运维成本。

**本章判断：**文书和行政协作提供了相对清晰的入口，但要避免“低风险文书”叙事掩盖下游影响。比更高生成速度更重要的，是新版本是否在真实工作流中持续减少负担，同时不增加临床风险。

> 医疗 AI 的价值不在于让病历写得更像人，而在于帮助专业人员更可靠地记录、理解和完成诊疗相关工作。
