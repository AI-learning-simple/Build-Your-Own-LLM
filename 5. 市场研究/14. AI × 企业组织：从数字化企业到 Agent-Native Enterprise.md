# 14. AI × 企业组织：从数字化企业到 Agent-Native Enterprise

> **研究更新日：2026-11-25。** “Agent-Native Enterprise”在本章指围绕可授权、可执行、可验收任务设计流程的方向，不是已经统一定义的企业类别。

## 14.1 从组织使用 AI，到流程真正改变

企业买了助手，并不意味着组织结构已经改变。员工可能更快地写出邮件，但审批等待、数据冲突和跨部门交接仍然存在。

Stanford HAI《2026 AI Index》汇总：2025 年 88% 的受访组织使用 AI，70% 至少在一个职能使用生成式 AI；按职能观察的 Agent 部署率仍普遍较低。[1] 这些是调查采用口径，不能当作企业总体普查或盈利比例。

因此，研究单位应从“企业装没装 AI”进一步转向“哪些任务已经改变，改变后有什么结果”。

## 14.2 商业化已出现，但数字不能混用

### Salesforce：必须标记 ARR 口径变化

Salesforce 于 **2026-08-26** 披露截至 2026-07-31 的 FY2027 Q2 结果：[2]

| 指标 | 披露值 | 注意事项 |
|---|---|---|
| Agentforce ARR | 超过 15 亿美元，同比增长超 240% | 本季起纳入 AI 产品、Slackbot 和 Headless 360 |
| Agentforce 与 Data 360 合并 ARR | 接近 39 亿美元，同比增长超 210% | 已含 Agentforce，不可再相加 |
| Agentforce 与 Slack 当季工作单元 | 32 亿 AWU，环比增长 97% | 供应商定义的用量，不是完成业务结果数 |

当季口径扩展意味着不能机械地将当前数字与旧版 Agentforce 指标组成同口径增长曲线。ARR 是年化指标，也不是当季已确认收入。本页未披露独立付费客户总数，不应由合同数或账户数补造。

### Microsoft：使用增长不等于席位数字

Microsoft 在 **2026-10-28** 的 FY2027 Q1 电话会中披露 Copilot 日用户环比增长近 50%、同比超过 5 倍；Agent 365 注册 Agent 超过 5,000 万，环比增长超过 30%。[3]

这次电话会未更新 Microsoft 365 Copilot 的独立付费席位总数。注册 Agent 不是活跃 Agent、付费用户或员工替代数。因此，本章不再采用无法由这次披露支持的“7,000 万付费席位”“16 万组织生产部署”。

## 14.3 企业改变的是任务分配，不是给软件发工牌

可以把任务划分为：

- **规则明确、输入稳定**：优先传统自动化或确定性工作流。
- **材料复杂、输出可复核**：适合 Copilot。
- **需要根据反馈选工具、风险可控**：可以试验有界 Agent。
- **高后果、难评价或信息不充分**：保留专业人员主导。

多 Agent 不是默认终点。每增加一个执行主体，都增加状态同步、权限、成本和失败传播问题。只有职责确实独立或存在有效并行空间时，拆分才可能有收益。

## 14.4 从流程出发的目标架构

建议将企业能力分为五层：

1. **业务事实**：客户、订单、合同、资产等权威记录。
2. **能力接口**：带输入校验、权限和回执的操作。
3. **任务运行**：状态、检查点、超时、重试和取消。
4. **组织控制**：预算、审批、责任人和异常升级。
5. **评测与经营**：质量、成本、时效、客户影响和版本比较。

Agent 是其中的决策与协调组件，而不是绕过既有业务系统的超级账号。各层可以由已有软件提供，不需要为了“Agent-Native”从零建设一个操作系统。

## 14.5 购买还是自建

| 选择 | 较适合的情况 | 主要风险 |
|---|---|---|
| 使用既有平台内置 AI | 核心流程已经在该平台 | 功能边界、组合收费、供应商锁定 |
| 采购垂直产品 | 特定行业任务有成熟交付 | 集成、数据边界、厂商持续性 |
| 自建有界工作流 | 任务差异明显、掌握数据与工程能力 | 运维、评测、持续升级成本 |
| 混合方案 | 复用平台、保留关键控制 | 多方责任与接口兼容 |

不要将 Token 单价当作完整报价。软件席位、用量、实施、数据整理、人工复核和失败处理都可能成为主要成本；具体价格要按地区、产品版本与合同核验。

## 14.6 如何衡量组织回报

建议分阶段测量：先看员工任务，再看端到端流程，最后看财务与客户结果。

- 员工层：总工时、复核、返工，而非自报“感觉更快”。
- 流程层：从请求到完成的时长、一次成功、异常积压。
- 经营层：净毛利、可兑现成本、留存和服务质量。
- 控制层：越权、重复执行、缺失审计和数据泄露事件。

任务效率提高未必减少人员成本，也可能释放容量用于增长。如果流程的瓶颈在审批或系统接入，文本生成再快也未必改变交付时间。

## 14.7 条件性结论

**本章判断：**已有商业披露支持企业 AI 产品需求增长，但不足以证明企业会普遍变成无人组织。真正的进展，是任务、权限、状态与责任越来越清楚，而不是公司拥有越来越多名义上的 Agent。

下一步应追踪同口径收入、真实生产活跃、续约扩展、单位完成成本，以及从试点复制到第二个团队时增加多少工作。

> Agent-Native 的核心不是“组织里没有人”，而是人和软件各自承担适合的职责，并能对完成结果负责。
