# 16. AI × 商业网络：从企业协作到智能体间经济（Agent-to-Agent Economy）

上一章我们讨论了：

> **人 + Agent + Robot 如何组成新的劳动力体系。**

如果 Agent 不再只是企业内部的数字员工，而开始能够：

```text
发现服务
寻找供应商
比较方案
发起交易
进行谈判
签订合同
完成支付
```

那么一个更大的变化就出现了：

> **Agent 开始进入市场。**

这意味着商业活动的基本参与者，可能从：

```text
Human ↔ Company
```

逐渐增加：

```text
Human
Company
Agent
Robot
        ↕
Market
```

最终形成：

> **Agent-to-Agent Economy。**

# 16.100 行业实践：A2A 协议与 Agent 经济的地基

本章推演的“Agent 互相发现、谈判、交易”，其协议地基在 2025 年已经打下。

最重要的事件：2025 年 4 月，Google 联合五十多家企业（Salesforce、SAP、ServiceNow、Atlassian 等）发布了 A2A（Agent-to-Agent）开放协议，并随后移交开放治理。它解决的是本章的核心问题——不同厂商、不同框架构建的 Agent 如何互操作：

```text
Agent Card：Agent 的自我描述
（我是谁、我能做什么、如何认证我）

任务协商：Agent 之间派发与接受任务

消息与工件：多轮交换结构与产出物
```

与此同时，商业交易层也有了协议：ACP（Agentic Commerce Protocol）由 OpenAI 与 Stripe 等推动，让购物 Agent 能替用户完成支付；零售侧的 UCP 则由 Amazon 等推动。加上连接工具的 MCP（详见下一章），Agent 经济的三层协议栈在 2025 年成型：

```text
交易层：ACP / UCP（Agent 如何付钱）
协作层：A2A（Agent 如何找到彼此、协作）
工具层：MCP（Agent 如何使用工具与数据）
```

为什么这件事重要？回看互联网历史：

```text
TCP/IP → 让网络互联成为可能
HTTP → 让 Web 成为可能
支付协议 → 让电商成为可能
```

每一代经济形态都建立在协议层之上。A2A 之于 Agent 经济，正如 HTTP 之于 Web——它不保证经济会发生，但它把“发生”的成本降了一个数量级。

受影响的人群：

* 企业 IT 与集成商：点对点 API 集成的工作被协议化标准化，集成商要么上移到 Agent 编排，要么被淘汰；
* SaaS 公司：产品需要暴露 Agent Card 与能力接口，否则会被绕过；
* 开发者：多 Agent 系统开发第一次有了类似“Web 开发”的标准栈；
* 反欺诈与安全团队：Agent 冒充、任务欺诈成为新的攻防前线。

商业网络的启示：协议的出现意味着这个领域从“概念讨论期”进入“基础设施建设期”——历史上所有基础设施期，都是先行者的窗口期。
