# 16. AI × 商业网络：从企业协作到 Agent-to-Agent Economy

> **研究更新日：2026-11-25。** 本章研究跨企业任务与交易协作。Agent 可以代表被授权的人或组织执行操作，但协议连接不会使它自动成为独立商业责任主体。

## 16.1 企业之间本来就有机器协作

API、电子订单、供应链系统和自动支付早已支持机器间协作。新变化主要是：大模型可以理解更复杂的请求，并在一定范围内选择工具、处理非结构化材料和协调任务。

因此，不能把“过去互联网只有人操作，现在才有机器协作”作为起点。真正需要验证的是：Agent 能否降低既有跨企业流程的集成与异常处理成本，而不是仅仅换一种调用形式。

## 16.2 截至 2026 年的协议事实

| 协议 | 本次可核验定位 | 主要对象 | 不负责的事情 |
|---|---|---|---|
| MCP | 工具、资源等能力接入，定位见第 18 章；本次授权页标注 2026-07-28 版本[4] | Agent 应用与工具服务 | 交易合同与业务授权的全部规则 |
| A2A | 本次规范页标注最新发布版 1.0.0 | 独立 Agent 系统之间的任务、消息和产物 | 自动建立商业信用或资金结算 |
| ACP | OpenAI 于 2025-09-29 公告，与 Stripe 及伙伴共同开发 | Agent 与商家交易流程 | 全球商家自动接入 |
| UCP | Google Developers 于 2026-01-11 介绍 | 商务能力、结账与订单相关语义 | 替代所有工具和身份协议 |

UCP 的共同开发者包括 Google、Shopify、Etsy、Wayfair、Target 和 Walmart。[1] 不应写成 Amazon 主导，也不能称这些商务协议已于 2025 年构成统一、完整的三层标准栈。

ACP 在其他领域也可能是不同协议的缩写。本文的 ACP 特指 **Agentic Commerce Protocol**，不是泛指所有 Agent 通信协议。[2]

## 16.3 协议的成熟与商业网络的成熟不同

A2A 可以描述任务、状态和产物，并支持认证授权相关信息。[3] 但对方声明“能够处理采购”，不等于它具备供应能力、履约信用或代表某公司的有效授权。

同样，商务协议定义结账对象，不意味着任意商家的税费、配送、退货与售后都会自动兼容。开放规范与生态采用之间，还需要实现、测试、商家接入和运营。

因此，市场不能只按协议支持数量或合作伙伴徽标来衡量。需要看实际生产连接、重复交易、交付成功、异常处理与合同续约。

## 16.4 从一个受控采购流程理解协作

以下为设计示例，不是某厂商已经实现的通用能力：

1. **提出需求**：采购人员给出规格、数量、预算与截止时间。
2. **查找候选**：Agent 仅从允许的供应商与数据源获得报价。
3. **核对条件**：检查库存、交付、税费、币种和报价有效期。
4. **生成比较**：解释差异和缺失信息，不擅自改变采购目标。
5. **审批承诺**：在形成采购订单或付款前校验权限。
6. **执行与核验**：以订单回执、交付和对账结果确认完成。
7. **处理异常**：对取消、部分交付、退款和争议分别建状态。

其中每个步骤都可以由已有软件或服务完成，不一定需要多个 LLM。在独立部署、异构系统或跨组织协作中，应根据实际互操作需求评估 Agent 间协议的价值；同一组织内部也可能存在这种需求。

## 16.5 经济性来自减少协调，而不只是减少点击

潜在收益包括更快的报价整理、减少材料往返、提高异常可见性和缩短订单处理时间。但更多 Agent 也可能带来更多调用、重复工作、错误和供应商依赖。

建议记录：

- 从需求到可执行报价的时间；
- 获得合格供应商的成本和数量；
- 订单修改、取消和重复执行；
- 按约交付、争议与退款；
- 全流程人工投入与软件成本。

如果减少了前端操作，却增加了后端异常处理，商业价值并没有自动成立。

## 16.6 买方与可行市场入口

买方可能是大型采购方、垂直交易平台、供应链服务商和商家。独立团队可以提供能力目录、商品与服务数据标准化、交易对账、授权验证或特定行业协作。

开放网络面对更难的问题：服务声明可信度、数据时效、语义差异、费用可比性以及出错后的责任。早期产品更适合从明确伙伴与固定流程开始，而不是让 Agent 随意发现陌生服务并交易。

## 16.7 条件性判断

**本章判断：**协议进展支持更低摩擦的机器协作，但尚不足以证明已经形成无边界、自治的 Agent 经济。更可能先扩展的是既有企业关系中的可授权任务网络。

> 机器可以协商格式和传递任务，但交易真正成立，还需要可信身份、明确授权、可验证履约和可处理的争议。
