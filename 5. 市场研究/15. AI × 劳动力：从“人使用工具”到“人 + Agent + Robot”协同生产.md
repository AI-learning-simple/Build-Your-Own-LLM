# 15. AI × 劳动力：从“人使用工具”到“人 + Agent + Robot”协同生产

上一章我们讨论了 Agent-Native Enterprise。

如果企业的组织方式正在变化，那么接下来必须回答一个更直接的问题：

> **企业未来到底需要什么样的劳动力？**

过去，一个企业的基本生产单元是：

```text
人
 ↓
工具
 ↓
完成任务
```

工业革命之后：

```text
人
 ↓
机器
 ↓
完成更多任务
```

软件革命之后：

```text
人
 ↓
软件
 ↓
完成数字任务
```

而 Agent 时代可能变成：

```text
人
 ↓
Agent
 ↓
Software / Robot / Service
 ↓
完成复杂任务
```

这意味着真正发生变化的，不只是工具。

而是：

> **劳动力本身开始数字化。**

# 15.50 行业实践：Klarna 实验的劳动力账本

关于“Agent 如何改变劳动力”，Klarna 是目前最完整的一份公开账本，值得单独展开。

这家支付公司在 2023 到 2026 年间经历了一个完整的循环：

```text
2023-2024：AI 客服上线，替代约 700 个客服岗位
2024-2025：发现复杂客诉处理质量下降，回聘部分人员
2025-2026：员工总数从约 4500 人降至约一半
同期：平均薪资上涨约 60%
```

这份账本里藏着劳动力市场的三个新规律。

第一，替代不是全有或全无，而是任务分层。简单对话归 AI，高情绪价值与高复杂度对话归人——Klarna 裁了又聘的那部分人，恰恰是做 AI 做不了的事。

第二，组织变小，人均产值变大。员工减半而业务量增长，意味着人均产出翻倍以上；薪资上涨 60% 说明市场开始为“能指挥 AI 的人”支付溢价。

第三，“管理”这个职能被重新定价。当 AI 承担执行，中层管理者的价值从“盯过程”转向“设计人机分工与处理例外”。

对比传统自动化（如流水线机器人）的历史，Agent 带来的差异在于打击面：物理自动化替代的是蓝领重复劳动，而 Agent 替代的是白领流程劳动——客服、文书、基础分析，这些正是过去三十年就业增长最快的岗位。

受影响的人群：

* 客服、行政、初级分析师：数量收缩最快的白领岗位；
* 剩余员工：工作复杂度与薪资同时上升，但需要具备“与 AI 协作”的新技能；
* HR 部门：招聘 JD 从“会用某软件”变成“会指挥 Agent 完成某结果”；
* 政策制定者：劳动力市场的调整速度第一次可能快于再培训体系的响应速度。

劳动力这一章的启示：Agent 时代的就业问题不是“有没有工作”，而是“调整期的摩擦有多痛”——Klarna 的账本证明终态可以是更高的生产力与薪资，但中间被替代的个体需要新的社会缓冲机制。

# 15.51 本章小结

AI 对劳动力最大的影响，不一定是：

> “AI 会不会取代人。”

更准确的问题应该是：

> **未来一个人能够调动多少智能资源？**

未来生产单元可能从：

```text
1 Human
```

变成：

```text
1 Human
+
N Agents
+
M Robots
+
External Services
```

最终形成：

```text
Human
  ↓
Agent
  ↓
Software / Robot
  ↓
Outcome
```

这意味着：

> **劳动力将从“人力规模竞争”逐渐走向“智能杠杆竞争”。**

而当这种能力进一步跨越企业边界，就会出现下一层变化：

```text
Individual
    ↓
Enterprise
    ↓
Agent Network
    ↓
Agent-to-Agent Commerce
    ↓
Agent Economy
```

这将不再只是企业内部的组织问题。

而会开始触及：

> **未来的交易、市场与经济体系。**
