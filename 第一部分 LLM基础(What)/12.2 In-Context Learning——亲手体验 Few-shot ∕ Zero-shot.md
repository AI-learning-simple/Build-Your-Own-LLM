# 12.2 In-Context Learning——亲手体验 Few-shot / Zero-shot

> **本节目标**：第12章讲了 In-Context Learning——模型不用训练、只靠 Prompt 里的几个例子就能"学会"一个新任务。本节，我们设计一个模型训练时几乎不可能见过的**自定义规则**，亲手验证 Zero-shot 会失败、而给几个例子（Few-shot）就能成功。
>
> **硬件要求**：只需要一个 1.5B 左右的模型做推理，**显存占用不到 2GB，8GB 显存绰绰有余**。

# 二、加载模型

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "Qwen/Qwen2.5-1.5B-Instruct"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, device_map="auto")

def ask(prompt, max_new_tokens=60):
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=False)
    return tokenizer.decode(output[0][inputs["input_ids"].shape[1]:], skip_special_tokens=True)
```

# 三、设计一个"自造规则"任务

如果直接用"英译中"之类的常见任务，模型训练时大概率已经见过无数遍，无法体现"当场学会新规则"的效果。我们发明一条模型不可能在训练数据里见过的规则：**把每个字母替换成字母表中往后数第3个字母**（`a→d, b→e, c→f...`，也就是简单的凯撒密码，key=3）。

---

# 四、Zero-shot：直接问，大概率会失败

```python
zero_shot_prompt = "请把字符串 'hello' 按照某种加密规则转换。规则是：每个字母替换成字母表中往后第3个字母。请直接给出结果，不要解释。"
print("Zero-shot 结果:", ask(zero_shot_prompt))
```

正确答案应该是 `khoor`（h→k, e→h, l→o, l→o, o→r）。1.5B 这个规模的模型在 Zero-shot 下经常会算错（字母表偏移计算需要精确的逐字符推理，小模型很容易出错），或者干脆理解错任务要求。

---

# 五、Few-shot：给几个例子，模型当场"学会"

```python
few_shot_prompt = """请学习下面的转换规律，并完成最后一个：

abc -> def
xyz -> abc
hello -> khoor

world ->"""

print("Few-shot 结果:", ask(few_shot_prompt, max_new_tokens=10))
```

正确答案是 `zruog`（w→z, o→r, r→u, l→o, d→g）。给了 3 个例子之后，你通常会发现模型的准确率明显提升——**它没有被重新训练，参数完全没有变化，只是从 Prompt 里的例子中"临时归纳"出了规律**，这正是 In-Context Learning 的核心。

---

# 六、增加例子数量，观察准确率变化

```python
def build_prompt(num_examples, examples, question):
    shown = examples[:num_examples]
    lines = [f"{a} -> {b}" for a, b in shown]
    return "请学习下面的转换规律，并完成最后一个：\n\n" + "\n".join(lines) + f"\n\n{question} ->"

examples = [("abc", "def"), ("xyz", "abc"), ("hello", "khoor"), ("test", "whvw"), ("code", "frgh")]
question = "python"  # 正确答案: sbwkrq

for n in [0, 1, 3, 5]:
    prompt = build_prompt(n, examples, question)
    result = ask(prompt, max_new_tokens=10)
    print(f"示例数={n}: {result!r}")
```

正确答案 `python -> sbwkrq`。理论上，示例数量越多，模型越容易"归纳"出正确规律——你可以实际跑一下，记录每个 `n` 下模型是否答对，感受 Few-shot 数量对效果的影响（不一定是严格单调的，但趋势通常是例子越多越稳）。

---

# 七、为什么这不是"训练"？

用 `nvidia-smi`（GPU）或 Python 内存工具观察，你会发现整个过程中**模型权重文件从头到尾没有发生任何写入或更新**——所有的"学习"都发生在一次 `forward` 计算里，例子和问题只是被一起塞进了同一个 Prompt，模型只是在**推理**，而不是在**训练**。这正是第12章反复强调的：In-Context Learning 改变的是 Context Representation，不是模型参数。
