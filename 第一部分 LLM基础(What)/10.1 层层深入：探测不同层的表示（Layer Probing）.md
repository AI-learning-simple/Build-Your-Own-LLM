# 10.1 层层深入：探测不同层的表示（Layer Probing）

> **本节目标**：第10章的核心结论是"Transformer 不同层学到了不同层次的信息——浅层学词法，中层学语义，深层学推理"。这个结论听起来很有道理，但它是真的吗？本节，我们将加载一个别人已经训练好的开源小模型，亲手把每一层的中间表示"挖"出来，用数据验证这个结论，而不是仅凭直觉相信它。
>
> **硬件要求**：本节只做推理（Inference），不做训练。模型选择 `Qwen2.5-0.5B`（5 亿参数，FP16 约 1GB 显存），**8GB 显存完全是"降维打击"，CPU 也能跑，只是慢一些**。这是全书第一次加载真实的开源大模型。

# 二、加载一个真实的开源模型

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "Qwen/Qwen2.5-0.5B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, output_hidden_states=True)
model.eval()
device = "cuda" if torch.cuda.is_available() else "cpu"
model.to(device)
print("模型层数:", model.config.num_hidden_layers)
```

第一次运行会自动从 Hugging Face 下载权重（约 1GB），下载完成后离线也能用。`output_hidden_states=True` 是本节实验的关键——它会让模型返回**每一层**的中间表示，而不仅仅是最后一层。

---

# 三、设计一个探测任务：多义词在不同层的变化

第10章举过一个例子：`bank` 在不同句子里到底表示"银行"还是"河岸"，Embedding 层无法区分，但随着层数加深，模型会逐渐分化出正确的含义。我们用中文的多义词 `苹果` 复现这个实验——一句话里 `苹果` 指水果，另一句话里 `苹果` 指公司：

```python
sentence_a = "我今天早上吃了一个苹果，很甜。"
sentence_b = "苹果公司今天发布了新款手机。"

def get_hidden_states(sentence, target_word):
    inputs = tokenizer(sentence, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = model(**inputs)
    hidden_states = outputs.hidden_states  # tuple: (层数+1, batch, seq_len, hidden_size)

    tokens = tokenizer.convert_ids_to_tokens(inputs["input_ids"][0])
    target_pos = [i for i, t in enumerate(tokens) if target_word in t][0]

    return [layer[0, target_pos, :].float().cpu() for layer in hidden_states]

vecs_a = get_hidden_states(sentence_a, "苹")
vecs_b = get_hidden_states(sentence_b, "苹")
print("共", len(vecs_a), "层表示（第0层是 Embedding，之后每一层是一个 Transformer Block 的输出）")
```

---

# 四、计算每一层的相似度变化

如果第10章的理论是对的，`苹果（水果）` 和 `苹果（公司）` 这两个表示在**浅层应该几乎一样**（因为浅层还没结合上下文），但**深层应该逐渐分化**（因为模型已经理解了两句话里"苹果"含义完全不同）：

```python
import torch.nn.functional as F

for layer_idx in range(len(vecs_a)):
    sim = F.cosine_similarity(vecs_a[layer_idx].unsqueeze(0), vecs_b[layer_idx].unsqueeze(0)).item()
    print(f"Layer {layer_idx:2d}: cosine similarity = {sim:.4f}")
```

在 Qwen2.5-0.5B（24 层）上运行，你会观察到类似的趋势：**第 0~2 层（接近 Embedding）相似度很高（0.9+），中间层开始明显下降，到较深的层数相似度降到 0.5 甚至更低**——这与第10章"浅层几乎不区分上下文、深层逐渐分化语义"的结论完全吻合。

# 五、可视化整条曲线

```python
import matplotlib.pyplot as plt

sims = [F.cosine_similarity(vecs_a[i].unsqueeze(0), vecs_b[i].unsqueeze(0)).item() for i in range(len(vecs_a))]
plt.plot(range(len(sims)), sims, marker="o")
plt.xlabel("Layer")
plt.ylabel("Cosine Similarity (水果义 vs 公司义)")
plt.title("苹果在不同层的语义分化")
plt.show()
```

你会看到一条整体向下走的曲线——这正是"层层深入、逐渐抽象"最直观的证据。

# 六、换一个角度：不同层做同一个任务，效果一样吗？

除了看相似度，还可以直接验证"不同层的表示，用于同一个任务，效果是否不同"。这里用一个简化探针（Probe）实验：截断模型到第 `k` 层，直接接一个语言模型头，看这个"半成品模型"预测下一个词的能力：

```python
from transformers import AutoModelForCausalLM

def predict_with_layer(prompt, num_layers_to_use):
    inputs = tokenizer(prompt, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = model(**inputs)
    hidden = outputs.hidden_states[num_layers_to_use][0, -1, :]
    logits = model.lm_head(hidden.unsqueeze(0).to(model.lm_head.weight.dtype))
    top_id = torch.argmax(logits, dim=-1).item()
    return tokenizer.decode([top_id])

prompt = "中国的首都是"
for k in [2, 6, 12, 18, 24]:
    print(f"只用前 {k} 层 -> 预测下一个词: {predict_with_layer(prompt, k)!r}")
```

请注意，这个实验有一个前提：模型的 `lm_head` 是专门针对"最后一层"训练的，用在中间层上不完全公平（相当于"用只考了前半场的成绩去预判最终排名"），但即便如此，你通常仍能观察到：**层数越少，预测越离题；层数越多，预测越靠近正确答案（"北京"）**——这也从另一个角度印证了"越深的层，越接近最终预测目标"。

---

# 七、这个实验和第10章理论的对应关系

| 第10章理论 | 本节实验证据 |
|---|---|
| Embedding 只是初始表示，不含上下文 | 第0层（Embedding 层）两个"苹果"几乎完全相同 |
| Attention/FFN 不断更新 Representation | 相似度曲线随层数增加持续变化 |
| 浅层学词法/局部语法，深层学语义/推理 | 浅层相似度高（还没分化），深层相似度低（已分化出具体含义） |
| 最终预测依赖最后一层表示 | 层数越多，"预测下一个词"的准确性越高 |
