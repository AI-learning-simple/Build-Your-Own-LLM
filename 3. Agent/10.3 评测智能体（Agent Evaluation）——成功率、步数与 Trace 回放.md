# 10.3 评测智能体（Agent Evaluation）——成功率、步数与 Trace 回放

> **本节定位**：实践第 10 章的评测闭环。一个完整文件包含 v1/v2/v3、受限计算器、统一评分器、Trace 保存与确定性回放。
>
> **硬件要求**：默认标准库、CPU，无下载和付费服务；可选本地模型模式需另装依赖并准备权重。

## 一、先定义通过条件

本实验要求“借助 calculator 回答”，而非仅答对算术题。因此通过必须同时满足：

1. 工具真实执行成功，且其结果与预期数值一致；
2. 结果作为 observation 传给下一轮之后，模型才给最终答案；
3. 最终答案数值正确。未经工具就直接 `ANSWER`、工具报错后碰巧答对、同轮抢答都不通过。

题目并不保证某个模型“心算不动”；是否调用工具应由验收契约检查，不应靠题目难度猜测。以下默认使用**预设响应的确定性测试替身**来复现工程错误；它不代表真实模型能力。真实模型评测使用同一个 `run_one`。

## 二、保存完整实验文件

Python 3.11+，将整个代码块保存为 `eval_agent.py`，默认无第三方依赖：

```python
import argparse
import ast
import copy
import importlib.metadata
import json
import math
import operator
import platform
import re
import time
from pathlib import Path

SYSTEM = ("必须先调用 calculator，等待结果后再回答。每轮只输出一种格式：\n"
          "ACTION: calculator(算式)\n或 ANSWER: 数字。")
QUESTIONS = [
    ("387×291", 112617), ("(23+45)×12", 816), ("1567-889", 678),
    ("1024/32", 32), ("57*83", 4731), ("9527-3468", 6059),
    ("144+256-89", 311), ("9720÷27", 360), ("68*74", 5032),
    ("(1000-237)/7", 109),
]
TOOL_SCHEMA = {"name": "calculator", "input": {"expr": "算术表达式字符串，最长128字符"},
               "output": {"ok": "bool", "value": "number（仅成功时）", "error": "失败原因"}}
OPS = {ast.Add: operator.add, ast.Sub: operator.sub,
       ast.Mult: operator.mul, ast.Div: operator.truediv}

def calculator(expr, normalize=False):
    try:
        if normalize:
            expr = expr.replace("×", "*").replace("÷", "/")
        if len(expr) > 128 or not re.fullmatch(r"[0-9+*/().\s-]+", expr):
            raise ValueError("表达式过长或含非法字符")
        tree = ast.parse(expr.strip(), mode="eval")
        if len(list(ast.walk(tree))) > 64:
            raise ValueError("表达式过于复杂")
        def evaluate(node):
            if isinstance(node, ast.Expression):
                return evaluate(node.body)
            if isinstance(node, ast.Constant) and type(node.value) in (int, float):
                value = node.value
            elif isinstance(node, ast.BinOp) and type(node.op) in OPS:
                value = OPS[type(node.op)](evaluate(node.left), evaluate(node.right))
            elif isinstance(node, ast.UnaryOp) and isinstance(node.op, (ast.USub, ast.UAdd)):
                value = evaluate(node.operand) * (-1 if isinstance(node.op, ast.USub) else 1)
            else:
                raise ValueError("仅允许数字、括号和四则运算")
            if not math.isfinite(value) or abs(value) > 1e12:
                raise ValueError("数值超出实验范围")
            return value
        return {"ok": True, "value": evaluate(tree)}
    except (ValueError, SyntaxError, ZeroDivisionError, OverflowError, RecursionError) as exc:
        return {"ok": False, "error": str(exc)}

def extract_expr(response, version):
    if version in ("v1", "v2"):
        # 故意保留的教学错误：遇到第一个右括号就结束。
        match = re.search(r"ACTION:\s*calculator\(([^)]+)\)", response)
        return match.group(1) if match else None
    # v3 恰好一个完整动作行；允许同轮 ANSWER 但控制器会忽略它。
    lines = [line.strip() for line in response.splitlines() if line.strip()]
    actions = [line for line in lines if line.startswith("ACTION:")]
    if len(actions) != 1 or any(
        not line.startswith("ACTION:") and not re.fullmatch(
            r"ANSWER:\s*-?(?:\d+(?:\.\d*)?|\.\d+)", line)
        for line in lines
    ):
        return None
    match = re.fullmatch(r"ACTION:\s*calculator\((.*)\)", actions[0])
    return match.group(1) if match else None

def run_one(question, expected, version, llm, metadata):
    messages = [{"role": "system", "content": SYSTEM},
                {"role": "user", "content": "请计算：" + question}]
    trace = []
    tool_calls = 0
    observed_correct_tool = False
    status, success = "step_limit", False
    for step in range(6):
        started = time.perf_counter()
        response = llm(copy.deepcopy(messages))
        trace.append({"kind": "llm", "step": step, "messages": copy.deepcopy(messages),
                      "output": response, "latency_s": time.perf_counter() - started})
        expr = extract_expr(response, version)
        answer = re.search(r"ANSWER:\s*(-?(?:\d+(?:\.\d*)?|\.\d+))\s*$", response)
        if expr is not None:
            result = calculator(expr, normalize=(version == "v3"))
            tool_calls += 1
            trace.append({"kind": "tool", "step": step, "name": "calculator",
                          "arguments": {"expr": expr}, "result": result})
            if version == "v1" and answer:
                # 故意错误：控制器采纳同轮答案；独立评分契约必须判失败。
                status = "premature_answer"
                break
            messages += [{"role": "assistant", "content": response},
                         {"role": "user", "content": "OBSERVATION: " + json.dumps(result)}]
            observed_correct_tool = result["ok"] and math.isclose(
                float(result.get("value", 0)), expected, rel_tol=0, abs_tol=0.01)
            continue
        final_answer = re.fullmatch(r"ANSWER:\s*(-?(?:\d+(?:\.\d*)?|\.\d+))", response.strip())
        if final_answer:
            value = float(final_answer.group(1))
            success = observed_correct_tool and math.isfinite(value) and math.isclose(
                value, expected, rel_tol=0, abs_tol=0.01)
            status = "passed" if success else "answer_without_valid_tool_or_wrong_answer"
            break
        messages += [{"role": "assistant", "content": response},
                     {"role": "user", "content": "格式错误，请输出单个 ACTION 或 ANSWER。"}]
    return {"question": question, "expected": expected, "version": version,
            "metadata": metadata, "tool_schema": TOOL_SCHEMA,
            "success": success, "status": status, "steps": step + 1,
            "tool_calls": tool_calls, "trace": trace}

def scripted_llm(question, expected):
    # 用固定响应注入三类错误，不在这里调用模型；每题返回独立闭包。
    def respond(messages):
        if len(messages) == 2:
            expr = question.replace("×", "*")
            premature = "\nANSWER: 114057" if question == "387×291" else ""
            return "ACTION: calculator(" + expr + ")" + premature
        # 即使工具失败也给预期答案，专门测试评分器不会把碰巧答对算成功。
        return "ANSWER: " + str(expected)
    return respond

def load_local_llm():
    import torch
    from transformers import AutoTokenizer, AutoModelForCausalLM
    model_id = "Qwen/Qwen2.5-1.5B-Instruct"
    tokenizer = AutoTokenizer.from_pretrained(model_id)
    model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype=torch.float32).eval()
    config = {"max_new_tokens": 80, "do_sample": False}
    def respond(messages):
        text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
        inputs = tokenizer(text, return_tensors="pt")
        with torch.inference_mode():
            output = model.generate(**inputs, **config)
        return tokenizer.decode(output[0][inputs["input_ids"].shape[1]:], skip_special_tokens=True)
    metadata = {"backend": "local", "model_id": model_id,
                "model_revision": getattr(model.config, "_commit_hash", None),
                "generation": config, "python": platform.python_version(),
                "libraries": {p: importlib.metadata.version(p) for p in ["torch", "transformers"]}}
    return respond, metadata

def replay(run):
    # 冻结 LLM 输出，校验完整输入，再真实重算无副作用的 calculator。
    calls = iter(event for event in run["trace"] if event["kind"] == "llm")
    def recorded_llm(messages):
        event = next(calls)
        assert messages == event["messages"], "输入轨迹不一致，不能声称等价回放"
        return event["output"]
    result = run_one(run["question"], run["expected"], run["version"], recorded_llm, run["metadata"])
    assert next(calls, None) is None, "回放没有消费完原轨迹"
    assert result["status"] == run["status"] and result["success"] == run["success"]
    old_tools = [e for e in run["trace"] if e["kind"] == "tool"]
    new_tools = [e for e in result["trace"] if e["kind"] == "tool"]
    assert old_tools == new_tools, "工具结果或调用顺序发生变化"
    return result

def self_test():
    assert calculator("(23+45)×12", True) == {"ok": True, "value": 816}
    assert calculator("9720÷27", True)["value"] == 360
    for expr in ["1/0", "2**100", "name()", "(" * 1000]:
        assert not calculator(expr, True)["ok"]
    meta = {"backend": "test"}
    assert not run_one("1+1", 2, "v3", lambda _: "ANSWER: 2", meta)["success"]
    assert not run_one("1/0", 2, "v3", scripted_llm("1/0", 2), meta)["success"]
    assert extract_expr("ACTION: calculator(1+1)\nACTION: calculator(2+2)", "v3") is None
    malformed = lambda messages: "ACTION: calculator(1+1)" if len(messages) == 2 else "备注 ANSWER: 2"
    assert not run_one("1+1", 2, "v3", malformed, meta)["success"]

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--backend", choices=["scripted", "local"], default="scripted")
    parser.add_argument("--output", default="trace.json")
    parser.add_argument("--replay")
    args = parser.parse_args()
    self_test()
    if args.replay:
        saved = json.loads(Path(args.replay).read_text(encoding="utf-8"))
        for run in saved["runs"]:
            replay(run)
        print("确定性回放通过：", len(saved["runs"]), "条轨迹")
    else:
        local_llm, metadata = (None, {"backend": "scripted", "fixture_version": "1",
                                     "python": platform.python_version()})
        if args.backend == "local":
            local_llm, metadata = load_local_llm()
        runs = []
        for version in ["v1", "v2", "v3"]:
            batch = [run_one(q, expected, version, local_llm or scripted_llm(q, expected),
                             metadata) for q, expected in QUESTIONS]
            runs += batch
            print(version, {"successes": sum(r["success"] for r in batch),
                            "total": len(batch),
                            "mean_steps": sum(r["steps"] for r in batch) / len(batch),
                            "tool_calls": sum(r["tool_calls"] for r in batch)})
        Path(args.output).write_text(json.dumps({"format_version": 1, "implementation": "eval-1",
                                                "runs": runs}, ensure_ascii=False, indent=2),
                                    encoding="utf-8")
```

启动与回放：

```bash

python eval_agent.py --replay trace.json
```

## 三、三版改动怎样接到同一个评测器

| 版本 | 故意保留/修复的行为 | 如何从 Trace 观察 |
|---|---|---|
| v1 | 采纳同轮抢答；正则截断嵌套括号；不归一化乘除号 | 第一题 `premature_answer`；其他题的工具 `ok=False` |
| v2 | 工具结果必须反馈给下一轮，忽略同轮 ANSWER | 第一题恢复；括号/符号问题仍存在 |
| v3 | 完整动作行提取外层参数；AST 校验结构；归一化 `×/÷` | 嵌套算式完整进入工具，工具状态与答案共同决定通过 |

默认 fixture 的算术成功数可推导为 v1=6/10、v2=7/10、v3=10/10；这是固定输入注入的预期验收值，不是本地模型的实测成绩。真实模型结果必须由 `--backend local` 运行后填入实验记录，不能沿用旧版示意百分比或精确耗时。此处 v3 是仅适用于算术单动作行的小解析器，不是通用 Function Calling；原生工具调用也仍需要 schema 和运行时校验。

步骤数计 LLM 调用次数；工具次数计实际执行尝试，包括失败。生产评测还应单独统计工具成功率、格式违规率、预算超限与超时，不要用“调用次数多”代替“任务做得好”。

## 四、查看 Trace 不等于回放

打开 `trace.json` 查看输入、输出和工具结果只是**查看轨迹**。本例 `--replay` 才会重走控制器：冻结已记录的 LLM 响应、逐轮校验完整消息、重新执行纯计算工具，并比较状态与工具事件。延迟不参与相等判断。

这种回放定位的是控制流和纯工具回归，不会重新测模型质量、实时数据或生产副作用。对于发消息、写数据库等工具，应该使用录制结果的替身或隔离测试环境，不能默认重新产生副作用。比较新控制器时，输入消息很可能变化；原轨迹不能自动充当新策略的有效后续回答。

本例保存了完整问题、预期值、system 指令（在每轮 messages 内）、工具契约、实现格式版本、策略版本和模型/库元数据。若模型 revision 返回 `None`，应补记实际下载的 commit/hash 后才能做严格跨机器复现。Trace 可能包含敏感输入，上线前应增加脱敏、访问控制与保留期限。

## 五、验收与外推边界

- 默认运行自测覆盖嵌套括号、符号归一化、除零、超长输入、禁用运算、直接抢答和失败工具后答对；v1/v2 的故意错误产生可记录失败，不再表现为未定义变量或函数外 `continue`。
- 十题只是开发集；不能由 10/10 推断通用能力，更不能把替身成绩当作模型测评。
- 真实模型应使用独立测试集、重复运行、版本固定与置信区间；重复全部成功率需逐任务测量，不可直接把总体成功率任意乘方。
- 本节完成“记录→定位→修改→同一入口复测”，不是“打印旧日志即声称复现”。
