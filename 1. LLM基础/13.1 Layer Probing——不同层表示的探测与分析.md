# 13.1 Layer Probing——不同层表示的探测与分析

> **硬件要求**：CPU 即可运行；涉及加载小型模型的部分，如有 GPU 会更快
>
> **本节目标**：加载一个预训练开源模型，提取各层 Hidden State，探索同一 Token 在两种左侧上下文中的表示相似度如何变化。实验不预设“浅层词法、中层语义、深层推理”的固定分工；单个句对只能提供观察线索，不能验证普遍层次规律。

> **硬件说明**：本节只做推理，不训练参数。实际内存/显存和速度取决于 checkpoint、dtype、后端、输入长度、是否返回全部 Hidden State 以及库版本。CUDA 可用时可使用 FP16；CPU 通常应使用 FP32。能否在特定设备运行以本机测量为准。

# 二、加载一个真实的开源模型

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "Qwen/Qwen2.5-0.5B"
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
dtype = torch.float16 if device.type == "cuda" else torch.float32

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=dtype,
    output_hidden_states=True,
).to(device)
model.eval()
print("模型层数:", model.config.num_hidden_layers)
```

第一次运行会自动从 Hugging Face 下载权重（约 1GB），下载完成后离线也能用。`output_hidden_states=True` 是本节实验的关键——它会让模型返回**每一层**的中间表示，而不仅仅是最后一层。

# 三、设计一个探测任务：多义词在不同层的变化

第 13 章举过一个例子：`bank` 在不同句子里到底表示"银行"还是"河岸"，Embedding 层无法区分，但随着层数加深，模型会逐渐分化出正确的含义。我们用中文的多义词 `苹果` 复现这个实验——一句话里 `苹果` 指水果，另一句话里 `苹果` 指公司：

```python
# Qwen是因果模型，目标词只能利用左侧上下文；因此把消歧线索放在“苹果”之前
# 两句采用平行结构，也尽量让目标词处于相同位置
sentence_a = "今天购买的水果是苹果"
sentence_b = "今天投资的公司是苹果"

def get_hidden_states(sentence, target_word):
    inputs = tokenizer(sentence, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = model(**inputs)
    hidden_states = outputs.hidden_states  # tuple: (层数+1, batch, seq_len, hidden_size)

    tokens = tokenizer.convert_ids_to_tokens(inputs["input_ids"][0])
    target_pos = [i for i, t in enumerate(tokens) if target_word in t][0]

    return [layer[0, target_pos, :].float().cpu() for layer in hidden_states]

vecs_a = get_hidden_states(sentence_a, "苹")
vecs_b = get_hidden_states(sentence_b, "苹")
print("共", len(vecs_a), "层表示（第0层是 Embedding，之后每一层是一个 Transformer Block 的输出）")
```

---

# 四、计算每一层的相似度变化

第0层主要由相同的 Token Embedding 和位置表示组成；经过多层因果 Attention 后，目标词会结合左侧“水果”或“公司”等线索。因此可以观察两条表示的余弦相似度是否随层数变化。注意：这是探索性探测，不应预设曲线必须单调下降。

```python
import torch.nn.functional as F

for layer_idx in range(len(vecs_a)):
    sim = F.cosine_similarity(vecs_a[layer_idx].unsqueeze(0), vecs_b[layer_idx].unsqueeze(0)).item()
    print(f"Layer {layer_idx:2d}: cosine similarity = {sim:.4f}")
```

运行后请记录真实曲线，而不要把某个固定数值当作必然结果。不同模型、Token 切分和句式可能产生不同走势；若后续层的表示出现分化，只能说明上下文改变了该位置的内部表示，不能仅凭一条曲线证明模型已经完成严格的词义消歧。

# 五、可视化整条曲线

```python
import matplotlib.pyplot as plt

sims = [F.cosine_similarity(vecs_a[i].unsqueeze(0), vecs_b[i].unsqueeze(0)).item() for i in range(len(vecs_a))]
plt.plot(range(len(sims)), sims, marker="o")
plt.xlabel("Layer")
plt.ylabel("Cosine Similarity (水果义 vs 公司义)")
plt.title("苹果在不同层的语义分化")
plt.show()
```

图中展示的是两段上下文对同一 Token 表示的影响如何随层数变化。曲线可能下降、波动，甚至在某些层回升；应结合更多句对、随机种子和线性探针再判断层次化语义规律。

# 六、简化 Logit Lens：中间层经最终输出头会偏好哪些 Token？

下面做一个简化的 **logit lens**：模型仍执行完整 forward 并返回所有 Hidden State；代码只是事后取第 `k` 层最后一个位置的向量，直接送入模型最终的 `lm_head`，观察最高分 Token。它没有截断计算，也没有训练分类器，因此不属于通常所说的受监督 Probe。

```python
from transformers import AutoModelForCausalLM

def predict_with_layer(prompt, num_layers_to_use):
    inputs = tokenizer(prompt, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = model(**inputs)
    hidden = outputs.hidden_states[num_layers_to_use][0, -1, :]
    logits = model.lm_head(hidden.unsqueeze(0).to(model.lm_head.weight.dtype))
    top_id = torch.argmax(logits, dim=-1).item()
    return tokenizer.decode([top_id])

prompt = "中国的首都是"
layers_to_view = [
    k for k in [2, 6, 12, 18, 24]
    if k < len(model.model.layers) + 1
]
for k in layers_to_view:
    print(f"读取 Hidden State {k:2d} -> 最终 lm_head 的 top-1: {predict_with_layer(prompt, k)!r}")
```

这个结果有两项关键局限。第一，`outputs.hidden_states[k]` 来自一次完整 forward；读取早期状态不会节省后续层计算，`k` 只标识事后选取的 Hidden State。第二，最终 `lm_head`（以及某些架构在输出头前使用的 final norm）按最终层分布训练，直接作用于中间层存在分布错配；本简化代码也未额外拟合层专属 Probe。各层 top-1 可能改善、波动或退化，不能预设越深越接近“北京”，也不能据此给层能力排序。

# 七、这个实验和第 13 章理论的对应关系

| 第 13 章理论 | 本节实验证据 |
|---|---|
| Embedding 是初始表示 | 同一 Token、相同位置的第0层表示应非常接近 |
| Attention/FFN 更新 Representation | 相似度曲线可显示两种左侧上下文如何逐层影响目标位置 |
| 不同层可能编码不同信息 | 单个余弦曲线只能提供线索，需要更多样本和探针验证 |
| 最终输出头针对最终层分布训练 | 中间层直连最终 `lm_head` 只是简化 logit lens，存在 final norm/分布错配 |

---

# 本节小结

本实验演示了如何提取开源模型各层 Hidden State、比较同一 Token 在两种左侧上下文中的表示，并用简化 logit lens 查看中间表示经最终输出头后的 Token 偏好。结果应被视为探索性分析：单个句对和未校准的最终 head 不足以证明“浅层/深层”的普遍分工；严格结论需要控制数据集、多随机种子，以及为各层单独训练和评测的 Probe。
