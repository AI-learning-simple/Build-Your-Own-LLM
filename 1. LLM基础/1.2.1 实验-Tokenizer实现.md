## 实验2.1：给第一章增加 Character Tokenizer

### 实验目标

第一章中，我们的 Language Model 一直直接处理字符串：

```python
current = text[i]
next = text[i+1]
```

这一节，我们**不改变 Language Model 的任何逻辑**，只是在它前面增加一个 Tokenizer，最终的数据流变成：

```text
Text
 │
Tokenizer
 │
Token ID
 │
Language Mode
```

---

### Step1 建立 Vocabulary

新增 tokenizer.py

```python
text = "hello world"

chars = sorted(set(text))

print(chars)
```

输出：

```text
[' ', 'd', 'e', 'h', 'l', 'o', 'r', 'w']
```

这就是 Character Vocabulary。

---

### Step2 建立 stoi

继续增加：

```python
stoi = {
    ch: i
    for i, ch in enumerate(chars)
}

print(stoi)
```

输出：

```python
{
 ' ':0,
 'd':1,
 'e':2,
 'h':3,
 'l':4,
 'o':5,
 'r':6,
 'w':7
}
```

这里第一次得到 Token ID。

---

### Step3 建立 itos

```python
itos = {
    i: ch
    for ch, i in stoi.items()
}
```

作用：

```
字符
↓
ID

ID
↓
字符
```

以后模型生成数字以后，就靠它恢复文字。

---

### Step4 Encode

增加：

```python
encoded = [
    stoi[ch]
    for ch in text
]

print(encoded)
```

输出：

```text
[3,2,4,4,5,0,7,5,6,4,1]
```

到这里，Tokenizer 已经完成。

---

### Step5 改造第一章代码

第一章：

```python
current = text[i]
next = text[i+1]
```

改成：

```python
current = encoded[i]
next = encoded[i+1]
```

**只有这一处需要修改**，其它代码全部保持不变。

---

### Step6 Decode

生成结束以后：

```python
result = [
    3,2,4,4,5,0,7,5,6,4,1
]

text = "".join(
    itos[i]
    for i in result
)

print(text)
```

输出 "hello world" 说明整个流程已经打通。

---

### 完整代码
```python
import random

# ===========================
# Step1：准备训练数据
# ===========================

text = "hello world"

# ===========================
# Step2：构建 Character Tokenizer
# ===========================

# Vocabulary
chars = sorted(set(text))

# String -> Integer
stoi = {
    ch: i
    for i, ch in enumerate(chars)
}

# Integer -> String
itos = {
    i: ch
    for ch, i in stoi.items()
}

print("Vocabulary:")
print(chars)

print("\nString -> ID")
print(stoi)

# ===========================
# Step3：Encode
# ===========================

encoded = [
    stoi[ch]
    for ch in text
]

print("\nEncoded:")
print(encoded)

# ===========================
# Step4：训练 Bigram Model
# ===========================

model = {}

for i in range(len(encoded) - 1):

    current = encoded[i]
    nxt = encoded[i + 1]

    if current not in model:
        model[current] = []

    model[current].append(nxt)

# ===========================
# Step5：生成 Token ID
# ===========================

def generate(start_id, max_length=20):

    result = [start_id]

    current = start_id

    for _ in range(max_length):

        if current not in model:
            break

        nxt = random.choice(model[current])

        result.append(nxt)

        current = nxt

    return result

# ===========================
# Step6：Decode
# ===========================

start = stoi["h"]

generated_ids = generate(start)

generated_text = "".join(
    itos[i]
    for i in generated_ids
)

print("\nGenerated IDs:")
print(generated_ids)

print("\nGenerated Text:")
print(generated_text)
```

### 本实验修改了什么？

实际上，这个实验只增加了三个函数：

```text
encode()

decode()

Vocabulary
```

Language Model 一行没改，这是一个非常重要的结论：

> **Tokenizer 与 Language Model 是两个独立模块。**

后面无论是 Character、Word、BPE 还是 SentencePiece，我们都不会再修改 Language Model，只需要替换 Tokenizer 即可。
