# 11.1 从零训练 nanoGPT

> **本节目标**：参考 Andrej Karpathy 的 nanoGPT，手写一个 GPT-2 风格的语言模型。重点是**手写 `CausalSelfAttention`**——QKV 投影 → 拆多头 → 缩放点积 → Causal Mask → Softmax → 加权求和 → 拼接 → 乘 `W_O`，让每一行代码都和第 10 章手推的 Attention 公式一一对应。训练语料用英文 tiny-shakespeare，Tokenizer 用 BPE（tiktoken 的 `gpt2` 词表），最终让模型学会生成莎士比亚风格的英文。
>
> **硬件要求**：本节模型约 700 万参数，**8GB 显存的入门级显卡（如 RTX 3060/4060）绰绰有余，纯 CPU 笔记本也能在几分钟内跑完**。

---

# 一、为什么改用手写 Attention？

第 11 章拼 `TransformerBlock` 时，为了先跑通，用了 PyTorch 封装好的 `nn.MultiheadAttention`。它省事，但也把第 10 章辛辛苦苦讲透的细节——Q/K/V 从哪来、怎么拆成多头、怎么缩放点积、怎么拼回去、`W_O` 在哪——全部藏进了一个黑盒里。

nanoGPT 的价值正在于它**把这一切摊开写**：`CausalSelfAttention` 一共就十几行，每一行都对应第 10 章的一个公式。所以本节换用 nanoGPT 的写法，让"看懂原理"和"看懂代码"完全对齐。

# 三、准备数据：tiny-shakespeare

nanoGPT 原版用的语料是 **tiny-shakespeare**——莎士比亚全部作品拼成的一个纯文本文件，约 1MB，是验证"小模型能学会语言模式"的经典数据集。下载它：

```bash
wget https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt
```

下载后得到一个 `input.txt`。用 `tiktoken` 的 `gpt2` 词表把整本书编码成 Token ID 序列：

```python
import torch
import tiktoken

enc = tiktoken.get_encoding("gpt2")          # GPT-2 的 BPE 词表（vocab_size = 50257）
text = open("input.txt", encoding="utf-8").read()
data = enc.encode(text)                      # 整本书变成一串 token id
print("token 数:", len(data), "词表大小:", enc.n_vocab)
```

> 运行输出约为 `token 数: 1115394, 词表大小: 50257`。这正是第 2 章 BPE 思路的直接应用——只不过这里的词表是 GPT-2 在大规模英文上**已经训练好**的，不需要自己从头合并。

把数据切成 train/val 两份（90/10），并写一个取 Batch 的函数：这里沿用第 10 章 Attention 的训练思路，用固定长度的 `block_size` 作为当前序列窗口；每个样本都构造一个长度为 `block_size` 的输入序列 `x`，以及对应右移一位的目标 `y`，也就是 Next Token Prediction。这样在每次训练中，模型都在一个局部窗口内学习“当前位置要预测下一个 token”，而不是直接把整篇文本一次性喂进模型：

```python
block_size = 256        # 当前序列窗口长度
batch_size = 32

n = int(len(data) * 0.9)
train_data, val_data = data[:n], data[n:]

def get_batch(split):
    data = train_data if split == "train" else val_data
    ix = torch.randint(len(data) - block_size, (batch_size,))
    x = torch.stack([torch.tensor(data[i:i + block_size]) for i in ix])
    y = torch.stack([torch.tensor(data[i + 1:i + 1 + block_size]) for i in ix])
    return x, y
```

# 四、GPT 配置：GPTConfig

nanoGPT 用一个 `GPTConfig` 集中放所有超参数，避免到处散落魔法数字：

```python
from dataclasses import dataclass

@dataclass
class GPTConfig:
    block_size: int = 256      # 上下文窗口（最长能看多少个 Token）
    vocab_size: int = 50304    # 词表大小：gpt2 实际是 50257，pad 到 64 的倍数以便 GPU 计算
    n_layer: int = 4           # 层数
    n_head: int = 4            # 注意力头数
    n_embd: int = 128          # 隐藏维度 d_model
    dropout: float = 0.0       # 这么小的模型通常不需要 Dropout

config = GPTConfig()
```

> 这里的 `n_embd=128, n_head=4, n_layer=4` 是一个"baby"配置，约 700 万参数；nanoGPT 原版默认是 GPT-2 的 `n_layer=12, n_head=12, n_embd=768`（1.24 亿参数），两者**代码完全相同，只是配置不同**——这正体现了第 11 章说的"同一个 Block 靠堆叠和加宽来放大"。

# 五、手写 CausalSelfAttention（核心）

这是全节最值得逐行读的部分。回顾第 10 章的完整流程：

```
Embedding → 投影出 Q/K/V → 拆多头 → Q·K^T/√d_k → Causal Mask → Softmax → 加权 V → 拼接 → 乘 W_O → Output
```

手写代码正好按这 8 步走：

```python
import math
import torch.nn as nn
from torch.nn import functional as F

class CausalSelfAttention(nn.Module):
    def __init__(self, config):
        super().__init__()
        assert config.n_embd % config.n_head == 0  # 每个头的维度要能整除
        # 一个 Linear 同时投影出 Q、K、V 三份（第 10 章"线性投影（整体计算）"）
        self.c_attn = nn.Linear(config.n_embd, 3 * config.n_embd)
        # 输出投影 W_O（第 10 章明确强调：加权求和只是 Context，乘 W_O 才是真正的 Output）
        self.c_proj = nn.Linear(config.n_embd, config.n_embd)
        self.attn_dropout = nn.Dropout(config.dropout)
        self.resid_dropout = nn.Dropout(config.dropout)
        self.n_head = config.n_head
        self.n_embd = config.n_embd
        # Causal Mask：下三角矩阵（第 11 章第八节），1=可看、0=屏蔽
        self.register_buffer(
            "bias",
            torch.tril(torch.ones(config.block_size, config.block_size))
                 .view(1, 1, config.block_size, config.block_size),
        )

    def forward(self, x):
        B, T, C = x.size()   # batch、序列长度、隐藏维度

        # ① 整体投影出 Q、K、V，再切回三份（各 C 维）
        q, k, v = self.c_attn(x).split(self.n_embd, dim=2)

        # ② 拆多头 + 合并 batch 与头：把 (B,T,C) 变成 (B, nh, T, hs)
        #    hs = C // n_head 是每个头的维度；transpose 后"头"成了第 2 维，可独立并行算
        hs = C // self.n_head
        q = q.view(B, T, self.n_head, hs).transpose(1, 2)   # (B, nh, T, hs)
        k = k.view(B, T, self.n_head, hs).transpose(1, 2)
        v = v.view(B, T, self.n_head, hs).transpose(1, 2)

        # ③ 缩放点积：Q·K^T / √hs（第 10 章的 Scaled Dot-Product）
        att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(hs))   # (B, nh, T, T)

        # ④ Causal Mask：把"看向未来"的位置（上三角）设为 -inf
        att = att.masked_fill(self.bias[:, :, :T, :T] == 0, float("-inf"))

        # ⑤ Softmax：分数转权重（-inf 的位置权重变成 0）
        att = F.softmax(att, dim=-1)
        att = self.attn_dropout(att)

        # ⑥ 加权求和 V：每头各自得到一份"融合上下文"的向量（第 10 章的 O_h）
        y = att @ v                                          # (B, nh, T, hs)

        # ⑦ 拼接所有头，恢复形状 (B, T, C)——此时还只是"并排摆放"，不是最终输出
        y = y.transpose(1, 2).contiguous().view(B, T, C)

        # ⑧ 乘 W_O：把各头拼好的信息再线性融合一次，得到 Attention 模块的真正输出
        y = self.resid_dropout(self.c_proj(y))
        return y
```

对照第 10 章看这 8 步：

| 步骤        | 代码                          | 第 10 章对应               |
| ----------- | ----------------------------- | -------------------------- |
| ① 投影     | `self.c_attn(x).split(...)` | 线性投影，得到 Q/K/V       |
| ② 拆多头   | `view(...).transpose(1,2)`  | 拆分多头、合并 batch 与头  |
| ③ 缩放点积 | `q @ k.T * (1/√hs)`        | Scaled Dot-Product         |
| ④ Mask     | `masked_fill(..., -inf)`    | 第 11 章第八节 Causal Mask |
| ⑤ Softmax  | `F.softmax(att, dim=-1)`    | 分数转权重                 |
| ⑥ 加权求和 | `att @ v`                   | 各头加权和（`O_h`）      |
| ⑦ 拼接     | `transpose(1,2).view(...)`  | 多头拼接                   |
| ⑧ 输出投影 | `self.c_proj(y)`            | 乘`W_O`，得到最终 Output |

特别强调第 ⑥⑦⑧ 与第 10 章术语的关系：`att @ v` 得到的只是每头各自的加权和（`O_h`）；第 ⑦ 步拼在一起也**还不是最终输出**，只是"并排摆放"；第 ⑧ 步 `c_proj`（即 `W_O`）之后才是真正送进 `x = x + Attention(x)` 残差连接的 Output。这条线在第 10 章反复强调过，这里在代码里落到实锤。

# 六、MLP、Block 与 GPT

其余模块和第 11 章完全一致，只是变量名沿用 nanoGPT 的 `c_*` 风格：

```python
class MLP(nn.Module):
    """第 11 章的 FFN：升维 → GELU → 降维（d_ff = 4 * n_embd）"""
    def __init__(self, config):
        super().__init__()
        self.c_fc    = nn.Linear(config.n_embd, 4 * config.n_embd)
        self.gelu    = nn.GELU()
        self.c_proj  = nn.Linear(4 * config.n_embd, config.n_embd)
        self.dropout = nn.Dropout(config.dropout)

    def forward(self, x):
        return self.dropout(self.c_proj(self.gelu(self.c_fc(x))))


class Block(nn.Module):
    """第 11 章的 Transformer Block：Pre-LN + 残差，两条高速公路"""
    def __init__(self, config):
        super().__init__()
        self.ln_1 = nn.LayerNorm(config.n_embd)
        self.attn = CausalSelfAttention(config)
        self.ln_2 = nn.LayerNorm(config.n_embd)
        self.mlp = MLP(config)

    def forward(self, x):
        x = x + self.attn(self.ln_1(x))   # 先归一化 → Attention → 残差
        x = x + self.mlp(self.ln_2(x))    # 先归一化 → MLP → 残差
        return x


class GPT(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.config = config
        self.transformer = nn.ModuleDict(dict(
            wte = nn.Embedding(config.vocab_size, config.n_embd),   # Token Embedding
            wpe = nn.Embedding(config.block_size, config.n_embd),   # Position Embedding
            drop = nn.Dropout(config.dropout),
            h = nn.ModuleList([Block(config) for _ in range(config.n_layer)]),
            ln_f = nn.LayerNorm(config.n_embd),
        ))
        self.lm_head = nn.Linear(config.n_embd, config.vocab_size, bias=False)
        # 权重绑定（Weight Tying）：输入 Embedding 和输出投影共用同一份权重
        self.transformer.wte.weight = self.lm_head.weight

        # 初始化：正态分布 std=0.02（第 8 章权重初始化的具体落地）
        self.apply(self._init_weights)

    def _init_weights(self, module):
        if isinstance(module, nn.Linear):
            torch.nn.init.normal_(module.weight, mean=0.0, std=0.02)
            if module.bias is not None:
                torch.nn.init.zeros_(module.bias)
        elif isinstance(module, nn.Embedding):
            torch.nn.init.normal_(module.weight, mean=0.0, std=0.02)

    def forward(self, idx, targets=None):
        B, T = idx.size()
        pos = torch.arange(0, T, dtype=torch.long, device=idx.device)
        tok_emb = self.transformer.wte(idx)                    # (B, T, n_embd)
        pos_emb = self.transformer.wpe(pos)                    # (T, n_embd)
        x = self.transformer.drop(tok_emb + pos_emb)           # 第 11 章：Token + 位置
        for block in self.transformer.h:                       # 逐层堆叠
            x = block(x)
        x = self.transformer.ln_f(x)

        if targets is not None:                                # 训练：算全序列 Loss
            logits = self.lm_head(x)                           # (B, T, vocab_size)
            loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1))
        else:                                                  # 推理：只取最后一个位置的 logits
            logits = self.lm_head(x[:, [-1], :])
            loss = None
        return logits, loss
```

几个和第 11 章呼应的小点：

- **Pre-LN**：`Block` 里先 `ln_1` 再 `attn`，正是第 11 章第四、六节说的"先归一化再计算"的现代写法；
- **权重绑定**：`wte.weight = lm_head.weight` 让输入词表和输出词表共享参数，是 GPT-2 的一个经典技巧——省参数、还带来一点正则化；
- **Causal Mask 放在 Attention 内部**：`bias` 是注册在 `CausalSelfAttention` 上的下三角 buffer，因此 `GPT.forward` 里不用像第 11 章那样手写 `torch.triu` 掩码。

# 七、训练循环

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
model = GPT(config).to(device)
num_params = sum(p.numel() for p in model.parameters())
print(f"参数量: {num_params:,}")

# nanoGPT 的 AdamW 配置：betas=(0.9, 0.95) 是 GPT 训练的常见选择
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4, betas=(0.9, 0.95), weight_decay=0.1)

@torch.no_grad()
def estimate_loss(eval_iters=20):
    model.eval()
    out = {}
    for split in ["train", "val"]:
        losses = torch.zeros(eval_iters)
        for i in range(eval_iters):
            x, y = get_batch(split)
            x, y = x.to(device), y.to(device)
            _, loss = model(x, y)
            losses[i] = loss.item()
        out[split] = losses.mean().item()
    model.train()
    return out

for step in range(2001):                      # 包含 step 2000
    x, y = get_batch("train")
    x, y = x.to(device), y.to(device)

    _, loss = model(x, y)
    optimizer.zero_grad(set_to_none=True)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)   # 梯度裁剪（第 8 章第七节）
    optimizer.step()

    if step % 200 == 0:   # 每 200 步验证一次：1 步 = 处理 1 个 batch、更新一次参数
        est = estimate_loss()
        print(f"step {step:4d}: train loss {est['train']:.3f}, val loss {est['val']:.3f}")
```

> nanoGPT 原版的 `train.py` 还有 **学习率调度（warmup + cosine decay）**、梯度累积、混合精度等工程手段；这里为了把主线讲清楚做了简化（固定 `lr=3e-4`）。第 8 章已讲过学习率调度与 AdamW 的细节，可自行把这些手段加回去。

初始 Loss 约 `log(50257) ≈ 10.8`（模型随机瞎猜时的量级），2000 步后训练 Loss 降到 `3` 出头，模型明显学到了莎士比亚的语言模式。

# 八、生成文字

训练完成后，用自回归采样续写。这里是 **Sampling（按概率抽样）**，并加入了 **Temperature**（第 1 章讲过这两个解码策略）：

```python
@torch.no_grad()
def generate(model, prompt, max_new_tokens=200, temperature=0.8):
    model.eval()
    idx = torch.tensor([enc.encode(prompt)], device=device)
    for _ in range(max_new_tokens):
        idx_cond = idx[:, -block_size:]                     # 只保留最后 block_size 个 token
        logits, _ = model(idx_cond)
        logits = logits[:, -1, :] / temperature             # Temperature：除以 T 再 softmax
        probs = F.softmax(logits, dim=-1)
        next_id = torch.multinomial(probs, num_samples=1)   # 按概率抽样
        idx = torch.cat([idx, next_id], dim=1)
    return enc.decode(idx[0].tolist())

print(generate(model, "ROMEO:"))
```

- `temperature < 1` 让分布更尖锐、更接近 Greedy（输出稳定但容易重复）；
- `temperature > 1` 让分布更平坦、更随机（输出多样但可能不通顺）。

# 十、这和真正的 GPT 差多少？

|           | nanoGPT（本节）         | GPT-2 Small     | GPT-3                |
| --------- | ----------------------- | --------------- | -------------------- |
| 参数量    | 约 700 万               | 1.24 亿         | 1750 亿              |
| 层数      | 4                       | 12              | 96                   |
| 训练数据  | tiny-shakespeare 约 1MB | WebText 约 40GB | 约 3000 亿训练 Token |
| Tokenizer | BPE（tiktoken gpt2）    | BPE             | BPE                  |

它们共享同一套 Decoder-only、自回归 Next Token Prediction 的骨架——**代码结构几乎一样，差别只在规模和训练工程**。nanoGPT 原版把配置一改（`n_layer=12, n_head=12, n_embd=768`）就是 GPT-2 的架构；再往上堆，就是今天 GPT 家族的方向。真实 GPT 还涉及数据清洗与配比、分布式训练、混合精度与稳定性工程；现代 LLM 又常使用 RoPE、RMSNorm、SwiGLU、GQA 等改动（第 12 章展开）。
