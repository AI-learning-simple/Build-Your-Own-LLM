# 二、数据：Wikitext-103(为什么是它？)

- **Wikitext-103**(Salesforce 发布)：**1.03 亿 token** 的维基百科语料,语言模型领域最权威的标准基准之一;
- 对比我们第 1~3 章用过的微型语料：13 万词的小说只能学到"man↔woman"这种粗粒度关系,而 1000 万 token 的维基百科能学到 `king → throne, reign, prince, monarch` 这样精细的语义;
- 本节默认取前 **1000 万 token**(约 1 分钟训练);想跑全量 8300 万,改一个数字即可;

> **教学点(呼应第 1 章 Zipf 定律)**：词表只要 15000 个高频词,就覆盖了文本的 92.9%——剩下 7% 是只出现一两次的生僻词,全部归入 `<UNK>`。这正是第 2 章"词表大小 vs 覆盖率"的权衡在真实数据上的体现。

# 三、核心思想：共现矩阵 + PPMI + SVD

## 3.1 共现矩阵(第 1 章 Bigram 的推广)

第 1 章我们统计"`the` 后面跟什么词";这里统计更一般的关系：**窗口内任意两个词共同出现的次数**。`M[i][j]` = 词 i 和词 j 在上下文中共同出现的次数。这就是把第 1 章的"相邻共现"推广成"窗口共现"。

## 3.2 PPMI：过滤"都在出现的词"

直接拿共现次数做矩阵分解有个问题：`the`、`of` 和所有词都共现,噪声极大。**PPMI(正点互信息)** 做了一次"去重"：如果两个词的共现次数和它们各自的出现频率匹配(甚至是巧合),就压到 0;只有"显著多于巧合"的共现才保留正值。

## 3.3 SVD：从共现统计到词向量

**SVD(奇异值分解)** 把 15000 × 15000 的 PPMI 矩阵分解,取前 100 个奇异向量,就得到 15000 × 100 的词向量矩阵——**这就是第 3 章那张 Embedding Matrix 的真实版**。每一行是一个词的 100 维向量,而"语义"就藏在向量的方向里。

> **工程点(真实世界的做法)**：15000 × 15000 矩阵有 2.25 亿个格子,但 99% 是 0。真实世界用**稀疏矩阵**只存非零元素(本数据 1330 万个),SVD 也用稀疏版本——全量稠密 SVD 要 10 分钟,稀疏 SVD 只要 10 秒。

```python
import re
import numpy as np
from collections import Counter
from scipy.sparse import coo_matrix
from scipy.sparse.linalg import svds

# ---- 数据:Wikitext-103 前 1000 万 token(正则分词,第2章的知识) ----
raw = open("/tmp/wikitext103_train.txt", encoding="utf-8").read()
tokens = re.findall(r"[a-z]+", raw.lower())[:10_000_000]

# ---- 词表(第2章:高频词 + <UNK>) ----
freq = Counter(tokens)
VOCAB = 15000
vocab = [w for w, _ in freq.most_common(VOCAB)]
word2id = {w: i for i, w in enumerate(vocab)}
V = len(vocab)
ids = np.array([word2id.get(w, -1) for w in tokens], dtype=np.int64)

# ---- 共现矩阵(窗口 5,稀疏存储) ----
WINDOW = 5
n = len(ids)
offs = np.arange(-WINDOW, WINDOW+1)
offs = offs[offs != 0]
rows, cols, vals = [], [], []
for start in range(0, n, 2_000_000):          # 分批构造,控制内存
    end = min(n, start + 2_000_000)
    lo, hi = max(start, WINDOW), min(end, n - WINDOW)
    if lo >= hi:
        continue
    i_ar = np.arange(lo, hi)
    J = (i_ar[:, None] + offs[None, :]).ravel()
    I = np.repeat(i_ar, 2*WINDOW)
    m = (J >= 0) & (J < n)
    c, x = ids[I[m]], ids[J[m]]
    m2 = (c != -1) & (x != -1)
    rows.append(c[m2]); cols.append(x[m2]); vals.append(np.ones(m2.sum()))
M = coo_matrix((np.concatenate(vals), (np.concatenate(rows), np.concatenate(cols))),
               shape=(V, V)).tocsr()

# ---- PPMI + 稀疏 SVD ----
row_sum = np.asarray(M.sum(axis=1)).ravel()
col_sum = np.asarray(M.sum(axis=0)).ravel()
total = M.sum()
Mcoo = M.tocoo()
with np.errstate(divide="ignore"):
    ppmi = np.maximum(np.log(Mcoo.data * total / (row_sum[Mcoo.row] * col_sum[Mcoo.col] + 1e-9)), 0)
PPMI = coo_matrix((ppmi, (Mcoo.row, Mcoo.col)), shape=(V, V)).tocsr()
U, S, Vt = svds(PPMI, k=100)
order = np.argsort(S)[::-1]
E = U[:, order] * np.sqrt(S[order])          # (15000, 100) 词向量矩阵!
```

# 四、验证：语义空间真的出现了

## 4.1 相似词(第 3 章"语义空间"的直接验证)

```python
def cosine(a, b):
    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-9))

for w in ["king", "queen", "computer", "music"]:
    v = E[word2id[w]]
    sims = sorted(((vocab[i], cosine(v, E[i])) for i in range(V) if i != word2id[w]),
                  key=lambda x: -x[1])[:4]
    print(w, "->", ", ".join(f"{x}({s:.2f})" for x, s in sims))
```

真实运行结果：

```text
king     -> throne(0.79), reign(0.74), ii(0.73), prince(0.71)
queen    -> prince(0.76), princess(0.73), duchess(0.73), elizabeth(0.66)
computer -> computers(0.82), interface(0.81), software(0.80), graphics(0.75)
music    -> musical(0.84), songs(0.82), pop(0.78), album(0.78)
```

模型从没见过"王权""科技"这些概念,它只见过这些词**出现的上下文**——但它们聚在了一起。这就是第 3 章 Distributional Hypothesis(分布式假设)的活生生证明。

## 4.2 类比推理：语义空间里的向量运算

```text
king - man + woman  ->  throne(0.781), heir(0.738), queen(0.726)
father - man + woman ->  mother(0.882)
```

**词向量的加减法,对应着语义的加减法**——这是第 3 章"语义空间几何直觉"最漂亮的验证。模型没有"性别"概念,但它在数据里发现:king 和 queen 的向量差,恰好和 man 与 woman 的向量差方向一致。

## 4.3 聚类指标：数字证明"同类更近"

```text
同类词平均相似度 0.625 vs 异类词平均相似度 0.097 → 差异 +0.528
```

# 五、可视化：语义空间长什么样(第 3 章的几何直觉)

100 维向量没法直接画,用 **PCA 降到 2 维**(手写 PCA:中心化 → 协方差 → 特征分解,不需要 sklearn):

```python
def pca(X, k=2):
    Xc = X - X.mean(axis=0)
    cov = Xc.T @ Xc / len(X)
    w, v = np.linalg.eigh(cov)
    order = np.argsort(w)[::-1][:k]
    return Xc @ v[:, order]
```

选三组语义相关的词(王室/科技/音乐)画散点图,同类用同色——**同类词在图上自动聚成一团**:

```text
组内平均相似度 0.661 vs 跨组平均相似度 0.042 → 差异 +0.618
```

图片保存在 `~/embedding_project/embedding_groups.png`(脚本 `visualize_embedding.py`)。

> **Insight:为什么 PCA 用协方差特征分解?** 降维的本质是"找数据方差最大的方向"——协方差矩阵的特征向量就是这些方向,特征值越大,该方向保留的信息越多。取前 2 个特征向量,就是把词向量投影到"信息最多的平面上"。

# 六、对比路线:为什么不用 Word2Vec(第 6 章知识的应用)

作为对比,脚本里还实现了一条**神经网络路线**——CBOW + 负采样(第 3.3 节讲过的 Word2Vec 思想):

```text
CBOW + 负采样,3000 步:loss 1.3865 → 1.3863(几乎没动)
相似词:man -> surviving(0.38), stages(0.38), adopting(0.37)(无意义)
```

同一份 1000 万 token 语料,神经网络路线几乎学不动——**这是"数据饥饿"的真实体验**:Word2Vec 式方法需要亿级 token + 大训练量,而 SVD 路线一次性消化全部共现统计(全局),千万级就能出语义。这正好呼应第 6 章的结论:**数据量 × 训练量,是神经网络路线的命门;而统计路线的上限,则是词表与窗口的选择**。
