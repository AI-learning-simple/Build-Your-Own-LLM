# 8.3 为什么需要 Softmax？——从分数到注意力权重

上一节，我们学会了用 Dot Product 计算 Attention Score，算出 `cat` 对 `The cat is sleeping` 每个词的分数：`[0.0, 1.25, -0.05, 1.2]`。这些分数可以直接使用吗？答案是不能。

---

# 三个问题

**问题一：数字没有范围。** 不同句子的 Score 可能是 `8.3, 5.1` 也可能是 `120, 95, 40`，没有任何统一范围，模型越来越难训练。

**问题二：不能直接解释为分配比例。** 原始 Score 可以为负，也不保证总和为 1；我们需要把同一个 Query 对各个 Key 的分数转换为一组非负、和为 1 的权重。

**问题三：点积分数可能随维度变大。** 当 Query、Key 的各维方差相近时，点积的典型幅度会随 `d_k` 增长，使 Softmax 过早饱和、梯度变小。Scaled Dot-Product Attention 因此先除以 `√d_k`：`softmax(QKᵀ/√d_k)`。注意，Softmax 对整体缩放并不保持比例不变；把 `[8,4,2]` 乘 10 会得到更尖锐的分布。

---

# 一个直接的想法：归一化

把分数变成百分比会不会好一点？`8,4,2 → 57%,29%,14%`，现在立刻知道模型主要关注谁：

```python
scores = [8, 4, 2]
total = sum(scores)
weights = [s / total for s in scores]
print(weights)  # [0.57, 0.29, 0.14]
```

所有数字都在 0~1，加起来等于 1，已经很像概率。但如果 Score 里出现负数，例如 `[-5, 3, 10]`，直接除以总和会出现**负权重**——Attention 不能出现负关注。

---

# 我们需要一种新函数

它必须满足：①所有结果 > 0；②所有结果加起来 = 1；③大的分数应该变得更大，小的分数应该变得更小。这就是 **Softmax**。

---

# Softmax 做了什么？

第一步，把所有分数变成指数（`e^x`），指数永远大于 0，因此不会再出现负权重；第二步，做归一化。为延续前面的二维教学例子，下面暂时直接对 8.2 节的未缩放分数 `[0.0, 1.25, -0.05, 1.2]` 做 Softmax；完整 Transformer 会先除以 `√d_k`，8.7 节将使用完整公式：

```python
import numpy as np

scores = np.array([0.0, 1.25, -0.05, 1.2])  # The, cat, is, sleeping（来自 8.3 节）
exp = np.exp(scores - np.max(scores))        # 减去最大值，数值更稳定
weights = exp / np.sum(exp)
print(np.round(weights, 3))  # [0.114 0.398 0.109 0.379]
```

结果：`The11.4%, cat 39.8%, is 10.9%, sleeping 37.9%`——`cat` 主要关注自己和`sleeping`（合计约 78%），几乎不理会 `The` 和 `is` 这两个功能词。这组权重 `[0.114, 0.398, 0.109, 0.379]`，我们会在 8.4 节继续用来做 Weighted Sum。

---

# 本节总结

本节，我们完成了 `Attention Score → Attention Weight` 的转换：✅ 为什么不能直接使用 Dot Product ✅ 为什么需要归一化 ✅ 为什么普通归一化还不够 ✅ Softmax 如何把任意分数变成注意力权重。
