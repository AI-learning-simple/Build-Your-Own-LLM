# 实验 1.1：Character Bigram Language Model

> **实验目标**
>
> 本实验实现一个最小 Character Bigram Language Model。它不使用神经网络，只通过相邻字符计数完成两项任务：
>
> **Predict Next Character（预测下一个字符）**
>
> 虽然它非常简单，但后面所有 GPT 都是在这个模型基础上的不断演进。

---

# 一、准备数据

为了方便观察，我们先使用一段极小的数据：

```python
text = "hello world"
```

为什么不用几百万文本？因为第一章的目标不是训练一个好模型，而是理解**Language Model 到底在做什么**，数据越小越容易观察。

---

# 二、观察数据

把所有字符打印出来：

```python
for ch in text:
    print(ch)
```

对于第一章来说，**Language Model 根本不知道什么是单词**，它看到的只是一串字符：`h → e → l → l → o → ...`。所以第一章实际上训练的是 **Character Language Model**，而不是 Word Language Model。第二章我们才会升级到 Tokenizer。

---

# 三、Bigram 是什么？

Bigram 就是**利用当前一个字符，预测下一个字符**。例如 `hello` 里面包含：

| Current | Next |
|----------|------|
| h | e |
| e | l |
| l | l |
| l | o |

如果输入 `h`，模型应该预测 `e`；如果输入 `e`，模型预测 `l`。整个模型只有这一条规则。

---

# 四、统计所有 Bigram

下面开始真正训练模型：

```python
text = "hello world"
model = {}

for i in range(len(text) - 1):
    current = text[i]
    nxt = text[i + 1]
    if current not in model:
        model[current] = []
    model[current].append(nxt)

print(model)
```

运行结果：

```
{'h':['e'],'e':['l'],'l':['l','o','d'],'o':[' ','r'],' ':['w'],'w':['o'],'r':['l']}
```

至此，我们得到了一张字符 Bigram 频次表。这里的“训练”只是从语料中计数，不涉及梯度下降。

---

# 五、理解训练结果

很多同学第一次看到 `'l':['l','o','d']` 都会疑惑：为什么 `l` 后面有三个结果？观察原文 `hello world` 可以找到三次出现：`l→l`、`l→o`、`l→d`。这个列表保存了每次观测；如果某个后继重复出现，它也会重复写入列表。因此，后面的 `random.choice()` 实际会按经验频率采样，只是本节还没有显式计算和展示概率。

---

# 六、生成文本

增加一个生成函数：

```python
import random

def generate(start, max_length=20):
    result = start
    current = start
    for _ in range(max_length):
        if current not in model:
            break
        nxt = random.choice(model[current])
        result += nxt
        current = nxt
    return result
```

运行 `print(generate("h"))`，可能得到 `hello world`，再次运行可能得到 `hello worlllo`。为什么每次都不一样？因为 `l` 后面有 `l`、`o`、`d` 三种可能，模型不知道应该选择哪一个，于是随机选择。

这里使用 `random.choice()` 从包含重复观测的列表中采样，因此频繁出现的后继会被更常选中。更一般的采样策略会在第 6.3 节讨论。

---

# 七、完整代码

```python
import random

text = "hello world"
model = {}

for i in range(len(text) - 1):
    current = text[i]
    nxt = text[i + 1]
    if current not in model:
        model[current] = []
    model[current].append(nxt)


def generate(start, max_length=20):
    result = start
    current = start
    for _ in range(max_length):
        if current not in model:
            break
        nxt = random.choice(model[current])
        result += nxt
        current = nxt
    return result


print(generate("h"))
```

总代码**不到 40 行**，但已经能够生成文本。

---

# 八、运行结果

多次运行的结果都是正常现象，例如：`hello world`、`hello worllo`、`hello worldllo` 等。

---

# 九、为什么它叫 Language Model？

重新观察整个程序，训练阶段它没有理解英文、学习语法、学习单词、学习知识，它只是统计"当前字符 → 下一字符"；推理阶段根据统计结果预测 Next Character。这就是 Language Model。因此：

> **从训练目标看，这个 Bigram 模型学习的是相邻字符的条件统计；它是否构成“理解”不是本实验能够回答的问题。**

---

# 十、本实验的局限性

虽然我们的模型已经能够生成文本，但存在很多问题。例如 `I love AI` 中，它只能看到 `A → I`，却不知道 `I love` 这个整体——它一次只能看到一个字符。这种模型叫 **Bigram Language Model**。

下一节，我们会把隐含在重复观测中的经验频率显式整理成 **Probability Distribution（概率分布）**，例如在某段字符语料中得到 `P("l" | "l") = 60%`、`P("o" | "l") = 40%`。
