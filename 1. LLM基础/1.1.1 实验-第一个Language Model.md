### 三、真正的数据结构

以 Python 字典为例：

```python
{
    "h":["e"],
    "e":["l"],
    "l":["l","o","d"],
    "o":[" ","r"],
    "r":["l"]
}
```

什么意思？

例如l，后面出现过"l"，也出现过"o"和"d"，以后随机选一个，就能生成文字。

---

这就是：

Character Bigram Model。

以后模型会不断升级,但是思想没有变。

### 四、完整代码

下面代码建议自己敲。

```python
import random

text = "hello world"

model = {}

for i in range(len(text)-1):

    current = text[i]

    nxt = text[i+1]

    if current not in model:
        model[current] = []

    model[current].append(nxt)


def generate(start, length=20):

    result = start

    current = start

    for _ in range(length):

        if current not in model:
            break

        nxt = random.choice(model[current])

        result += nxt

        current = nxt

    return result


print(generate("h"))
print(generate("w"))
```

---

运行可能得到：

```text
hello world

```

再次运行：

```text
hello worllo worl
```

或者：

```text
hello worldllo wo
```

为什么会这样？因为这里：

```python
random.choice()
```

每次都是随机选择。

### 七、这一章真正想让你理解什么？

到这里，请不要急着进入 Transformer。

先停下来，确认自己已经真正理解了下面四句话：

1. **语言模型不是在"记住答案"，而是在学习"下一个元素出现的概率"。**
2. **生成文本不是一次输出整句话，而是一次生成一个 Token（这里是字符）。**
3. **训练的本质，就是从大量文本中统计"前文 → 后文"的规律。**
4. **Transformer 并没有改变这个目标，它只是让模型能够学习更加复杂、更长距离的统计规律。**
