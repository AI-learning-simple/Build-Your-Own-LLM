# 10.8 Attention 可视化——注意力权重的分布与解释

上一节，我们知道 Self-Attention 最终会得到一个 Attention Matrix。但如果全部都是数字，其实很难理解模型到底在关注什么。因此研究人员通常会把它画成**热力图（Heatmap）**。

---

# Attention Heatmap

颜色越深，表示 Attention Weight 越大；颜色越浅，表示权重越小。继续用本章 `The cat is sleeping` 的教学例子：`cat` 这一行对自己和 `sleeping` 的权重较大。这里的矩阵来自人工指定的二维向量，并没有经过训练，因此它只能演示“如何读取热力图”，不能据此声称模型学到了语法或语义关系。

在真实的已训练模型中，某些 Head 可能对依存关系、相邻位置或标点呈现统计上的偏好，但需要在大量样本上验证，不能凭单张图下结论。

---

# Experiment 10.8：自己画一张 Heatmap

```python
import matplotlib.pyplot as plt
import numpy as np

attention = np.array([
    [0.259, 0.250, 0.245, 0.245],
    [0.149, 0.360, 0.144, 0.348],
    [0.249, 0.245, 0.258, 0.249],
    [0.149, 0.355, 0.149, 0.348],
])  # 来自 10.7 节 Scaled Dot-Product 教学矩阵
tokens = ["The", "cat", "is", "sleeping"]

plt.imshow(attention)
plt.xticks(range(4), tokens)
plt.yticks(range(4), tokens)
plt.colorbar()
plt.show()
```

运行后会得到一张真正的 Attention Heatmap，`cat` 和 `sleeping` 所在的格子会明显更深，`The`、`is` 那两行则接近均匀的浅色。

---

# 一个有趣的发现

研究人员观察 GPT、BERT 等已训练模型时，确实发现不同 Head 的热图可能呈现不同偏好，例如更常指向相邻词、标点或某类依存位置。不过这种模式通常不是“一 Head 固定对应一种语言关系”，而且 Attention Weight 也不等同于完整的因果解释；严谨分析需要跨样本统计，并结合消融等方法。

---

# 本节总结

本节把 Attention Weight 矩阵画成热图，观察了每个 Query 行如何在各 Key 上分配权重，并说明了解读时的边界：权重分布只是模型计算过程的记录，不等于因果解释。
