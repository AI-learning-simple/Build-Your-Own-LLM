```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "Qwen/Qwen2.5-1.5B-Instruct"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, device_map="auto")

def ask(prompt, temperature=0.0, max_new_tokens=300):
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    if temperature > 0:
        output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=True, temperature=temperature)
    else:
        output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=False)
    return tokenizer.decode(output[0][inputs["input_ids"].shape[1]:], skip_special_tokens=True)
```

# 三、统一答案提取与评分

三种方法必须使用同一个评分函数。Prompt 统一要求模型在单独一行输出 `FINAL: 数字`，解析器只接受该字段；缺失、重复或格式错误直接计错。这样不会把推理过程中的中间数字误当成最终答案。

```python
import math
import re
from collections import Counter


FINAL_PATTERN = re.compile(
    r"(?im)^\s*FINAL:\s*([-+]?(?:\d+(?:\.\d*)?|\.\d+))\s*$"
)


def extract_number(text):
    matches = FINAL_PATTERN.findall(text.replace(",", ""))
    return float(matches[0]) if len(matches) == 1 else None


def is_correct(predicted, expected):
    return predicted is not None and math.isclose(
        predicted, expected, rel_tol=1e-2, abs_tol=5e-2
    )


def accuracy(predictions):
    hits = [is_correct(pred, p["expected"]) for pred, p in zip(predictions, problems)]
    return sum(hits) / len(hits)
```

# 四、方式一与方式二：Direct / Chain of Thought

```python
direct_prompt_template = "{q}\n不要解释，只输出一行：FINAL: <数字>"
cot_prompt_template = (
    "{q}\n请逐步计算，并在最后单独输出一行：FINAL: <数字>"
)


def run_single_pass(template):
    predictions = []
    for p in problems:
        raw = ask(template.format(q=p["q"]), temperature=0.0)
        predicted = extract_number(raw)
        predictions.append(predicted)
        print(p["q"], "| 抽取答案:", predicted, "| 正确答案:", p["expected"])
    return predictions


direct_predictions = run_single_pass(direct_prompt_template)
cot_predictions = run_single_pass(cot_prompt_template)
```

Direct 与 CoT 都只调用模型一次，但 CoT 往往生成更多 Token，因此实际解码时间和计算量通常更高。它是否提高准确率要由本次统计决定，不能从提示语本身推出。

# 五、方式三：Self-Consistency 多路径投票

对每道题以同一 CoT Prompt 独立采样多次，再对成功解析的 `FINAL:` 数值投票。浮点答案先四舍五入，避免 `14.2857` 和 `14.286` 被当成两个类别：

```python
def self_consistency(prompt, num_samples=5):
    answers = []
    for _ in range(num_samples):
        raw = ask(prompt, temperature=0.7)
        predicted = extract_number(raw)
        if predicted is not None:
            answers.append(round(predicted, 3))
    if not answers:
        return None
    return Counter(answers).most_common(1)[0][0]


sc_predictions = []
for p in problems:
    voted = self_consistency(cot_prompt_template.format(q=p["q"]), num_samples=5)
    sc_predictions.append(voted)
    print(p["q"], "| 投票答案:", voted, "| 正确答案:", p["expected"])
```

Self-Consistency 增加的是推理阶段的采样与聚合计算，不改变模型参数。多数投票只有在不同路径的错误不完全相关、且正确答案具有足够票数时才可能受益；并不保证优于单次解码。

# 六、真正统计三种方式

```python
scores = {
    "Direct": accuracy(direct_predictions),
    "CoT": accuracy(cot_predictions),
    "Self-Consistency (5 samples)": accuracy(sc_predictions),
}
for method, score in scores.items():
    print(f"{method:28s}: {score:.1%} ({round(score * len(problems))}/{len(problems)})")
```

这 5 道简单题只用于走通评测代码，不能支持“CoT 或 Self-Consistency 普遍更好”的统计结论。更可靠的实验需要更多题目、固定采样随机种子、报告多次运行的均值与方差，并同时记录输出 Token 数、延迟或 FLOPs。
