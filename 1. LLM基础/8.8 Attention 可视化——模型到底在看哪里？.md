# 8.8 Attention可视化——模型到底在看哪里？

上一节，我们知道 Self-Attention 最终会得到一个 Attention Matrix。但如果全部都是数字，其实很难理解模型到底在关注什么。因此研究人员通常会把它画成**热力图（Heatmap）**。

---

# Attention Heatmap

颜色越深，表示 Attention Weight 越大；颜色越浅，表示模型几乎没有关注。继续用本章 `The cat is sleeping` 这个例子：观察 `cat` 这一行，模型最关注自己，其次关注 `sleeping`，说明模型认为 `cat` 和 `sleeping` 之间存在较强关联；而 `The`、`is` 这两行几乎是均匀的浅色，说明模型没有找到明显的关注对象。

再看一句话 `The boy kicked the ball.`：观察 `ball` 这一行，你会发现它可能主要关注 `kicked`——因为"球"和"踢"关系最强，模型自动学到了动作关系。

---

# Experiment 8.8：自己画一张 Heatmap

```python
import matplotlib.pyplot as plt
import numpy as np

attention = np.array([
    [0.263, 0.251, 0.243, 0.243],
    [0.114, 0.398, 0.109, 0.379],
    [0.248, 0.243, 0.261, 0.248],
    [0.114, 0.391, 0.114, 0.380],
])  # 来自 8.7 节算出的真实矩阵
tokens = ["The", "cat", "is", "sleeping"]

plt.imshow(attention)
plt.xticks(range(4), tokens)
plt.yticks(range(4), tokens)
plt.colorbar()
plt.show()
```

运行后会得到一张真正的 Attention Heatmap，`cat` 和 `sleeping` 所在的格子会明显更深，`The`、`is` 那两行则接近均匀的浅色。

---

# 一个有趣的发现

研究人员训练完 GPT、BERT 等模型后观察 Attention Heatmap，发现不同 Head 画出来的图完全不同：有的 Head 专门关注主语（`boy → kicked`），有的专门关注宾语（`kicked → ball`），还有一些专门关注标点符号，甚至句子的开始。这些现象都不是人为设计的，而是模型自己学出来的。

# 一个问题

如果一个 Head 只能学习一种关注方式（例如只学主谓关系），那另一种关系（例如时间关系）怎么办？是不是可以同时训练多个不同的 Attention？答案是当然可以。于是 Transformer 提出了**Multi-Head Attention（多头注意力）**。
