# 实验 1.2：让 Bigram 输出概率分布

> **实验目标**
>
> 上一节的重复列表已经隐含了经验频率，但没有显式计算或展示每个候选字符的概率。本实验将频次整理成条件概率分布。

---

# 一、为什么需要概率？

观察字符 `l` 的后继。假设训练语料中 `l→l` 出现 600 次，`l→o` 出现 400 次。给定当前字符 `l`，下一个字符不是唯一确定的，而可用经验条件概率表示：

| Next Character | Probability |
|----------------|------------:|
| `l` | 60% |
| `o` | 40% |

概率来自计数归一化：某个后继的次数除以所有后继的总次数。

---

# 二、统计出现次数（Frequency）

上一节的模型保存的是列表结构 `{'l':['l','o','d']}`，这种结构不方便统计次数。现在修改成字典结构：

```python
{'l':{'l':1,'o':1,'d':1}}
```

这样每一种下一个字符都有自己的计数。

---

# 三、修改训练代码

把上一节的 `model[current].append(next)` 修改为：

```python
if current not in model:
    model[current] = {}
if nxt not in model[current]:
    model[current][nxt] = 0
model[current][nxt] += 1
```

运行后不再保存列表，而是保存**出现次数**：

```
{'h':{'e':1},'e':{'l':1},'l':{'l':1,'o':1,'d':1},'o':{' ':1,'r':1}, ...}
```

---

# 四、计算概率

例如 `l` 对应 `{'l':1,'o':1,'d':1}`，总次数为 3，因此 `P(l|l)=1/3`，`P(o|l)=1/3`，`P(d|l)=1/3`。

如果训练数据改成 `helllllllo world`，那么 `l` 对应 `{'l':6,'o':1,'d':1}`，概率变为：

| Next | Probability |
|------|------------:|
| l | 75% |
| o | 12.5% |
| d | 12.5% |

这个过程说明了如何从计数得到条件概率；现代神经语言模型也输出条件分布，但计算方式和上下文表示远比这里复杂。

---

# 五、新增 predict() 函数

```python
def predict(current):
    if current not in model:
        print(f"未观察到字符 {current!r}，没有可用的后继分布。")
        return {}
    table = model[current]
    total = sum(table.values())
    print(f"\nCurrent: {current}")
    print("-"*25)
    for nxt, count in sorted(table.items(), key=lambda x: -x[1]):
        prob = count / total
        print(f"{nxt:<5} {prob:.2%}")
```

运行 `predict("l")` 输出：

```
Current: l
-------------------------
l      33.33%
o      33.33%
d      33.33%
```

运行 `predict("o")` 输出 `(space) 50%`、`r 50%`，这就是由观察频数归一化得到的 **Probability Distribution（概率分布）**。本例只给已观察后继分配概率，未见转移的概率视为 0；实际统计语言模型常使用平滑方法，避免未见事件被永久判为 0。

---

# 六、完整代码

```python
#!/usr/bin/env python3
text = "hello world"
model = {}

for i in range(len(text)-1):
    current = text[i]
    nxt = text[i+1]
    if current not in model:
        model[current] = {}
    if nxt not in model[current]:
        model[current][nxt] = 0
    model[current][nxt] += 1


def predict(current):
    if current not in model:
        print(f"未观察到字符 {current!r}，没有可用的后继分布。")
        return {}
    table = model[current]
    total = sum(table.values())
    print(f"\nCurrent: {current}")
    print("-"*25)
    for nxt, count in sorted(table.items(), key=lambda x: -x[1]):
        print(f"{repr(nxt):<8}{count/total:.2%}")


predict("l")
predict("o")
```

# 八、实验总结

相比实验 1.1，本节把重复列表改成显式频数表，并将频数归一化为条件概率。这个 Character Bigram 仍只使用一个字符的上下文；现代神经语言模型同样输出 Token 条件分布，但使用可学习向量和神经网络计算。

下一章开始构建 **Tokenizer**。第一章人为把单个字符直接当作 Token；主流 GPT 类模型通常先通过子词或字节级 Tokenizer，把文本转换成 Token ID，再送入模型。
