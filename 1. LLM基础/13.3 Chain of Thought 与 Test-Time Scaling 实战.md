# 13.3 Chain of Thought 与 Test-Time Scaling 实战

> **本节目标**：第13章讲了 Chain of Thought（一步步思考提升推理能力）和 Test-Time Scaling（推理阶段多想几遍，效果更好）。本节，我们用同一个模型、同一道数学题，对比"直接回答"、"思维链"、"多路径投票"三种方式的准确率差异，亲手验证这两个结论。
>
> **硬件要求**：纯推理任务，用 1.5B~3B 模型即可，**显存占用不到 3GB，8GB 显卡完全足够，甚至可以同时多开几个采样进程**。

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "Qwen/Qwen2.5-1.5B-Instruct"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, device_map="auto")

def ask(prompt, temperature=0.0, max_new_tokens=300):
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    if temperature > 0:
        output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=True, temperature=temperature)
    else:
        output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=False)
    return tokenizer.decode(output[0][inputs["input_ids"].shape[1]:], skip_special_tokens=True)
```

# 二、准备一批带标准答案的数学题

选一批需要多步计算的应用题，人工写好正确答案，方便统计准确率：

```python
problems = [
    {"q": "一个水池，甲管每小时注水20升，乙管每小时注水15升，同时打开两管，多少小时能注满500升的水池？", "answer": "500/(20+15)"},
    {"q": "小张买了3本书，每本25元，又买了2支笔，每支3元，一共花了多少钱？", "answer": "3*25+2*3"},
    {"q": "一列火车速度是80公里/小时，行驶了2.5小时，请问行驶了多少公里？", "answer": "80*2.5"},
    {"q": "某商品原价200元，先打8折，再降价10元，最终售价是多少？", "answer": "200*0.8-10"},
    {"q": "一个班有45名学生，其中3/5是男生，请问女生有多少人？", "answer": "45*(2/5)"},
]

for p in problems:
    p["expected"] = eval(p["answer"])
    print(p["q"], "-> 正确答案:", p["expected"])
```

# 三、方式一：直接回答（Baseline）

```python
direct_prompt_template = "{q} 请直接给出最终数字答案,不要解释过程。"

correct_direct = 0
for p in problems:
    result = ask(direct_prompt_template.format(q=p["q"]))
    print(p["q"], "-> 模型答案:", result)
```

人工核对每一题的输出是否接近 `p["expected"]`（考虑到模型可能输出的格式不完全一致，需要人工判断或写一个简单的数字提取函数）。

# 四、方式二：Chain of Thought（一步一步思考）

```python
cot_prompt_template = "{q} 请一步一步思考,写出计算过程,最后给出答案。"

for p in problems:
    result = ask(cot_prompt_template.format(q=p["q"]))
    print(p["q"], "\n模型回答:\n", result, "\n---")
```

对比第三步的结果，通常会发现：**加上"一步一步思考"后，模型更容易把复杂问题拆解成正确的中间步骤，最终答案的准确率明显提升**——尤其是在题目本身包含多个运算步骤（先乘除、再加减）时，效果差异会更明显。

# 五、方式三：Test-Time Scaling（多路径采样投票）

对同一道题，用较高的 `temperature` 采样多次，然后对最终答案做"多数投票"（Self-Consistency）：

```python
from collections import Counter
import re

def extract_number(text):
    matches = re.findall(r"[-+]?\d+\.?\d*", text.replace(",", ""))
    return matches[-1] if matches else None

def self_consistency(prompt, num_samples=5):
  answers = []
  for _ in range(num_samples):
    result = ask(prompt, temperature=0.7)
    num = extract_number(result)
    if num:
      answers.append(num)
  if not answers:
    return None
  return Counter(answers).most_common(1)[0][0]

for p in problems:
    voted = self_consistency(cot_prompt_template.format(q=p["q"]), num_samples=5)
    print(p["q"], "-> 多数投票结果:", voted, "| 正确答案:", p["expected"])
```

多次采样、独立思考、再投票，通常比单次采样更稳定——这正是第13章讲的 **Test-Time Scaling**：不增加模型参数，只增加推理阶段的计算量，换取更高的准确率。

# 六、三种方式的效果对比表（示例）

实际跑完后，把三种方式在这 5 道题上的准确率填进表格，你会得到类似这样的趋势（具体数字因模型和题目难度而异）：

| 方式 | 准确率（示例） | 额外计算成本 |
|---|---|---|
| 直接回答 | 40% | 1× |
| Chain of Thought | 70% | 1×（但输出更长） |
| Self-Consistency（5次投票） | 85% | 5× |

**代价与收益是成对出现的**：CoT 几乎不增加计算成本就能提升准确率；Self-Consistency 效果更好，但要多花 5 倍的推理算力——这正是第13章反复强调的核心权衡：**Test-Time Scaling 用更多计算换更好的答案，而不是免费的午餐。**
