# 5.2 实现 N-Gram 语言模型

> **实验目标**
>
> 把 `(Context, Target)` 样本汇总成 N-Gram 统计表，并用计数计算 $P(\text{Target}\mid\text{Context})$。你还将亲手观察未见 Context 如何暴露统计式模型的数据稀疏性。

开始前，请先完成 [实验 5.1：构建 N-Gram 数据集](./5.1%20构建%20N-Gram%20数据集.md)。Context Window、N-Gram、条件概率和数据稀疏性的概念均已在 [第5章：固定上下文与 N-Gram 语言模型](./5.%20固定上下文与%20N-Gram%20语言模型.md) 中说明。

---

# 一、从样本到统计表

使用三句话作为语料：

```text
I love AI
I love Python
I like AI
```

令 Context Window 为 2，可以得到三条样本：

```text
[I, love] -> AI
[I, love] -> Python
[I, like] -> AI
```

把相同 Context 的 Target 次数放到同一组，便得到：

```text
(I, love) -> {AI: 1, Python: 1}
(I, like) -> {AI: 1}
```

代码中会把 Context 从列表转换成元组，例如 `("I", "love")`。原因只是 Python 字典的键需要可哈希，而列表不能直接作为键；这个表示变化不会改变 Token 的内容和顺序。

---

# 二、构建 N-Gram 统计表

```python
from collections import defaultdict


def build_ngram_table(corpus, context_size=2):
    table = defaultdict(lambda: defaultdict(int))

    for sentence in corpus:
        tokens = sentence.split()

        for i in range(context_size, len(tokens)):
            context = tuple(tokens[i - context_size:i])
            target = tokens[i]
            table[context][target] += 1

    return table
```

这里使用 `context_size` 表示 Context Window 的长度。按标准 N-Gram 命名，`context_size=2` 意味着用两个历史 Token 预测一个 Target，整体属于 Trigram。不要把“Context 长度”也命名为 `n`，否则容易与 N-Gram 的阶数混淆。

`table[context][target] += 1` 就是训练过程：每看到一次 `(Context, Target)`，对应计数加一。

---

# 三、把计数转换成概率

预测时先查找 Context `c` 的计数表，再把各个 Target 次数除以总次数。例如计数为 `{AI: 3, Python: 1}`，概率就是 `{AI: 0.75, Python: 0.25}`。通用写法是：

$$
P(t\mid c)=\frac{C(c,t)}{\sum_{t'}C(c,t')}
$$

**这个公式的作用**：把离散出现次数归一化为条件概率。`C(c,t)` 是 Context `c` 后出现 Target `t` 的次数，分母是同一 Context 后所有 Target 的总次数。

直接翻译成代码：

```python
def predict(table, context):
    counts = table.get(tuple(context), {})

    if not counts:
        return None

    total = sum(counts.values())
    return {
        word: count / total
        for word, count in counts.items()
    }
```

如果 Context 没有出现在统计表中，`counts` 为空。因为分母为 0，当前这个不带平滑或回退策略的模型返回 `None`，明确表示“没有可用统计信息”。

---

# 四、完整代码

```python
#!/usr/bin/env python3
from collections import defaultdict


def build_ngram_table(corpus, context_size=2):
    table = defaultdict(lambda: defaultdict(int))

    for sentence in corpus:
        tokens = sentence.split()

        for i in range(context_size, len(tokens)):
            context = tuple(tokens[i - context_size:i])
            target = tokens[i]
            table[context][target] += 1

    return table


def predict(table, context):
    counts = table.get(tuple(context), {})

    if not counts:
        return None

    total = sum(counts.values())
    return {
        word: count / total
        for word, count in counts.items()
    }


corpus = [
    "I love AI",
    "I love Python",
    "I like AI",
]

context_size = 2
table = build_ngram_table(corpus, context_size=context_size)

print("N-Gram 统计表:")
for context, targets in table.items():
    print(context, "->", dict(targets))

print("\n预测结果:")
print(("I", "love"), "->", predict(table, ("I", "love")))
print(("I", "like"), "->", predict(table, ("I", "like")))
print(("I", "enjoy"), "->", predict(table, ("I", "enjoy")))
```

---

# 五、运行结果

```text
N-Gram 统计表:
('I', 'love') -> {'AI': 1, 'Python': 1}
('I', 'like') -> {'AI': 1}

预测结果:
('I', 'love') -> {'AI': 0.5, 'Python': 0.5}
('I', 'like') -> {'AI': 1.0}
('I', 'enjoy') -> None
```

对于 `("I", "love")`，两个 Target 各出现 1 次，总次数为 2，所以：

$$
P(\text{AI}\mid\text{I love})=\frac{1}{2}=0.5
$$

$$
P(\text{Python}\mid\text{I love})=\frac{1}{2}=0.5
$$

对于 `("I", "like")`，只观察到 `AI`，因此当前语料下的经验概率为 1.0。

---

# 六、观察未见 Context

`("I", "enjoy")` 与 `("I", "love")` 的含义看起来相近，但统计表只把它们当作两个不同的离散键。训练语料从未包含 `I enjoy ...`，所以查询结果是 `None`。

这正是主章介绍的数据稀疏性：

- 见过的 Context 可以用计数计算概率；
- 没见过的 Context 没有计数；
- 不同 Context 之间不会因为 Token 语义相近而自动共享经验。

这里故意不添加平滑、回退或其它补救方法，因为本实验的目标是看清最朴素 N-Gram 统计表的工作方式与边界。下一章会沿着这个失败案例，引出能够使用 Embedding 共享语义信息的 Neural Language Model。

# 七、增加重复样本

把 `"I love AI"` 在语料中再加入一次：

```python
corpus = [
    "I love AI",
    "I love AI",
    "I love Python",
    "I like AI",
]
```

重新运行后，`("I", "love")` 的计数变为：

```text
('I', 'love') -> {'AI': 2, 'Python': 1}
```

对应概率为：

```text
('I', 'love') -> {'AI': 0.6666666666666666, 'Python': 0.3333333333333333}
```

这说明统计式语言模型的概率直接来自语料频次：某个 Target 在指定 Context 后出现得越多，归一化后的概率就越高。

# 本实验总结

本实验完成了一个最小但完整的统计式 N-Gram 语言模型：

1. 用固定窗口从语料提取 `(Context, Target)`；
2. 统计每个 Context 后各 Target 的出现次数；
3. 归一化计数，得到条件概率；
4. 用未见 Context 暴露离散统计表的数据稀疏性。
