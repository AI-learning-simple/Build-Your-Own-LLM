# 实验 10.4：实现 Multi-Head Attention

> **硬件要求**：CPU 即可运行（普通笔记本可跑）

## 实验目标

第 10 章第十节按主流工程实现（PyTorch 的 `nn.MultiheadAttention`、GPT-2）把 Multi-Head Attention 拆成五个步骤。本实验用 NumPy 把这五步逐行写出来，用 padding Mask 处理变长句子，并验证"一次大投影 + 张量折叠"与论文"逐头循环"两种写法结果完全一致。

---

## 一、玩具设置与第 1 步：线性投影

沿用主章节的玩具维度 `d_model=4`、`H=2`（于是 `d_head=2`），但这次一次处理 `B=2` 条句子——第 2 条句子只有前 2 个 Token 有效，为第 4 步的 Mask 做准备：

```python
import numpy as np

np.random.seed(42)
B, T, d_model, H = 2, 4, 4, 2
d_head = d_model // H

X = np.random.randn(B, T, d_model)
W_Q = np.random.randn(d_model, d_model)
W_K = np.random.randn(d_model, d_model)
W_V = np.random.randn(d_model, d_model)
W_O = np.random.randn(d_model, d_model)

def softmax(x):
    exp = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return exp / exp.sum(axis=-1, keepdims=True)

# 第 1 步：线性投影（整体计算）——还没有"头"的概念
Q, K, V = X @ W_Q, X @ W_K, X @ W_V
print(Q.shape)   # (2, 4, 4) = (B, T, d_model)
```

---

## 二、第 2、3 步：拆分多头，再合并批次与头数

```python
# 第 2 步：拆分多头——切特征维，再 transpose 把"头"提到前面
Q = Q.reshape(B, T, H, d_head).transpose(0, 2, 1, 3)   # (B, H, T, d_head)
K = K.reshape(B, T, H, d_head).transpose(0, 2, 1, 3)
V = V.reshape(B, T, H, d_head).transpose(0, 2, 1, 3)

# 第 3 步：合并批次与头数——折叠成 B·H 份独立小矩阵
Qh = Q.reshape(B * H, T, d_head)   # (4, 4, 2) = (B·H, T, d_head)
Kh = K.reshape(B * H, T, d_head)
Vh = V.reshape(B * H, T, d_head)
```

折叠后 `(4, 4, 2)` 里躺着 `2×2=4` 份完全独立的 `(4, 2)` 小矩阵——从这一步起，批次和头已经没有区别，都是"再来一份"，后续所有计算一视同仁。

---

## 三、第 4 步：缩放点积与 Padding Mask

```python
scores = Qh @ Kh.transpose(0, 2, 1) / np.sqrt(d_head)   # (B·H, T, T)

valid_len = np.array([4, 2])        # 第 2 条句子只有前 2 个 Token 有效
mask = np.zeros((B, T, T))
for b in range(B):
    mask[b, :, valid_len[b]:] = -1e9        # Key 方向的 padding 列
mask = np.repeat(mask[:, None], H, axis=0).reshape(B * H, T, T)
scores = scores + mask
```

Mask 的形状是 `(T, T)`——行是 Query、列是 Key：`mask[b, :, 2:] = -1e9` 把"Key 是填充位"的整列压成大负数；`np.repeat` 把同一份 Mask 复制给每个头。它加在 Softmax 之前，Softmax 之后这些列的权重就变成 0，且每行只在有效 Key 上重新归一化。

---

## 四、第 5 步：加权求和与恢复形状

```python
weights = softmax(scores)              # (B·H, T, T)
head_ctx = weights @ Vh                # (B·H, T, d_head)  ← 每头的 Context（C_h）
head_ctx = head_ctx.reshape(B, H, T, d_head).transpose(0, 2, 1, 3)  # (B, T, H, d_head)
concat = head_ctx.reshape(B, T, d_model)   # Concat：把 H 份 C 拼宽，还未融合
output = concat @ W_O                       # (B, T, d_model)  ← 模块最终输出
```

代码里每头算出的 `head_ctx` 就是主章节第六节定义的 `C`（每头一份，记作 `C_h`）；最后两行把 H 份 `C_h` 拼宽、经 `W_O` 融合，得到模块最终输出 `output`。

把五步的 Shape 变化一次打印出来：

```text
第 1 步 Q: (2, 4, 4)      ← (B, T, d_model)
第 2 步 Q: (2, 2, 4, 2)   ← (B, H, T, d_head)
第 3 步 Qh: (4, 4, 2)     ← (B·H, T, d_head)
第 4 步 scores: (4, 4, 4) ← (B·H, T, T)
第 5 步 output: (2, 4, 4) ← (B, T, d_model)
```

恢复形状是第 2、3 步的**逆序**：先 `reshape` 拆回 `(B, H, T, d_head)`，再 `transpose(0, 2, 1, 3)` 把 `T` 提回前面，最后 `reshape` 成 `(B, T, d_model)`——注意 `transpose` 之后必须经过 `reshape`（NumPy 里直接 `reshape` 一个非连续内存的数组会自动拷贝，PyTorch 里则要显式 `.contiguous()`）才能安全变回二维拼接。

再观察第 2 条句子、头 1 的权重矩阵，确认 Mask 生效：

```python
print(np.round(weights.reshape(B, H, T, T)[1, 0], 3))
```

```text
[[0.986 0.014 0.    0.   ]
 [0.3   0.7   0.    0.   ]
 [0.502 0.498 0.    0.   ]
 [0.528 0.472 0.    0.   ]]
```

第 3、4 列（padding 位置）全部为 0——没有任何 Token 关注填充位。

## 五、对照验证：逐头循环的朴素版

主章节说过，"一次大投影再 reshape"（工程写法）与"每头一套小投影"（论文写法）等价——大 `W_Q` **按列切块**就是每头的小投影矩阵。用循环写一遍朴素版来验证：

```python
out_naive = np.zeros((B, T, d_model))
for h in range(H):
    Wq_h = W_Q[:, h * d_head:(h + 1) * d_head]   # 大矩阵按列切块 = 头 h 的小投影
    Wk_h = W_K[:, h * d_head:(h + 1) * d_head]
    Wv_h = W_V[:, h * d_head:(h + 1) * d_head]
    Q_h, K_h, V_h = X @ Wq_h, X @ Wk_h, X @ Wv_h
    s_h = Q_h @ K_h.transpose(0, 2, 1) / np.sqrt(d_head)
    s_h = s_h + mask.reshape(B, H, T, T)[:, h]   # 同一份 Mask
    out_naive[:, :, h * d_head:(h + 1) * d_head] = softmax(s_h) @ V_h
out_naive = out_naive @ W_O

print(np.allclose(output, out_naive))
```

输出：

```text
True
```

两种写法数值完全一致：工程版快在"一次大矩阵乘 + 折叠后的批量矩阵乘"，朴素版直观在"每头一套参数看得见摸得着"。PyTorch 的 `nn.MultiheadAttention`（11.1 节会直接用到）内部走的就是工程版路线。

## 本实验总结

✅ 按主流工程实现的五步（线性投影 → 拆分多头 → 合并批次与头数 → Mask → 恢复形状）用 NumPy 实现了完整的 Multi-Head Attention ✅ 用 padding Mask 屏蔽了变长句子的填充位 ✅ 验证了"张量折叠"与"逐头循环"两种写法结果一致。
