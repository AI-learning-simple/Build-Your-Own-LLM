# Experiment 6.9：阶段性成果——在 WikiText-2 上训练 Embedding Language Model

> **本节目标**：使用来自英文维基百科文章的 WikiText-2 语料，从随机初始化开始训练一个 Neural Language Model。模型通过 Next Token Prediction 同时学习 Token Embedding 与 MLP 权重；实验使用独立的训练集和验证集，并用 Loss、Perplexity、Embedding 变化量、最近邻和下一词预测检查训练结果。

---

# 一、为什么从玩具语料转向 WikiText-2

6.8 使用重复的 `I love AI today` 验证了训练循环是否正确。那种数据适合排查代码，却不能检验模型面对真实语言分布时的行为。

WikiText-2 来自经过整理的英文维基百科文章，具有三个适合本阶段的特点：

1. **规模明显大于手写句子**：包含百万量级 Token，可以形成大量不同的 Context；
2. **保留真实语言结构**：包括自然句子、标点和跨句关系；
3. **提供固定数据划分**：`train`、`validation`、`test` 已经分开，便于避免评估数据泄漏。

WikiText-2 仍然只是小型语言模型数据集，不代表现代 LLM 的训练规模。本节的目标是把训练链扩展到真实语料，而不是追求通用词向量或高质量文本生成。

---

# 二、训练目标没有改变

数据变大以后，模型仍然执行第 6 章一直使用的任务：给定固定长度 Context，预测下一个 Token。

```text
Context Token ID
→ Embedding Lookup
→ Concatenate
→ Linear → ReLU → Linear
→ Logits
→ Cross Entropy
→ Backpropagation
→ AdamW
→ 更新 Embedding 与 MLP Weight
```

Embedding 没有单独的“语义 Loss”。它是模型的输入参数，Next Token Prediction 的梯度会穿过 MLP 和 Concatenate，最后更新被 Context 查到的 Embedding 行。

如果两个词经常承担相近的上下文作用，它们可能获得相近的向量；这只是训练可能形成的统计结构，不是数学保证。向量几何还会受到 Tokenizer、语料频率、模型结构、随机初始化和优化过程影响。

---

# 三、实验设计与边界

完整 WikiText-2 可以生成大量样本。为了让普通 CPU 笔记本也能完成实验，默认配置读取完整语料并建立词表，但从训练集不同位置均匀抽取 `100,000` 个 Context，从验证集抽取 `20,000` 个 Context。

| 配置 | 默认值 | 作用 |
|---|---:|---|
| `VOCAB_SIZE` | 5,000 | 保留训练集中最高频的 Token，其余映射为 `<unk>` |
| `WINDOW_SIZE` | 4 | 使用前 4 个 Token 预测下一个 Token |
| `EMBED_DIM` | 32 | 每个 Token 的向量维度 |
| `HIDDEN_DIM` | 64 | MLP 隐藏层宽度 |
| `MAX_TRAIN_SAMPLES` | 100,000 | 默认训练样本数 |
| `MAX_VALID_SAMPLES` | 20,000 | 默认验证样本数 |
| `EPOCHS` | 2 | 遍历抽样训练集的次数 |

这里必须遵守一条数据原则：**Vocabulary 只能由训练集建立**。验证集中的未登录词统一映射为 `<unk>`，不能提前把验证集词频泄漏给模型。

本实验使用最小 Word Tokenizer，只保留英文单词、缩写和常见标点。它便于观察 Embedding，但不能解决任意未登录词；真实 LLM 通常使用 BPE 等 Subword Tokenizer。

# 五、完整代码

下面是一份可直接保存为 `.py` 文件运行的完整脚本：

```python
#!/usr/bin/env python3
import math
import re
from collections import Counter

import torch
import torch.nn as nn
import torch.nn.functional as F
from datasets import load_dataset
from torch.utils.data import DataLoader, Dataset

SEED = 42
VOCAB_SIZE = 5_000
WINDOW_SIZE = 4
EMBED_DIM = 32
HIDDEN_DIM = 64
BATCH_SIZE = 256
EPOCHS = 2
PEAK_LR = 3e-3
WEIGHT_DECAY = 1e-4
MAX_TRAIN_SAMPLES = 100_000
MAX_VALID_SAMPLES = 20_000


torch.manual_seed(SEED)

if torch.cuda.is_available():
    device = torch.device("cuda")
elif hasattr(torch.backends, "mps") and torch.backends.mps.is_available():
    device = torch.device("mps")
else:
    device = torch.device("cpu")
print("device =", device)


# 1. 下载 WikiText-2 的固定 train / validation / test 划分
dataset = load_dataset("Salesforce/wikitext", "wikitext-2-raw-v1")
print(dataset)


# 2. 最小 Word Tokenizer：小写化，跳过标题行，保留常见标点
TOKEN_PATTERN = re.compile(r"[a-z]+(?:'[a-z]+)?|[0-9]+|[.,!?;:]")


def tokenize_lines(lines):
    tokens = []
    for line in lines:
        line = line.strip().lower()
        if not line:
            continue
        if line.startswith("=") and line.endswith("="):
            continue

        line_tokens = TOKEN_PATTERN.findall(line)
        if line_tokens:
            tokens.extend(line_tokens)
            tokens.append("<eos>")
    return tokens


train_tokens = tokenize_lines(dataset["train"]["text"])
valid_tokens = tokenize_lines(dataset["validation"]["text"])
test_tokens = tokenize_lines(dataset["test"]["text"])

print("train tokens =", len(train_tokens))
print("valid tokens =", len(valid_tokens))
print("test tokens  =", len(test_tokens))


# 3. 只用训练集建立 Vocabulary
SPECIAL_TOKENS = ["<unk>", "<eos>"]
word_counts = Counter(train_tokens)
for token in SPECIAL_TOKENS:
    word_counts.pop(token, None)

vocab = SPECIAL_TOKENS + [
    word for word, _ in word_counts.most_common(VOCAB_SIZE - len(SPECIAL_TOKENS))
]
word2id = {word: token_id for token_id, word in enumerate(vocab)}
id2word = {token_id: word for word, token_id in word2id.items()}
unk_id = word2id["<unk>"]


def encode(tokens):
    return torch.tensor(
        [word2id.get(token, unk_id) for token in tokens],
        dtype=torch.long,
    )


train_ids = encode(train_tokens)
valid_ids = encode(valid_tokens)
test_ids = encode(test_tokens)

print("vocab size =", len(vocab))
print("validation <unk> rate =", (valid_ids == unk_id).float().mean().item())

# 字符串列表已完成使命，释放它们占用的内存
del train_tokens, valid_tokens, test_tokens


# 4. 从一条 Token ID 序列构造 (Context, Target)
class NextTokenDataset(Dataset):
    def __init__(self, token_ids, window_size, max_samples=None):
        self.token_ids = token_ids
        self.window_size = window_size
        available = len(token_ids) - window_size
        if available <= 0:
            raise ValueError("Token 数量必须大于 window_size")

        sample_count = available if max_samples is None else min(max_samples, available)
        # 默认样本覆盖整个 split，而不是只截取开头几篇文章
        self.positions = torch.linspace(
            0,
            available - 1,
            steps=sample_count,
        ).long()

    def __len__(self):
        return len(self.positions)

    def __getitem__(self, index):
        start = self.positions[index].item()
        context = self.token_ids[start:start + self.window_size]
        target = self.token_ids[start + self.window_size]
        return context, target


train_data = NextTokenDataset(
    train_ids,
    WINDOW_SIZE,
    max_samples=MAX_TRAIN_SAMPLES,
)
valid_data = NextTokenDataset(
    valid_ids,
    WINDOW_SIZE,
    max_samples=MAX_VALID_SAMPLES,
)
test_data = NextTokenDataset(
    test_ids,
    WINDOW_SIZE,
    max_samples=MAX_VALID_SAMPLES,
)

generator = torch.Generator().manual_seed(SEED)
train_loader = DataLoader(
    train_data,
    batch_size=BATCH_SIZE,
    shuffle=True,
    generator=generator,
    num_workers=0,
)
valid_loader = DataLoader(
    valid_data,
    batch_size=BATCH_SIZE,
    shuffle=False,
    num_workers=0,
)

print("train samples =", len(train_data))
print("valid samples =", len(valid_data))


# 5. 定义 Embedding Language Model
class EmbeddingLanguageModel(nn.Module):
    def __init__(self, vocab_size, embed_dim, window_size, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.fc1 = nn.Linear(window_size * embed_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, vocab_size)

        nn.init.normal_(self.embedding.weight, mean=0.0, std=0.02)
        nn.init.kaiming_uniform_(self.fc1.weight, nonlinearity="relu")
        nn.init.zeros_(self.fc1.bias)
        nn.init.xavier_uniform_(self.fc2.weight)
        nn.init.zeros_(self.fc2.bias)

    def forward(self, context_ids):
        vectors = self.embedding(context_ids)
        x = vectors.reshape(vectors.size(0), -1)
        hidden = torch.relu(self.fc1(x))
        return self.fc2(hidden)


model = EmbeddingLanguageModel(
    vocab_size=len(vocab),
    embed_dim=EMBED_DIM,
    window_size=WINDOW_SIZE,
    hidden_dim=HIDDEN_DIM,
).to(device)

initial_embedding = model.embedding.weight.detach().cpu().clone()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(
    [
        {"params": model.embedding.parameters(), "weight_decay": 0.0},
        {"params": model.fc1.parameters()},
        {"params": model.fc2.parameters()},
    ],
    lr=PEAK_LR,
    weight_decay=WEIGHT_DECAY,
)


# 6. Warmup + Cosine Decay
TOTAL_STEPS = EPOCHS * len(train_loader)
WARMUP_STEPS = max(1, int(0.05 * TOTAL_STEPS))


def learning_rate(step):
    if step < WARMUP_STEPS:
        return PEAK_LR * (step + 1) / WARMUP_STEPS

    decay_steps = max(1, TOTAL_STEPS - WARMUP_STEPS)
    progress = (step - WARMUP_STEPS) / decay_steps
    return PEAK_LR * 0.5 * (1.0 + math.cos(math.pi * progress))


@torch.no_grad()
def evaluate(data_loader):
    model.eval()
    total_loss = 0.0
    total_items = 0

    for contexts, targets in data_loader:
        contexts = contexts.to(device)
        targets = targets.to(device)
        loss = criterion(model(contexts), targets)
        total_loss += loss.item() * targets.size(0)
        total_items += targets.size(0)

    mean_loss = total_loss / total_items
    return mean_loss, math.exp(mean_loss)


# 7. 训练与验证
initial_val_loss, initial_val_ppl = evaluate(valid_loader)
print(
    f"before training | val loss={initial_val_loss:.4f} "
    f"val ppl={initial_val_ppl:.2f}"
)

global_step = 0
for epoch in range(1, EPOCHS + 1):
    model.train()
    total_loss = 0.0
    total_items = 0

    for contexts, targets in train_loader:
        lr = learning_rate(global_step)
        for group in optimizer.param_groups:
            group["lr"] = lr

        contexts = contexts.to(device)
        targets = targets.to(device)

        optimizer.zero_grad(set_to_none=True)
        logits = model(contexts)
        loss = criterion(logits, targets)
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * targets.size(0)
        total_items += targets.size(0)
        global_step += 1

    train_loss = total_loss / total_items
    val_loss, val_ppl = evaluate(valid_loader)
    print(
        f"epoch={epoch} train loss={train_loss:.4f} "
        f"val loss={val_loss:.4f} val ppl={val_ppl:.2f} lr={lr:.6f}"
    )


# 8. 确认 Embedding 已经被梯度更新
# 上面的参数分组将 Embedding 的 weight_decay 设为 0，避免衰减单独改变向量
final_embedding = model.embedding.weight.detach().cpu()
row_change = (final_embedding - initial_embedding).norm(dim=1)
print("mean |delta embedding| =", row_change.mean().item())

for word in ["the", "music", "city", "film", "game"]:
    if word in word2id:
        change = row_change[word2id[word]].item()
        print(f"{word:<8} |delta embedding| = {change:.6f}")


# 9. 查询训练后 Embedding 的最近邻
@torch.no_grad()
def nearest(word, top_k=5):
    if word not in word2id:
        return []

    matrix = F.normalize(model.embedding.weight.detach(), dim=1)
    query_id = word2id[word]
    scores = matrix @ matrix[query_id]
    scores[query_id] = -float("inf")
    for special in SPECIAL_TOKENS:
        scores[word2id[special]] = -float("inf")

    values, indices = torch.topk(scores, k=top_k)
    return [
        (id2word[token_id.item()], score.item())
        for score, token_id in zip(values.cpu(), indices.cpu())
    ]


for word in ["music", "city", "film", "game"]:
    if word in word2id:
        print(word, "->", nearest(word))


# 10. 检查未参与训练的 test split 上的下一词预测
@torch.no_grad()
def inspect_predictions(data, indices):
    model.eval()
    for index in indices:
        context, target = data[index]
        logits = model(context.unsqueeze(0).to(device))[0]
        probabilities = torch.softmax(logits, dim=-1)
        values, pred_ids = torch.topk(probabilities, k=3)

        context_words = [id2word[token_id.item()] for token_id in context]
        predictions = [
            (id2word[token_id.item()], probability.item())
            for probability, token_id in zip(values.cpu(), pred_ids.cpu())
        ]
        print(context_words, "target=", id2word[target.item()], "top3=", predictions)


inspect_predictions(
    test_data,
    [0, len(test_data) // 3, 2 * len(test_data) // 3],
)


# 11. 保存恢复模型所需的全部状态
checkpoint = {
    "model_state_dict": model.state_dict(),
    "vocab": vocab,
    "config": {
        "vocab_size": len(vocab),
        "window_size": WINDOW_SIZE,
        "embed_dim": EMBED_DIM,
        "hidden_dim": HIDDEN_DIM,
    },
}
torch.save(checkpoint, "wikitext2_embedding_lm.pt")
print("saved: wikitext2_embedding_lm.pt")
```

# 六、理解代码中的关键设计

## （一）为什么不预先保存全部 Context

WikiText-2 能产生大量重叠窗口。如果把每个 Context 都复制成独立 Python 列表，会产生不必要的内存开销。`NextTokenDataset` 只保存一条 Token ID 序列和起点位置，取样时再切片：

```python
context = token_ids[start:start + window_size]
target = token_ids[start + window_size]
```

这和前面手写滑动窗口的数学含义相同，只是没有提前复制全部样本。

## （二）为什么 Vocabulary 只保留 5,000 个 Token

输出层必须为 Vocabulary 中每个 Token 产生一个 Logit。Vocabulary 越大，`fc2` 的参数量和每一步计算量越大：

$$
W_2\text{ 的参数量}=\text{HIDDEN\_DIM}\times\text{VOCAB\_SIZE}
$$

默认配置中，`W2` 的 Shape 是 `(5000, 64)`。低频词映射为 `<unk>`，以换取普通 CPU 可接受的训练成本。这是一项明确的工程折中，不表示低频词没有价值。

## （三）初始化如何对应 6.7

代码没有依赖各层的隐式默认值，而是明确指定：

- Embedding：均值为 0、标准差为 `0.02` 的随机初始化；
- `fc1`：配合 ReLU 使用 Kaiming 初始化；
- `fc2`：使用 Xavier 初始化；
- Bias：初始化为 0。

Embedding 可以随机初始化，因为训练前没有必须遵循的语义坐标；它只需要打破对称性，并在训练中接受梯度更新。

## （四）为什么同时记录 Train Loss 与 Validation Loss

Train Loss 衡量模型对参与参数更新的数据拟合得怎样；Validation Loss 衡量模型在未参与更新的数据上表现怎样。只看到 Train Loss 下降，不能证明模型获得了泛化能力。

Perplexity 由平均 Cross Entropy 得到：

$$
\text{Perplexity}=\exp(\text{Cross Entropy})
$$

它越低，表示模型平均为真实下一个 Token 分配的概率越高。不同 Tokenizer 和 Vocabulary 会改变任务难度，因此不能直接比较词表不同的模型。

## （五）Warmup 与 Cosine Decay 如何进入真实训练

6.7 已经解释过学习率调度。本节在每次 `optimizer.step()` 前，根据 `global_step` 设置当前学习率：最初 5% 的训练步数线性 Warmup，之后按 Cosine 曲线衰减。

```text
较小学习率
→ 线性升至 PEAK_LR
→ 余弦衰减至接近 0
```

这使 6.7 的公式真正进入端到端训练，而不是停留在独立示例中。

# 七、如何判断实验是否成功

不要要求不同系统输出完全相同的数字。CPU、CUDA、MPS、PyTorch 版本和底层浮点实现都可能带来差异。应检查以下事实：

1. **Train Loss 总体下降**：说明优化器正在拟合训练样本；
2. **Validation Loss 低于训练前基线**：说明模型在未参与更新的数据上获得了预测能力；
3. **`mean |delta embedding|` 明显大于 0**：本实验已把 Embedding 的 `weight_decay` 设为 0，因此变化来自训练梯度；
4. **下一词 Top-3 不再完全随机**：真实 Target 应在一部分样本中获得较高概率；
5. **最近邻出现可解释结构时保持克制**：功能相近、主题相近或词频相近都可能造成向量接近，单个邻居不能证明模型“理解”了词义。

随机均匀预测的 Loss 量级约为：

$$
\ln(V)=\ln(5000)\approx 8.52
$$

模型初始化并不会让所有 Logit 严格相等，所以训练前 Loss 不必精确等于 `8.52`；它只是量级检查。


# 九、实验边界

本实验仍有以下限制：

1. Word Tokenizer 会把大量低频词压缩为同一个 `<unk>`；
2. 固定窗口只能使用前 4 个 Token，无法保留任意长度历史；
3. Concatenate 让每个位置连接到 `fc1` 的不同列，不能自然处理变长输入；
4. 输入 Embedding 是静态向量，同一个 Token 在不同句子中先从同一行开始；
5. Next Token Prediction 学到的最近邻不等同于专门训练的通用语义词向量；
6. 默认只抽取部分 Context，目标是控制本地实验成本，不是得到 WikiText-2 最佳结果。

下一章将引入 RNN，让模型用 Hidden State 处理变长历史；之后 Attention 和 Transformer 会进一步为每个 Token 构造依赖当前上下文的表示。

# 本节总结

本节把第 1～6 章的组件应用到 WikiText-2 英文语料，完成了从真实文本到模型检查点的闭环：

```text
WikiText-2
→ Word Tokenizer
→ 训练集 Vocabulary
→ Context / Target
→ 随机 Embedding
→ MLP / Logits
→ Cross Entropy
→ Backpropagation
→ AdamW + Warmup + Cosine Decay
→ Validation Loss / Perplexity
→ Embedding 与下一词预测检查
```

Token ID 只是离散行号；Embedding 的结构来自具体语料、训练目标和梯度更新。到这里，第 6 章已经从单次前向计算推进到真实英文语料上的完整训练，下一章开始处理固定 Context Window 的限制。
