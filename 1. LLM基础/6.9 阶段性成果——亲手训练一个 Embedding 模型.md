# Experiment 6.9：静态词向量旁支——用 PPMI + SVD 构建 Embedding

> **本节定位**：6.1～6.8 的主线是“可训练的 Neural Language Model”：前向计算、Cross Entropy、反向传播和优化器。本节暂时离开这条主线，介绍一种经典的**静态词向量统计方法**。它不使用 6.5 的反向传播，也不使用 6.8 的 AdamW；其核心是“共现统计 → PPMI → 截断 SVD”。

这条旁支能帮助理解第 3 章的分布假设和 Embedding 几何，但它不是把前六章所有组件组装成语言模型，也不会根据 Context 预测下一个 Token。

---

# 一、静态词向量与语言模型的区别

| 项目 | 本节 PPMI + SVD | 6.7 Neural Language Model |
|---|---|---|
| 学习信号 | 窗口共现计数 | 下一个 Token 标签 |
| 求解方式 | 构造矩阵并做截断 SVD | Cross Entropy + 反向传播 + 优化器 |
| 同一个词的表示 | 在所有上下文中固定 | 6.7 的输入 Embedding 也固定；后续上下文模型会继续加工 |
| 输出 | 每个词一行静态向量 | 给定 Context 的下一词 Logits |
| 能否直接生成文本 | 不能 | 可按预测分布逐步生成 |

因此，本节的“构建 Embedding”不是梯度训练意义上的“训练一个语言模型”。

---

# 二、核心思想：共现矩阵、PPMI 与 SVD

## 2.1 共现矩阵

给定窗口半径 `WINDOW`，若词 `i` 和词 `j` 出现在同一窗口内，就给 `M[i, j]` 加 1。相比只统计相邻词的 Bigram，它统计更宽范围内的局部共现。

## 2.2 PPMI

高频词会与许多词共现，原始次数不能直接代表语义相关性。点互信息衡量观测到的共现相对“按边缘频率独立出现”高出了多少：

$$
\operatorname{PMI}(i,j)=\log\frac{M_{ij}\,N}{M_{i*}M_{*j}}
$$

PPMI 将负值截断为 0：

$$
\operatorname{PPMI}(i,j)=\max(\operatorname{PMI}(i,j),0)
$$

## 2.3 截断 SVD

对 PPMI 矩阵做低秩分解，只保留前 `D` 个奇异方向。常见的一种词向量取法是：

$$
E=U_D\sqrt{\Sigma_D}
$$

`E` 的形状为 `(V, D)`，每一行对应词表中的一个词。这是静态词向量矩阵，不是 6.7 模型中通过梯度更新得到的参数副本。

# 三、一个可核查的实现骨架

下面假设读者已经合法获取并解压了一份纯文本语料，并把路径填写为 `CORPUS_PATH`。数据下载方式、规模、耗时和内存峰值取决于语料来源与机器，本节不作固定承诺。

```python
import re
from collections import Counter

import numpy as np
from scipy.sparse import coo_matrix
from scipy.sparse.linalg import svds

CORPUS_PATH = "path/to/corpus.txt"
MAX_TOKENS = 1_000_000
VOCAB_SIZE = 15_000
WINDOW = 5
EMBED_DIM = 100

with open(CORPUS_PATH, encoding="utf-8") as f:
    tokens = re.findall(r"[a-z]+", f.read().lower())[:MAX_TOKENS]

freq = Counter(tokens)
vocab = [word for word, _ in freq.most_common(VOCAB_SIZE)]
word2id = {word: token_id for token_id, word in enumerate(vocab)}
ids = np.array([word2id.get(word, -1) for word in tokens], dtype=np.int32)
V = len(vocab)

# 这里只保留词表内的中心词/上下文词；词表外词被丢弃，并未映射到 <UNK>。
rows, cols = [], []
for offset in range(1, WINDOW + 1):
    left = ids[:-offset]
    right = ids[offset:]
    valid = (left >= 0) & (right >= 0)
    rows.append(left[valid])
    cols.append(right[valid])
    rows.append(right[valid])
    cols.append(left[valid])

rows = np.concatenate(rows)
cols = np.concatenate(cols)
counts = np.ones(len(rows), dtype=np.float32)
M = coo_matrix((counts, (rows, cols)), shape=(V, V), dtype=np.float32).tocsr()
M.sum_duplicates()

row_sum = np.asarray(M.sum(axis=1)).ravel()
col_sum = np.asarray(M.sum(axis=0)).ravel()
total = float(M.sum())
M_coo = M.tocoo()

pmi = np.log(
    (M_coo.data.astype(np.float64) * total)
    / (row_sum[M_coo.row] * col_sum[M_coo.col] + 1e-12)
)
ppmi_data = np.maximum(pmi, 0.0)
nonzero = ppmi_data > 0
PPMI = coo_matrix(
    (ppmi_data[nonzero], (M_coo.row[nonzero], M_coo.col[nonzero])),
    shape=(V, V),
).tocsr()

k = min(EMBED_DIM, min(PPMI.shape) - 1)
U, singular_values, _ = svds(PPMI, k=k)
order = np.argsort(singular_values)[::-1]
E = U[:, order] * np.sqrt(singular_values[order])
print(E.shape)
```

这段实现为了清楚展示算法而一次保留所有共现坐标。对于大语料，`rows`、`cols` 仍可能占用大量内存；“使用稀疏矩阵”不等于构造过程自动变成常量内存。工程实现应按语料分块聚合计数、定期合并稀疏块，或使用专门的共现统计工具。

如果希望显式保留 `<UNK>`，必须把它加入词表并把 OOV ID 映射到该行；上面的实现选择直接过滤 OOV，不能声称它们已归入 `<UNK>`。

# 四、检查静态语义空间

## 4.1 余弦相似度

```python
def cosine(a, b):
    denom = np.linalg.norm(a) * np.linalg.norm(b)
    return float(a @ b / (denom + 1e-12))


def nearest(word, top_k=8):
    token_id = word2id[word]
    query = E[token_id]
    scores = E @ query / (np.linalg.norm(E, axis=1) * np.linalg.norm(query) + 1e-12)
    scores[token_id] = -np.inf
    best = np.argpartition(-scores, top_k)[:top_k]
    best = best[np.argsort(-scores[best])]
    return [(vocab[i], float(scores[i])) for i in best]

print(nearest("king"))
```

具体近邻取决于语料、预处理、词表、窗口、PPMI 细节和 SVD 维度。没有实际运行与保存输出时，不应预先承诺某组固定词或相似度。

## 4.2 类比查询

```python
def analogy(a, b, c, top_k=8):
    query = E[word2id[a]] - E[word2id[b]] + E[word2id[c]]
    scores = E @ query / (np.linalg.norm(E, axis=1) * np.linalg.norm(query) + 1e-12)
    for word in (a, b, c):
        scores[word2id[word]] = -np.inf
    best = np.argpartition(-scores, top_k)[:top_k]
    best = best[np.argsort(-scores[best])]
    return [(vocab[i], float(scores[i])) for i in best]

print(analogy("king", "man", "woman"))
```

经典类比有时会出现，但不是数学保证。应在实际语料上报告结果，并同时检查失败案例，避免只展示挑选过的成功样例。

# 六、为什么不在这里用 CBOW 做胜负对比

CBOW/Skip-gram 与 PPMI + SVD 都能学习静态词向量，但公平比较至少要控制：

- 实际处理的正样本数和训练轮数；
- 负采样数、负样本分布与子采样策略；
- 词表、窗口、向量维度和预处理；
- 计算预算、实现效率与超参数搜索预算；
- 相同的内在/下游评测集。

仅用少量优化步骤训练一个未调参的 CBOW，再与已经汇总全语料共现统计的 SVD 比较，不能推出“CBOW 数据饥饿”或“统计路线胜出”。因此本节不提供这种不对等结论。若要比较，应建立独立、可复现的基准实验。

# 七、本节与主线的关系

本节证明的是：局部共现统计经过合适的加权和低秩分解，可以形成有用的**静态语义空间**。它回扣第 3 章的分布假设，但没有继续练习 6.5～6.8 的反向传播与优化器。

主线仍然是 6.7 的 Neural Language Model：Embedding 作为可训练参数参与下一 Token 预测。后续 RNN 与 Transformer 将进一步让 Token 表示依赖具体上下文。

---

# 本节总结

- PPMI + 截断 SVD 是经典的静态词向量方法，不是下一 Token 语言模型。
- OOV 是过滤还是映射到 `<UNK>`，必须与代码一致。
- 稀疏存储能降低矩阵存储成本，但大规模共现坐标的构造仍需专门控制内存。
- 近邻与类比结果必须以实际运行输出为准。
- 未控制训练预算和超参数的 CBOW/SVD 对比不能支持方法优劣结论。
