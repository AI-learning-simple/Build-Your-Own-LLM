# 10.7 从一个 Token 到整个句子——Attention Matrix（注意力矩阵）

上一节，我们学习了 Self-Attention：每一个 Token 都会查看整个句子。但我们始终站在**一个 Token 的视角**。而 Transformer 真正计算的时候，不是一个一个算，而是**整个句子一次完成**。

---

# 把所有结果放到一起

假设句子有 4 个 Token：`The cat is sleeping`。每一个 Token 作为 Query，都会对所有 Token 计算一次注意力，把结果排成一张表：

```text
                被关注(Key)
             The  cat  is  sleeping
Query  The    ?    ?    ?      ?
       cat    ?    ?    ?      ?
       is     ?    ?    ?      ?
  sleeping    ?    ?    ?      ?
```

这就是 **Attention Matrix（注意力矩阵）**，矩阵中每个数字表示**当前 Query 对某个 Token 的关注程度**。

标准 Self-Attention 先投影，再做缩放点积：

```
Q = XW_Q,  K = XW_K,  V = XW_V
A = softmax(QKᵀ / √d_k)
O = AV
```

其中 `X∈ℝ^(N×d_model)`，`Q,K∈ℝ^(N×d_k)`，`V∈ℝ^(N×d_v)`，所以 `A∈ℝ^(N×N)`。每一行沿 Key 维做 Softmax，行和为 1。

---

# Full Attention 与 Causal Attention

Encoder 的双向 Self-Attention 通常允许每个 Query 查看整段序列，称为 Full Attention。Decoder-only 语言模型还会在未来位置加入 Causal Mask，使位置 `i` 只能查看 `j≤i` 的 Key，避免训练时偷看答案。

---

# Experiment 10.7：计算完整的 Scaled QKV Attention

下面仍使用人工二维 Embedding。为隔离 QKV、缩放和 Mask 的作用，示例把三个投影矩阵设为单位阵；训练模型中的 `W_Q/W_K/W_V` 都是独立可学习参数。

```python
import numpy as np

X = np.array([
    [0.1, -0.2],   # The
    [1.0,  0.5],   # cat
    [-0.1, 0.1],   # is
    [0.9,  0.6],   # sleeping
])
W_Q = np.eye(2)
W_K = np.eye(2)
W_V = np.eye(2)

Q, K, V = X @ W_Q, X @ W_K, X @ W_V
d_k = Q.shape[-1]
scores = Q @ K.T / np.sqrt(d_k)

def softmax(x):
    exp = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return exp / exp.sum(axis=-1, keepdims=True)

full_attention = softmax(scores)
full_output = full_attention @ V

causal_mask = np.triu(np.ones_like(scores, dtype=bool), k=1)
causal_scores = np.where(causal_mask, -np.inf, scores)
causal_attention = softmax(causal_scores)
causal_output = causal_attention @ V

print("Full attention:\n", np.round(full_attention, 3))
print("Causal attention:\n", np.round(causal_attention, 3))
print("Output shape:", full_output.shape, causal_output.shape)
```

输出中的两张权重矩阵分别是：

```text
Full attention:
[[0.259 0.250 0.245 0.245]
 [0.149 0.360 0.144 0.348]
 [0.249 0.245 0.258 0.249]
 [0.149 0.355 0.149 0.348]]
Causal attention:
[[1.000 0.000 0.000 0.000]
 [0.292 0.708 0.000 0.000]
 [0.331 0.326 0.343 0.000]
 [0.149 0.355 0.149 0.348]]
```

两者都执行完整的 `QKᵀ/√d_k → Mask → Softmax → AV`。区别只在 Mask：Full Attention 没有屏蔽位置，Causal Attention 的严格上三角权重为 0。由于这里的 Embedding 与投影均为人工设定，矩阵只用于验证计算，不能解释为训练模型学到的语言关系。

---

# 为什么叫 Matrix？

之前计算的是“一个 Query → 所有 Key”，现在变成“所有 Query → 所有 Key”。若序列有 `N` 个 Token，需要形成 `N×N` 个分数；每次点积还要处理 `d_k` 个维度，因此分数计算量约为 `O(N²d_k)`，Attention Matrix 本身占用 `O(N²)` 内存。常说 Attention 对序列长度是“平方复杂度”，指的就是这个 `N²` 因子。

---

# Transformer 为什么能并行？

RNN 必须 `Token1 → Token2 → Token3` 一步一步计算，不能跳过，因为后一个 Hidden State 依赖前一个。而 Transformer 的 Attention Matrix 一次计算"所有 Query × 所有 Key"，整个句子可以一次送进 GPU 统一完成。这就是 Transformer 能够高效并行训练的根本原因。

---

# 本节总结

本节，我们完成了从"一个 Token 的 Attention"到"整个句子的 Self-Attention"的跨越：✅ 每个Token 都会形成一行 Attention Weight ✅ 所有行组合起来，就是Attention Matrix ✅ 每一行都是 Softmax 后的概率分布 ✅ Self-Attention 的计算复杂度是 O(N²) ✅ Transformer 能够并行，是因为整个矩阵可以一次计算
