# 7.11 Output Gate——模型如何决定"输出什么"

上一节，我们已经完成了Cell State 的更新：`旧 Cell → Forget Gate 保留旧信息 + Input Gate 加入新信息 → 新的 Cell State`。到这里，LSTM 已经拥有了一份新的长期记忆。但新的问题来了：**是不是 Cell State 中的所有信息，都应该立刻输出？** 答案当然不是。

---

# 一个生活中的例子

假设你的长期记忆里保存着 `Alice、教授、北京大学、图灵奖、出生地、论文、年龄`。现在别人问你"Alice 在哪里工作？"，你会回答"北京大学"，而不会把所有信息都说出来。虽然这些信息都存在长期记忆中，但当前真正需要输出的只有一部分。

---

# Output Gate 的作用

Output Gate 控制的不是"Cell State 是否存在"，而是**Cell State 中哪些内容参与当前计算**：

```mermaid
flowchart LR
    A["Cell State"] --> B["Output Gate"] --> C["Hidden State"] --> D[输出]
```

Cell State 仍然完整保留，只是当前输出只使用其中一部分。

---

# 为什么还需要Hidden State？

既然 Cell State 已经保存了长期记忆，为什么还需要 Hidden State？原因是：Cell State 更像**数据库**，保存全部数据；Hidden State 更像**当前显示的页面**，只显示当前需要的一部分。

---

# Experiment 7.12：体验 Output Gate

延续 7.10 节算出的 `new_cell = [7.9, 5.0]`：

```python
import numpy as np

new_cell = np.array([7.9, 5.0])   # 来自 7.10 节
output_gate = np.array([0.7, 0.6])  # Output Gate

hidden = output_gate * new_cell
print(hidden)  # [5.53 3.  ]
```

输出 `[5.53, 3.0]`——第一维输出了70%，第二维输出了60%，Cell State 本身完全没有减少，只是这一时刻的 Hidden State 只用到了其中一部分。

---

# 为什么还要经过 tanh？

真正的 LSTM，Output Gate 并不是直接输出 Cell State，而是先经过 `tanh(Cell State)` 整理一遍，再乘以 Output Gate：

```
hₜ = oₜ × tanh(Cₜ)
```

其中 `oₜ` 是 Output Gate，`Cₜ` 是 Cell State。翻译成人话：**先整理一下长期记忆，再决定输出多少。**

---

# 三个 Gate 如何协同工作？

```mermaid
flowchart TD
    H["上一时刻 Hidden State"] --> FG["Forget Gate"]
    FG --> KEEP["保留旧 Cell State"]
    KEEP --> IG["Input Gate + Candidate"]
    IG --> NEWCELL["新的 Cell State"]
    NEWCELL --> OG["Output Gate"]
    OG --> NEWHIDDEN["新的 Hidden State"]
    NEWHIDDEN --> NEXT["传递给下一时刻"]
```

三个 Gate 分别负责：Forget Gate 管理过去；Input Gate 管理现在；Output Gate 服务当前输出，并把 Hidden State 传递给下一时刻。整个流程形成一个完整的闭环。

---

# Experiment 7.13：手写一次完整的 LSTM 更新

把7.9~7.11 三节串起来，就是一次完整的 LSTM 更新：

```python
import numpy as np

old_cell = np.array([8, 4])
forget = np.array([0.8, 0.5])
candidate = np.array([3, 6])
input_gate = np.array([0.5, 0.5])
output_gate = np.array([0.7, 0.6])

new_cell = forget * old_cell + input_gate * candidate  # 更新 Cell State
hidden = output_gate * new_cell                          # 生成 Hidden State

print("Cell:", new_cell)     # [7.9 5. ]
print("Hidden:", hidden)     # [5.53 3.  ]
```

计算过程：旧记忆 `[8,4]` → Forget 保留 `[0.8,0.5]` → `[6.4,2.0]`；候选记忆 `[3,6]` → Input 写入 `[0.5,0.5]` → `[1.5,3.0]`；新 Cell = `[6.4+1.5, 2.0+3.0] = [7.9, 5.0]`；Output 输出 `[0.7,0.6]` → Hidden = `[5.53, 3.0]`。这和 7.9~7.11 三节分别算出的结果完全一致。
