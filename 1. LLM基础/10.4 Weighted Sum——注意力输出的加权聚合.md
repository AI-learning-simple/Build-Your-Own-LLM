# 10.4 Weighted Sum——注意力输出的加权聚合

> **硬件要求**：CPU 即可运行（普通笔记本可跑）

上一节，我们已经算出 `cat` 对 `The cat is sleeping` 的 Attention Weight：`The 0.114, cat 0.398, is 0.109, sleeping 0.379`。现在模型已经知道谁重要、谁不重要，新的问题来了：**接下来怎么办？**

---

# 第一种想法：只看最大的

找到最大权重 `cat: 0.398`，只读取 `cat` 自己。看起来省事，但这样Attention 就白算了——`cat` 完全没有从`sleeping` 那里获得任何新信息，等于什么都没改变。

---

# 一个更好的办法：全部利用，按权重分配

重要的多看一点，不重要的少看一点，最终输出就是所有 Token 的**加权平均**。

---

# Experiment 10.4：手写 Weighted Sum

```python
import numpy as np

embedding = np.array([
    [0.1, -0.2],   # The
    [1.0,  0.5],   # cat
    [-0.1, 0.1],   # is
    [0.9,  0.6],   # sleeping
])
weights = np.array([0.114, 0.398, 0.109, 0.379])  # 来自 10.3 节

output = np.sum(embedding * weights.reshape(-1,1), axis=0)
print(np.round(output, 3))  # [0.74 0.415]
```

新的 `cat' = [0.74, 0.415]`，比原来的 `cat = [1.0, 0.5]` 略微"偏向" `sleeping = [0.9, 0.6]` 的方向——这正是 Attention 的效果：`cat` 的新表示已经融合了 `sleeping` 带来的上下文信息，而不再是一个孤立的词向量。

---

# 为什么叫 Attention？

模型不是全部平均，也不是只选择一个，而是**按照注意力大小，对所有历史信息进行加权聚合**。这就是 Attention 名字的真正含义。

一个类比：老师问"介绍一下 Transformer"，你的脑海里不会随机回忆所有知识，而是不同内容占据不同权重（Attention 45%、Self-Attention 30%、GPT 15%……），最后融合起来形成回答。

---

# 从 Attention Score 到 Attention 输出

回顾整个推导：①保存全部历史 Token；②用 Dot Product 计算相关程度，得到 Attention Score；③经过 Softmax，得到 Attention Weight；④按权重融合所有 Value，得到新的表示。整个过程没有任何神秘公式，只是一步一步自然推导出来的。

现在终于可以看懂论文中的公式：

```
Attention = Softmax(Score) × Value
```

如果把 Score 换成 Dot Product `QKᵀ`，就变成：

```
Attention(Q, K, V) = Softmax(QKᵀ) V
```

这已经不是新知识，只是把我们刚刚完成的五个步骤写成了一行数学表达式。

---

# 补一个小细节：为什么要除以 √d

10.2 节提过一个"欠账"：Dot Product 数值会随着向量维度增大而越来越大。想象一下，把 Embedding 维度从这里的 2 维扩大到真实模型常用的 512 维甚至更高——每一位的乘积累加起来，Score 很容易膨胀到几十、几百。这会带来一个实际问题：Score 差距过大时，Softmax 会变得**过于"尖锐"**（几乎只有最大值那一项概率接近1，其余都接近0），对应的梯度也会趋近于0，训练会因此变得困难。

解决办法很直接：**把 Score 除以一个和维度相关的数，缩小它的数值范围。** Transformer 论文选择的是 `√d_k`（`d_k` 是 Q、K 向量的维度）——用维度的平方根来缩放，是因为 Dot Product 的数值大小大致会随维度线性增长，除以 `√d_k` 正好能把它稳定在一个合适的范围。加上这一步，完整公式变成：

```
Attention(Q, K, V) = Softmax(QKᵀ / √d_k) V
```

这正是论文原文的名字——**Scaled Dot-Product Attention（缩放点积注意力）**。至此，本章前面推导出的每一步都已经对应上了论文公式里的每一个符号。
