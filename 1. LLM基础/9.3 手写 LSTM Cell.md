# 实验 9.3：手写 LSTM Cell

> **硬件要求**：CPU 即可运行（普通笔记本可跑）

## 实验目标

第 9 章主章节已经讲完 LSTM 的概念。本实验用 NumPy 从"可控 Memory"到"Cell State + 三个门"，逐步手写一次完整的 LSTM 更新，最后体验信息瓶颈。

---

## 一、可控 Memory：从机械更新到有选择

普通 RNN 的 Memory 更新是机械的，没有任何选择。真正可控的 Memory 应该能"决定"哪些保留、哪些删除：

```python
memory = ["Alice"]

token = "天气很好"
if "天气" not in token:
    memory.append(token)
print(memory)  # ['Alice']

token = "Alice 是教授"
if "天气" not in token:
    memory.append(token)
print(memory)  # ['Alice', 'Alice 是教授']
```

当然，真正的神经网络不会写 `if "天气" in token` 这样的规则，而是通过训练自己学习哪些重要、哪些可以忘，但思想完全一样：**Memory 应该具有选择能力**。这个"选择"能力，就由 LSTM 的三个门来实现。

---

## 二、两种状态：Cell State 与 Hidden State

LSTM 的关键创新是准备了两份 Memory：Hidden State 负责当前计算，Cell State 负责长期保存。先用一个极简例子体会"Cell 不变、Hidden 变化"：

```python
cell = "Alice"
hidden = ""

tokens = ["今天下雨", "天气很好", "吃了午饭"]
for token in tokens:
    hidden = token
    print("Cell:", cell, "| Hidden:", hidden)
```

输出：

```text
Cell: Alice | Hidden: 今天下雨
Cell: Alice | Hidden: 天气很好
Cell: Alice | Hidden: 吃了午饭
```

Hidden 一直变化，但 Cell 完全没有变化，一直保存着 `Alice`。真正的 LSTM 不会用字符串，而是高维向量，但思想完全一致。

---

## 三、Forget Gate：选择性遗忘

延续本章例子：假设模型处理完 `I love AI` 后，LSTM 的 Cell State 是一个 2 维向量。Forget Gate 输出一个 0~1 的向量，按维度控制旧 Cell State 保留多少：

```python
import numpy as np

cell = np.array([8, 4])       # 当前 Cell State
forget = np.array([0.8, 0.5])  # Forget Gate，每一维有不同的保留比例

kept = forget * cell
print(kept)  # [6.4 2. ]
```

第一维保留了 80%（`8→6.4`），第二维只保留了 50%（`4→2.0`）——这意味着 LSTM 不是整体忘记，而是**按特征维度选择性遗忘**。这组 `kept = [6.4, 2.0]` 会在下一节继续使用。

---

## 四、Input Gate 与 Candidate Memory

Forget Gate 管"旧 Memory"，Input Gate 管"新 Memory"。候选记忆（Candidate）是"建议写入内容"，Input Gate 决定"写多少"：

```python
import numpy as np

kept = np.array([6.4, 2.0])     # 来自上一节
candidate = np.array([3, 6])     # 候选记忆（Candidate Memory）
input_gate = np.array([0.5, 0.5])  # Input Gate

written = input_gate * candidate
print(written)  # [1.5 3. ]
```

输出 `[1.5, 3.0]`——候选记忆只写入了一半。

---

## 五、一次完整的 Cell State 更新

把 Forget 与 Input 合起来，就是一次完整的 Cell State 更新：

```python
new_cell = kept + written
print(new_cell)  # [7.9 5. ]
```

计算过程：保留 `[6.4, 2.0]`，新增 `[1.5, 3.0]`，最终 `new_cell = [7.9, 5.0]`。对应公式 `Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ`。这组 `new_cell` 会在下一节继续用它计算 Output Gate。

---

## 六、Output Gate 与 Hidden State

标准 LSTM 的 Hidden State 不是 `output_gate × cell_state`，而是：

```
hₜ = oₜ × tanh(Cₜ)
```

`tanh` 先把 Cell State 压缩到 `[-1,1]`，Output Gate 再控制各维度有多少进入当前 Hidden State：

```python
import numpy as np

new_cell = np.array([7.9, 5.0])
output_gate = np.array([0.7, 0.6])

hidden = output_gate * np.tanh(new_cell)
print(hidden)  # [0.7000 0.5999]
```

Cell State 本身没有因此减少；变化的是当前时刻传给下一时间步或上层网络的 Hidden State。需要特别区分：`hₜ` 仍是隐藏表示，并不是词表上的预测概率。语言建模还需要输出投影与 Softmax，例如 `logitsₜ = W_y hₜ + b_y`、`p(yₜ)=softmax(logitsₜ)`。

---

## 七、手写一次完整的 LSTM 更新

把上面三节串起来，就是一次完整的 LSTM 更新：

```python
import numpy as np

old_cell = np.array([8, 4])
forget = np.array([0.8, 0.5])
candidate = np.array([3, 6])
input_gate = np.array([0.5, 0.5])
output_gate = np.array([0.7, 0.6])

new_cell = forget * old_cell + input_gate * candidate  # 更新 Cell State
hidden = output_gate * np.tanh(new_cell)                 # 标准 LSTM：生成 Hidden State

print("Cell:", new_cell)     # [7.9 5. ]
print("Hidden:", hidden)     # [0.7000 0.5999]
```

计算过程：旧记忆 `[8,4]` 经 Forget Gate 后保留 `[6.4,2.0]`；候选记忆 `[3,6]` 经 Input Gate 后写入 `[1.5,3.0]`；新 Cell 为 `[7.9,5.0]`。随后 `tanh(new_cell)≈[1.0000,0.9999]`，再乘 Output Gate `[0.7,0.6]`，得到 Hidden `[0.7000,0.5999]`。

## 八、体验信息瓶颈

最后体验一下 LSTM 的极限：无论 Cell State 多大，它仍然是固定长度，信息压缩不可避免。

```python
sentence = ["Alice", "毕业于清华", "加入 Google", "研究 Transformer", "获得最佳论文奖", "成为教授"]
memory = "Alice 很优秀"  # 假设只能保存一句摘要
```

请思考：`毕业于清华、加入 Google、Transformer、最佳论文、教授` 这些信息是否还在？答案：几乎全部丢失。

为什么不能把 Cell State 变得越来越大（128 → 512 → 2048 → 100000）？理论上当然可以，但代价越来越高，而且无论多大，最终仍然是**固定长度**。只要输入序列继续增长，信息压缩仍然不可避免——这正是下一章 Attention 要解决的信息瓶颈。
