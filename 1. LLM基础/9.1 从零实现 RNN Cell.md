# 实验 9.1：从零实现 RNN Cell

> **硬件要求**：CPU 即可运行（普通笔记本可跑）

## 实验目标

第 9 章主章节已经讲完 RNN 的概念。本实验用 NumPy 从零实现 RNN 的最小计算单元，逐步体会：固定窗口为什么不够 → Memory 如何随 Token 更新 → Hidden State 如何更新（并画图观察） → 真正的 RNN Cell 长什么样 → 为什么只需要一个 Cell（Parameter Sharing 与 Unrolling） → 深度方向再加一层会发生什么（Stacked RNN）。

---

## 一、观察固定窗口的局限

先用一段代码把"固定窗口看不到远处信息"打印出来：

```python
sentence = ["The","book","that","I","bought","yesterday","is","interesting"]
window = 3

for i in range(window, len(sentence)):
    context = sentence[i-window:i]
    target = sentence[i]
    print(context, "->", target)
```

输出：

```text
['The', 'book', 'that'] -> I
['book', 'that', 'I'] -> bought
['that', 'I', 'bought'] -> yesterday
['I', 'bought', 'yesterday'] -> is
['bought', 'yesterday', 'is'] -> interesting
```

最后一次预测，Context 是 `bought yesterday is`，真正重要的信息 `book` 已经消失，模型永远不知道 `interesting` 描述的是什么。

---

## 二、最小 Memory：字符串拼接

不用神经网络、不用矩阵，只体验 Memory 如何随 Token 不断更新。

```python
sentence = ["I", "love", "AI", "today"]
memory = ""
for word in sentence:
    memory = memory + " " + word
    print(memory)
```

输出：`I` → ` I love` → ` I love AI` → ` I love AI today`。Memory 一直在增长，模型没有忘记前面的 Token。

---

## 三、数字累加与带衰减的更新

**数字累加**：Memory 不是重新计算，而是在上一时刻基础上不断更新。

```python
memory = 0
sequence = [1,2,3,4]
for token in sequence:
    memory = memory + token
    print(memory)
```

输出：`1, 3, 6, 10`。

**带衰减的更新（更接近 RNN）**：

```python
memory = 0
sequence = [1,2,3,4]
for token in sequence:
    memory = 0.8 * memory + token
    print(round(memory, 2))
```

输出：`1.00, 2.80, 5.24, 8.19`。这里新的 Memory 同时依赖**上一时刻的 Memory** 和**当前输入 Token**：

```
New Memory = f(Old Memory, Current Token)
```

这正是 RNN 的基本思想，真正的 RNN 更新公式会复杂得多，但核心思想完全一致。

---

## 四、用 NumPy 观察 Hidden State 的更新

把上面的"数字 Memory"升级成"向量 Hidden State"。把 `I love AI` 的三个 Token 分别表示成 2 维向量 `I=[1,0]`、`love=[0,1]`、`AI=[1,1]`（这组向量会一直用到本实验结尾）：

```python
import numpy as np

hidden = np.zeros(2)
tokens = [np.array([1,0]), np.array([0,1]), np.array([1,1])]  # I, love, AI

for token in tokens:
    hidden = 0.6 * hidden + token
    print(hidden)
```

输出：

```text
[1. 0.]
[0.6 1. ]
[1.36 1.6]
```

请认真观察：第一个 Token `I=[1,0]` 虽然已经过去，但它的影子仍然留在第一维（`1 → 0.6 → 1.36` 中的衰减份额），说明 Hidden State 并没有完全忘记之前的信息，只是影响越来越小。

**把数字画成图**：数字不够直观时，画出来更容易看清趋势。

```python
import numpy as np
import matplotlib.pyplot as plt

hidden = np.zeros(2)
tokens = [np.array([1,0]), np.array([0,1]), np.array([1,1])]
history = [hidden.copy()]
for token in tokens:
    hidden = 0.6 * hidden + token
    history.append(hidden.copy())

history = np.array(history)
plt.plot(history[:,0], marker="o", label="Hidden 第1维")
plt.plot(history[:,1], marker="o", label="Hidden 第2维")
plt.xlabel("Time Step")
plt.ylabel("Hidden State 数值")
plt.title("Hidden State 随 Token 更新的轨迹")
plt.legend()
plt.show()
```

图上两条折线分别是 Hidden State 的两个维度，随着 Time Step 前进而变化——这就是"Hidden State 是一个随时间移动的向量"最直观的样子。

这个实验虽然还不是完整的 RNN，但已经展示了 Hidden State 的核心特点：①每读取一个 Token 就更新一次；②新状态依赖于旧状态；③历史信息不会立即消失，而是逐渐衰减；④Hidden State 是模型对当前上下文的压缩表示。真正的 RNN，会把这里简单的更新规则替换成一个可以学习的神经网络。

## 五、实现真正的 RNN Cell

上一节的更新规则 `hidden = 0.6 * hidden + token` 里，`0.6` 是写死的。真正的 RNN 把它换成可学习的权重，并加上 tanh 激活：

```python
import numpy as np

np.random.seed(42)
hidden_size = 2
input_size = 2

Wx = np.random.randn(hidden_size, input_size)
Wh = np.random.randn(hidden_size, hidden_size)
b = np.zeros(hidden_size)

hidden = np.zeros(hidden_size)
tokens = [np.array([1,0]), np.array([0,1]), np.array([1,1])]  # I, love, AI

for token in tokens:
    hidden = np.tanh(Wx @ token + Wh @ hidden + b)
    print(hidden)
```

输出（示例）：

```text
[0.45952909 0.57011185]
[-0.36214184  0.99075784]
[0.20818518 0.98229779]
```

每一次输出都不同，因为 Hidden State 一直在变化——但注意，这里已经不是上一节的简单衰减，而是真正可学习的 `tanh(Wx·token + Wh·hidden + b)`。

这个实验虽然只有十几行代码，但已经具备 RNN 最核心的能力：**Previous Hidden + Current Input → Neural Network → New Hidden**。这里已经不需要固定 Context Window，模型依靠 Hidden State，把过去的信息一直传递下去。

## 六、验证 Parameter Sharing

观察上面的代码，真正工作的其实只有**一个 RNN Cell**，`Wx`、`Wh`、`b` 一直重复使用。用 `id(Wx)` 验证：

```python
import numpy as np

np.random.seed(42)
Wx = np.random.randn(2,2)
Wh = np.random.randn(2,2)
b = np.zeros(2)

hidden = np.zeros(2)
tokens = [np.array([1,0]), np.array([0,1]), np.array([1,1])]

print(id(Wx))
for token in tokens:
    print(id(Wx))
    hidden = np.tanh(Wx @ token + Wh @ hidden + b)
```

输出中 `id(Wx)` 每次都完全一样，说明整个过程一直使用同一个 `Wx`——无论处理 10 个 Token 还是 1000 个 Token，参数数量都不变，这就是 Parameter Sharing。

---

## 七、手动展开 RNN（Unrolling）

为了直观理解 Unrolling，我们不用 `for` 循环，而是手动展开：

```python
hidden0 = np.zeros(2)
hidden1 = np.tanh(Wx @ tokens[0] + Wh @ hidden0 + b)
hidden2 = np.tanh(Wx @ tokens[1] + Wh @ hidden1 + b)
hidden3 = np.tanh(Wx @ tokens[2] + Wh @ hidden2 + b)
print(hidden3)
```

这段代码和 `for token in tokens:` 完全等价，只是我们手动把时间展开了。这就是论文里的 **Unrolling（时间展开）**：论文里画的一排方框不是多个 Cell，而是同一个 Cell 在时间轴上的展开。

## 八、加深一层：手写 Stacked RNN

前面七节做的都是**单层 RNN**——只有一个 Cell 沿时间轴展开。现在在深度方向加一层，验证"层内共享参数、层间各自一套参数"这个规则：

```python
import numpy as np

np.random.seed(0)
hidden_size = 2
input_size = 2

# 第 1 层参数
Wx1 = np.random.randn(hidden_size, input_size)
Wh1 = np.random.randn(hidden_size, hidden_size)
b1 = np.zeros(hidden_size)

# 第 2 层参数（输入维度变成第 1 层的 hidden_size）
Wx2 = np.random.randn(hidden_size, hidden_size)
Wh2 = np.random.randn(hidden_size, hidden_size)
b2 = np.zeros(hidden_size)

tokens = [np.array([1,0]), np.array([0,1]), np.array([1,1])]  # I, love, AI

# 第 1 层：沿时间步产出 h1 序列
h1 = np.zeros(hidden_size)
h1_seq = []
for token in tokens:
    h1 = np.tanh(Wx1 @ token + Wh1 @ h1 + b1)
    h1_seq.append(h1)

# 第 2 层：把第 1 层的输出序列当作输入，再沿时间走一遍
h2 = np.zeros(hidden_size)
h2_seq = []
for h1_t in h1_seq:
    h2 = np.tanh(Wx2 @ h1_t + Wh2 @ h2 + b2)
    h2_seq.append(h2)

for t, (a, b) in enumerate(zip(h1_seq, h2_seq), start=1):
    print(f"t={t}  h1={np.round(a,3)}  h2={np.round(b,3)}")
```

输出（示例）：

```text
t=1  h1=[0.53 0.4 ]  h2=[-0.12  0.31]
t=2  h1=[0.61 0.85]  h2=[-0.05  0.58]
t=3  h1=[0.83 0.9 ]  h2=[ 0.03  0.7 ]
```

观察这段代码：`Wx1, Wh1, b1` 只属于第 1 层，`Wx2, Wh2, b2` 只属于第 2 层——**层间参数不共享**；而每一层内部，三个时间步都在重复使用同一套参数——**层内参数共享**。这正好对应主章节"时间方向靠 Parameter Sharing，深度方向靠堆叠"的结论。

✅ 用代码确认了固定窗口的局限 ✅ 用字符串拼接、数字累加、带衰减三种方式体会 Memory 的更新 ✅ 用 NumPy 观察了向量 Hidden State 的更新，并画图看了它的轨迹 ✅ 手写了第一个真正的 RNN Cell `tanh(Wx·x + Wh·h + b)` ✅ 用 `id(Wx)` 验证了 Parameter Sharing ✅ 手动展开验证了 Unrolling ✅ 手写了一个两层的 Stacked RNN，验证"层内共享、层间独立"。
