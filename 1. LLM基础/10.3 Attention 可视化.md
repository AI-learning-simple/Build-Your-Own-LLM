# 实验 10.3：Attention 可视化

> **硬件要求**：CPU 即可运行，需要 `matplotlib`（普通笔记本可跑）

## 实验目标

第 10 章主章节已经说明：Attention Matrix 全是数字时很难读懂，通常画成**热力图（Heatmap）**。本实验把 10.2 节算出的注意力权重画成热力图，观察每个 Query 行如何在各 Key 上分配权重，并说明解读边界。

---

## 一、画 Attention Heatmap

继续用 10.2 节的 Scaled Dot-Product 教学矩阵（`The cat is sleeping`）：

```python
import matplotlib.pyplot as plt
import numpy as np

attention = np.array([
    [0.259, 0.250, 0.245, 0.245],
    [0.149, 0.360, 0.144, 0.348],
    [0.249, 0.245, 0.258, 0.249],
    [0.149, 0.355, 0.149, 0.348],
])  # 来自 10.2 节 Scaled Dot-Product 教学矩阵
tokens = ["The", "cat", "is", "sleeping"]

plt.imshow(attention)
plt.xticks(range(4), tokens)
plt.yticks(range(4), tokens)
plt.colorbar()
plt.show()
```

运行后会得到一张真正的 Attention Heatmap：`cat` 和 `sleeping` 所在的格子会明显更深，`The`、`is` 那两行则接近均匀的浅色。

---

## 二、如何读取热力图

颜色越深，表示 Attention Weight 越大；颜色越浅，表示权重越小。这张矩阵的每一行是一个 Query，每一列是一个 Key。观察 `cat` 这一行（第二行）：它对自己和 `sleeping` 的权重较大，说明"站在 `cat` 的视角"，它主要关注自己和谓语动作。

---

## 三、解读边界

这里要特别强调：这张矩阵来自**人工指定的二维向量**，并没有经过训练，因此它只能演示"如何读取热力图"，**不能据此声称模型学到了语法或语义关系**。

在真实的已训练模型中，某些 Head 可能对依存关系、相邻位置或标点呈现统计上的偏好，但需要在大量样本上验证，不能凭单张图下结论。Attention Weight 也不等同于完整的因果解释；严谨分析需要跨样本统计，并结合消融等方法。

---
