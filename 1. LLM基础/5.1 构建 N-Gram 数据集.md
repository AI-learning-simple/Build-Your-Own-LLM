# 实验 5.1：构建 N-Gram 数据集

> **实验目标**
>
> 把一段 Token 序列转换成固定窗口的 `(Context, Target)` 样本。完成本实验后，你将能亲手验证第 5 章介绍的 Context Window、Sliding Window 与样本数量公式。

开始前，请先阅读 [第5章：固定上下文与 N-Gram 语言模型](./5.%20固定上下文与%20N-Gram%20语言模型.md)。本实验只实现主章已经讲过的结构，不引入新的语言模型概念。

---

# 一、明确输入与输出

使用句子：

```text
I love AI today
```

它包含 4 个 Token。令 `window_size = 2`，也就是每个 Context 包含 Target 左侧最近的 2 个 Token。根据主章的公式，样本数为：

$$
\text{sample count}=L-W=4-2=2
$$

**这个公式的作用**：计算长度为 `L` 的单条 Token 序列，在窗口长度为 `W` 且每个位置都预测紧随其后的一个 Target 时，可以产生多少个滑动窗口样本。这里 `L=4、W=2`，因此只有两个合法起点。

预期得到：

```text
[I, love] -> AI
[love, AI] -> today
```

注意：窗口大小是 Context 长度。这里的 Context 长度为 2，Context 与 Target 合起来包含 3 个连续 Token，按标准 N-Gram 命名属于 Trigram 样本。

---

# 二、先手动移动窗口

窗口从序列开头出发：

1. 取位置 0、1 的 `[I, love]` 作为 Context，位置 2 的 `AI` 作为 Target；
2. 整个窗口右移一格，取 `[love, AI]` 作为 Context，`today` 作为 Target；
3. 此时 Target 已经到达序列末尾，停止。

只要让 Target 的位置 `i` 从 `window_size` 走到序列末尾，就能完成这个过程。对应的 Context 切片是 `tokens[i - window_size:i]`，Target 是 `tokens[i]`。

---

# 三、实现数据集生成函数

```python
def build_context_samples(tokens, window_size):
    samples = []

    for i in range(window_size, len(tokens)):
        context = tokens[i - window_size:i]
        target = tokens[i]
        samples.append((context, target))

    return samples
```

函数不负责理解 Token 的语义，只负责保持原顺序，并把每个 Target 与它左侧固定长度的 Context 配对。

---

# 四、完整代码

```python
#!/usr/bin/env python3


def build_context_samples(tokens, window_size):
    samples = []

    for i in range(window_size, len(tokens)):
        context = tokens[i - window_size:i]
        target = tokens[i]
        samples.append((context, target))

    return samples


sentence = ["I", "love", "AI", "today"]
window_size = 2
samples = build_context_samples(sentence, window_size)

print("Token 数量:", len(sentence))
print("Context Window:", window_size)
print("样本数量:", len(samples))

for context, target in samples:
    print(context, "->", target)
```

---

# 五、运行结果

```text
Token 数量: 4
Context Window: 2
样本数量: 2
['I', 'love'] -> AI
['love', 'AI'] -> today
```

结果与手动推导一致：原始句子包含 4 个 Token，窗口大小为 2，因此生成 $4-2=2$ 条样本。

---

# 六、改变窗口大小

把 `window_size` 改为 `3`：

```python
window_size = 3
samples = build_context_samples(sentence, window_size)

for context, target in samples:
    print(context, "->", target)
```

运行结果：

```text
['I', 'love', 'AI'] -> today
```

Context 变长后，模型的每次输入能包含更多历史，但同一个短句能够提供的完整窗口样本也减少了：此时只有 $4-3=1$ 条。

---

# 七、实验分析

这个生成器完成了三件事：

1. **保持词序**：Context 中 Token 的先后顺序没有改变；
2. **固定输入长度**：每条 Context 都恰好包含 `window_size` 个 Token；
3. **避免偷看未来**：Target 只由它左侧的 Context 预测。

生成的 `samples` 还不是一个会预测的模型，它只是训练数据。下一实验会把多条样本中相同 Context 的 Target 汇总计数，再将计数归一化成条件概率。
