# 一、把 4.8 节的公式接到真实 Logits 上

```python
#!/usr/bin/env python3
import numpy as np

id2word = {0:"I", 1:"love", 2:"AI", 3:"today"}
context = [1, 2]                                 # [love, AI]，来自 6.2 节
target = 3                                        # 真实答案：today
logits = np.array([2.305, -0.8975, 1.0104, -1.446])   # 来自 6.2 节，context=[love,AI] 算出的 Logits

shifted = logits - np.max(logits)
exp = np.exp(shifted)
prob = exp / np.sum(exp)

for i, p in enumerate(prob):
    mark = " ← 真实答案" if i == target else ""
    print(f"{id2word[i]:<8} {p:.3f}{mark}")
print("Sum:", prob.sum())
```

```text

love     0.030
AI       0.205
today    0.018 ← 真实答案
Sum: 1.0
```

# 二、第一次真正做出预测：Greedy Decoding

之前的 Logits/概率都只是一组数字,还没有选出"下一个 Token 到底是谁"。最简单的选择方式是直接取概率最大的那个:

```python
prediction = np.argmax(prob)
print(id2word[prediction])  # I
```

模型认为下一个 Token 最可能是 `I`，但真实答案（代码里已经写明的 `target = 3`，也就是 `today`）——这次预测**错了**，而且错得比较明显：正确答案 `today` 只拿到 1.8% 的概率，反而是 `I` 独占了 74.7%。这个错误结果 6.4 节会用来计算 Loss。
