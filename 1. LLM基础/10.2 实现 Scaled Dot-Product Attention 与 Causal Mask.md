# 实验 10.2：实现缩放点积注意力（Scaled Dot-Product Attention）与因果掩码（Causal Mask）

> **硬件要求**：CPU 即可运行（普通笔记本可跑）

## 实验目标

第 10 章主章节已经给出 Attention 的完整公式。本实验把上一节"手算一个 Query"升级为"整个句子一次计算"：引入 Q、K、V 投影，用 NumPy 实现完整的 Scaled QKV Attention，并对比 Full Attention 与 Causal Attention。

---

## 一、Q、K、V 的投影

标准 Self-Attention 先投影，再做缩放点积。为隔离 QKV、缩放和 Mask 的作用，本实验把三个投影矩阵设为单位阵（`IX = X`，投影等于没投影，Q/K/V 退化成输入 X 本身——见第 10 章第七节的说明）；训练模型中的 `W_Q/W_K/W_V` 都是独立可学习参数：

```python
import numpy as np

X = np.array([
    [0.1, -0.2],   # The
    [1.0,  0.5],   # cat
    [-0.1, 0.1],   # is
    [0.9,  0.6],   # sleeping
])
W_Q = np.eye(2)
W_K = np.eye(2)
W_V = np.eye(2)

Q, K, V = X @ W_Q, X @ W_K, X @ W_V
d_k = Q.shape[-1]
scores = Q @ K.T / np.sqrt(d_k)
```

其中 `scores = Q @ K.T / √d_k` 就是 **Scaled Dot-Product Attention** 的"缩放点积"部分。

---

## 二、完整的 Scaled QKV Attention

补上 Softmax 与 `AV`，得到完整的 Attention 输出：

```python
def softmax(x):
    exp = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return exp / exp.sum(axis=-1, keepdims=True)

full_attention = softmax(scores)
full_output = full_attention @ V

print("Full attention:\n", np.round(full_attention, 3))
print("Output shape:", full_output.shape)
```

输出：

```text
Full attention:
[[0.259 0.250 0.245 0.245]
 [0.149 0.360 0.144 0.348]
 [0.249 0.245 0.258 0.249]
 [0.149 0.355 0.149 0.348]]
Output shape: (4, 2)
```

注意 `cat` 这一行（第二行）对自己和 `sleeping` 的权重更大，和上一节"站在 `cat` 视角"手算的结论一致；只是现在整个句子的所有 Query 行一次都算出来了。

---

## 三、Full Attention 与 Causal Attention

Decoder-only 语言模型还会在未来位置加入 Causal Mask，使位置 `i` 只能查看 `j≤i` 的 Key。用严格上三角矩阵做掩码：

```python
causal_mask = np.triu(np.ones_like(scores, dtype=bool), k=1)
causal_scores = np.where(causal_mask, -np.inf, scores)
causal_attention = softmax(causal_scores)
causal_output = causal_attention @ V

print("Causal attention:\n", np.round(causal_attention, 3))
print("Output shape:", causal_output.shape)
```

输出：

```text
Causal attention:
[[1.000 0.000 0.000 0.000]
 [0.292 0.708 0.000 0.000]
 [0.331 0.326 0.343 0.000]
 [0.149 0.355 0.149 0.348]]
Output shape: (4, 2)
```

两者都执行完整的 `QKᵀ/√d_k → Mask → Softmax → AV`，区别只在 Mask：Full Attention 没有屏蔽位置，Causal Attention 的严格上三角权重为 0（每个 Query 看不到未来位置）。由于这里的 Embedding 与投影均为人工设定，矩阵只用于验证计算，不能解释为训练模型学到的语言关系。

---

## 四、Attention Matrix 与 O(N²)

把 `full_attention` 打印成矩阵后，可以直观看到：若序列有 `N` 个 Token，就形成 `N×N` 个分数，这就是 **Attention Matrix**。这里 `N=4`，所以是 `4×4`；若 `N=512`，就是 `512×512`。分数计算量约为 `O(N²d_k)`，矩阵本身占用 `O(N²)` 内存——常说 Attention 对序列长度是"平方复杂度"，指的就是这个 `N²` 因子。

Transformer 能并行，正是因为 `Q @ K.T` 一次算完"所有 Query × 所有 Key"，整句可以一次送进 GPU，而不像 RNN 那样必须逐步串行。

---

## 本实验总结

✅ 用单位阵演示了 Q、K、V 投影 ✅ 实现了完整的 Scaled QKV Attention（`softmax(QKᵀ/√d_k)V`）✅ 对比了 Full Attention 与 Causal Attention 的 Mask 差异 ✅ 确认了 Attention Matrix 的 `N²` 规模与并行性。
