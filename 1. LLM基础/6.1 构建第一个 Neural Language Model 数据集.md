# Experiment 6.1：构建第一个 Neural Language Model 数据集

## 实验目标

本实验将实现 Neural Language Model 的第一步：将一句自然语言转换成神经网络可以训练的数据。实验结束后，你将理解什么是 Context Window、什么是 Target Token、神经网络为什么不能直接输入一句话，以及为什么 Language Model 的训练数据都是 `(Context → Target)` 对。

最终效果：

```text
I love AI today
↓
Context          Target
[I, love]->   AI
[love, AI]  ->   today
```

---

# 一、实验原理

上一章已经介绍了 Context Window。假设 `I love AI today`，窗口大小为 2，神经网络一次只能看到 `[I love]` 预测 `AI`，随后窗口继续向前滑动，看到 `[love AI]` 预测 `today`。于是整个句子就变成了很多训练样本，这也是所有 Language Model 最基础的数据组织方式。

---

# 二、准备数据

```python
sentence = ["I", "love", "AI", "today"]

vocab = {"I":0, "love":1, "AI":2, "today":3}

token_ids = [vocab[word] for word in sentence]
print(token_ids)  # [0,1,2,3]
```

---

# 三、生成训练样本

```python
window_size = 2

samples = []
for i in range(window_size, len(token_ids)):
    context = token_ids[i-window_size:i]
    target = token_ids[i]
    samples.append((context, target))

for context, target in samples:
    print(context, "->", target)
```

输出：

```text
[0,1] -> 2
[1,2] -> 3
```

已经成功得到 `(Context → Target)` 数据。

---

# 四、恢复成单词查看

```python
id2word = {v: k for k, v in vocab.items()}

for context, target in samples:
    words = [id2word[i] for i in context]
    print(words, "->", id2word[target])
```

输出：

```text
['I','love'] -> AI
['love','AI'] -> today
```

现在终于可以直观看见Language Model 的训练数据。

---

# 五、完整代码

```python
#!/usr/bin/env python3
sentence = ["I", "love", "AI", "today"]
vocab = {"I":0, "love":1, "AI":2, "today":3}
id2word = {v: k for k, v in vocab.items()}
token_ids = [vocab[word] for word in sentence]

window_size = 2
samples = []
for i in range(window_size, len(token_ids)):
    context = token_ids[i-window_size:i]
    target = token_ids[i]
    samples.append((context, target))

print("="*40)
for context, target in samples:
    words = [id2word[i] for i in context]
    print(words, "->", id2word[target])
```

---

# 六、运行结果

```text
========================================
['I', 'love'] -> AI
['love', 'AI'] -> today
```

---

# 七、实验分析

请注意，模型真正学习的并不是 `AI → today`，而是 `[I love] → AI`。因此 Language Model 的输入永远都是 Context，输出永远都是 Next Token。后面所有 GPT、LLaMA、Qwen，训练数据组织方式都没有改变。
