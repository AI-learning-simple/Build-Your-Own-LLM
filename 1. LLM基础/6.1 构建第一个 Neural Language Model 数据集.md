# Experiment 6.1：构建第一个 Neural Language Model 数据集

## 实验目标

上一章 Experiment 5.1 已经用单词生成了 `(Context → Target)` 数据集。神经网络只吃数字，所以本实验只做一件事：把数据集里的单词换成 **Token ID**。实验结束后，你将理解为什么训练数据必须 ID 化，以及 `(Context → Target)` 在内存里的真实样子。

最终效果：

```text
I love AI today
↓
Context          Target
[I, love]->   AI
[love, AI]  ->   today
```

---

# 一、实验原理

上一章已经详细讲过 Context Window 和滑动窗口，这里不再重复。唯一的新变化：上一章的样本是单词（`['I','love'] → 'AI'`），神经网络无法直接处理字符串，必须先通过词表（Vocabulary）把每个单词映射成一个数字 ID——`I→0, love→1, AI→2, today→3`。这一步正是第 2 章 Tokenizer 做的事情（这里的词表极小，手动指定即可）。

---

# 二、准备数据

```python
sentence = ["I", "love", "AI", "today"]

vocab = {"I":0, "love":1, "AI":2, "today":3}

token_ids = [vocab[word] for word in sentence]
print(token_ids)  # [0,1,2,3]
```

---

# 三、生成训练样本

```python
window_size = 2

samples = []
for i in range(window_size, len(token_ids)):
    context = token_ids[i-window_size:i]
    target = token_ids[i]
    samples.append((context, target))

for context, target in samples:
    print(context, "->", target)
```

输出：

```text
[0,1] -> 2
[1,2] -> 3
```

已经成功得到 `(Context → Target)` 数据。

---

# 四、恢复成单词查看

```python
id2word = {v: k for k, v in vocab.items()}

for context, target in samples:
    words = [id2word[i] for i in context]
    print(words, "->", id2word[target])
```

输出：

```text
['I','love'] -> AI
['love','AI'] -> today
```

现在终于可以直观看见Language Model 的训练数据。

---

# 五、完整代码

```python
#!/usr/bin/env python3
sentence = ["I", "love", "AI", "today"]
vocab = {"I":0, "love":1, "AI":2, "today":3}
id2word = {v: k for k, v in vocab.items()}
token_ids = [vocab[word] for word in sentence]

window_size = 2
samples = []
for i in range(window_size, len(token_ids)):
    context = token_ids[i-window_size:i]
    target = token_ids[i]
    samples.append((context, target))

print("="*40)
for context, target in samples:
    words = [id2word[i] for i in context]
    print(words, "->", id2word[target])
```

---

# 六、运行结果

```text
========================================
['I', 'love'] -> AI
['love', 'AI'] -> today
```

---

# 七、实验分析

请注意，模型真正学习的并不是 `AI → today`，而是 `[I love] → AI`。因此 Language Model 的输入永远都是 Context，输出永远都是 Next Token。后面所有 GPT、LLaMA、Qwen，训练数据组织方式都没有改变。
