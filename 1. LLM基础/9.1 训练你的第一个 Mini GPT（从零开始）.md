# 9.1 训练你的第一个 Mini GPT（从零开始）

> **本节目标**：前面几节，我们亲手拼出了一个完整的 `TransformerBlock`（Multi-Head Attention + FFN + Residual + LayerNorm + Dropout）。但到目前为止，它只是一个"能跑通 forward"的空壳，从来没有真正训练过、也从来没有生成过一个字。本节，我们将用这个 `TransformerBlock` 拼出一个完整的 Mini GPT，从零开始训练，亲眼看着 Loss 下降、模型从"胡言乱语"变成"像话"。
>
> **硬件要求**：这是全书对硬件要求最低的一次实验。模型只有几百万参数，**8GB 显存的入门级显卡（如 RTX 3060/4060）绰绰有余，甚至纯 CPU 笔记本也能在几分钟内跑完**。这也是为什么我们先从"从零训练"开始：模型足够小，才有可能手写、可控、跑得动。

# 三、准备语料

用一段公开的中文文本作为训练语料，例如唐诗、《红楼梦》片段，或者任意几十 KB 的中文 txt 文件都可以。这里以字符级建模（复用第2章 Character Tokenizer 的思路）：

```python
# corpus.txt 放几百 KB 的中文文本即可，越多效果越好
text = open("corpus.txt", encoding="utf-8").read()

chars = sorted(set(text))
vocab_size = len(chars)
stoi = {ch: i for i, ch in enumerate(chars)}
itos = {i: ch for ch, i in stoi.items()}

def encode(s):
    return [stoi[c] for c in s]

def decode(ids):
    return "".join(itos[i] for i in ids)

data = encode(text)
print("语料长度:", len(data), "词表大小:", vocab_size)
```

---

# 四、构建训练样本

复用第6章的思路：每一个位置的输入是"前面一段连续 Token"，目标是"往后挪一位的同一段 Token"（Next Token Prediction 最直接的实现方式）：

```python
import torch

block_size = 64  # 上下文窗口长度（Context Window）

def get_batch(data, batch_size=32):
    idx = torch.randint(0, len(data) - block_size - 1, (batch_size,))
    x = torch.stack([torch.tensor(data[i:i + block_size]) for i in idx])
    y = torch.stack([torch.tensor(data[i + 1:i + block_size + 1]) for i in idx])
    return x, y
```

`x` 是输入，`y` 是 `x` 整体右移一位的结果——这正是第13章会正式命名的 **Next Token Prediction**。

# 五、拼出完整的 Mini GPT

结构非常直接：`Token Embedding + Position Embedding → N × TransformerBlock → LayerNorm → Linear（映射回词表）`。其中 `TransformerBlock` 直接复用本章前面实现的那个类：

```python
import torch.nn as nn

class TransformerBlock(nn.Module):
  def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
    super().__init__()
    self.ln1 = nn.LayerNorm(d_model)
    self.attn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
    self.dropout1 = nn.Dropout(dropout)
    self.ln2 = nn.LayerNorm(d_model)
    self.ffn = nn.Sequential(nn.Linear(d_model, d_ff), nn.GELU(), nn.Linear(d_ff, d_model))
    self.dropout2 = nn.Dropout(dropout)

  def forward(self, x, attn_mask=None):
    normed = self.ln1(x)
    attn_out, _ = self.attn(normed, normed, normed, attn_mask=attn_mask, need_weights=False)
    x = x + self.dropout1(attn_out)
    x = x + self.dropout2(self.ffn(self.ln2(x)))
    return x


class MiniGPT(nn.Module):
  def __init__(self, vocab_size, d_model=128, n_heads=4, d_ff=512, n_layers=4, block_size=64):
    super().__init__()
    self.token_emb = nn.Embedding(vocab_size, d_model)
    self.pos_emb = nn.Embedding(block_size, d_model)
    self.blocks = nn.ModuleList([TransformerBlock(d_model, n_heads, d_ff) for _ in range(n_layers)])
    self.ln_f = nn.LayerNorm(d_model)
    self.head = nn.Linear(d_model, vocab_size)
    self.block_size = block_size

  def forward(self, idx):
    B, T = idx.shape
    pos = torch.arange(T, device=idx.device)
    x = self.token_emb(idx) + self.pos_emb(pos)
    mask = torch.triu(torch.ones(T, T, device=idx.device), diagonal=1).bool()
    for block in self.blocks:
      x = block(x, attn_mask=mask)
    x = self.ln_f(x)
    return self.head(x)
```

整个模型只有 4 层、每层 4 个 Head、隐藏维度 128，参数量大约几百万——这就是为什么它能在 8GB 显存甚至 CPU 上轻松训练。

# 六、训练循环

复用第4、6章讲过的 Cross Entropy Loss 和梯度下降：

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
model = MiniGPT(vocab_size, block_size=block_size).to(device)
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)

for step in range(2000):
    x, y = get_batch(data)
    x, y = x.to(device), y.to(device)

    logits = model(x)  # (B, T, vocab_size)
    loss = nn.functional.cross_entropy(logits.view(-1, vocab_size), y.view(-1))

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if step % 200 == 0:
        print(f"step {step}, loss {loss.item():.3f}")
```

在 8GB 显卡上，这 2000 步通常只需要 1~3 分钟；纯 CPU 也能在十几分钟内跑完。观察 Loss：应该从初始的 `≈ log(vocab_size)`（模型完全随机瞎猜）逐渐降到一个明显更低的数字——这正是第4章讲过的"训练真正优化的是 Loss"在真实代码里的体现。

# 七、生成文字

训练完成后，用第13章即将正式讲解的自回归生成方式，一个 Token 一个 Token 地续写：

```python
@torch.no_grad()
def generate(model, prompt, max_new_tokens=100):
  model.eval()
  idx = torch.tensor([encode(prompt)], device=device)
  for _ in range(max_new_tokens):
    idx_cond = idx[:, -block_size:]
    logits = model(idx_cond)
    probs = torch.softmax(logits[:, -1, :], dim=-1)
    next_id = torch.multinomial(probs, num_samples=1)
    idx = torch.cat([idx, next_id], dim=1)
  return decode(idx[0].tolist())

print(generate(model, "床前明月光"))
```

# 八、训练前后对比

在训练刚开始（step 0）和训练结束（step 2000）分别调用一次 `generate`，你会清楚看到：

- **训练前**：输出几乎是随机字符的堆砌，毫无规律；
- **训练后**：输出开始出现语料中真实存在的词语搭配、常见句式，甚至偶尔押韵——虽然远远达不到 ChatGPT 的水平，但它确确实实"学到了一些东西"。

这个对比本身就是对前面章节全部理论最直接的验证：**Embedding、Attention、FFN、Residual、LayerNorm，这些模块组合起来，真的能够从数据中学习规律。**

# 九、这和真正的 GPT 差多少？

| | Mini GPT（本节） | GPT-2 Small | GPT-3 | GPT-4 级别 |
|---|---|---|---|---|
| 参数量 | ~500 万 | 1.24 亿 | 1750 亿 | 万亿级（推测，采用 MoE） |
| 层数 | 4 | 12 | 96 | 更多 + MoE |
| 训练数据 | 几十 KB | 40GB | 570GB | 数十 T Token |
| 训练硬件 | 8GB 显卡/CPU | 单卡 GPU 可训练 | 数千张 GPU | 数万张 GPU 集群 |

**结构上，它们没有本质差别**——都是 `Embedding → N × TransformerBlock → 输出层`。真正的差别只在于**规模**：更多参数、更多数据、更多算力。这正是第13章即将讲到的 **Scaling Law**。
