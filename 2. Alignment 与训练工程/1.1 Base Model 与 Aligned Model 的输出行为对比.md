# 1.1 Base Model 与 Aligned Model 的输出行为对比

> **本节目标**：第1章讲了很多关于 Alignment 的道理，但"Base Model 只会续写，Aligned Model 才会听指令"这句话，光看文字很难有真实体感。这一节我们直接加载同一个模型家族的两个版本——一个是纯 Pretraining 得到的 Base 版本，一个是经过 Alignment 之后的 Instruct 版本——用完全相同的输入，亲眼看看Alignment 到底改变了什么。
>
> **硬件要求**：本节使用的模型都在 5亿参数左右，CPU 或任意 8GB 以内显卡均可轻松运行。

我们选择 `Qwen2.5-0.5B`（Base）和 `Qwen2.5-0.5B-Instruct`（Aligned）——同一个模型家族、同一套参数规模，唯一的区别就是后者经过了 SFT + Preference Learning。

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

base_name = "Qwen/Qwen2.5-0.5B"
chat_name = "Qwen/Qwen2.5-0.5B-Instruct"

# Base：只经过 Pretraining，没有做过任何 Alignment
base_tok = AutoTokenizer.from_pretrained(base_name)
base_model = AutoModelForCausalLM.from_pretrained(base_name, torch_dtype=torch.float16, device_map="auto")

# Aligned：在同样的 Base 权重基础上，额外做了 SFT + Preference Learning
chat_tok = AutoTokenizer.from_pretrained(chat_name)
chat_model = AutoModelForCausalLM.from_pretrained(chat_name, torch_dtype=torch.float16, device_map="auto")
```

---

## 二、用完全相同的原始文本对比

先不用任何 Chat Template，直接把同一句话喂给两个模型，看它们如何"续写"：

```python
def generate_raw(model, tok, prompt, max_new_tokens=60):
    # 直接把原始文本喂给模型，不套用任何对话模板——模拟"最朴素的续写"场景
    inputs = tok(prompt, return_tensors="pt").to(model.device)
    output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=False)
    return tok.decode(output[0], skip_special_tokens=True)   # 这里连同输入一起解码，方便直接看到"续写"的效果

prompt = "帮我写一封请假邮件。"

print("=== Base Model ===")
print(generate_raw(base_model, base_tok, prompt))

print("\n=== Aligned Model（未使用Chat Template）===")
print(generate_raw(chat_model, chat_tok, prompt))
```

你会看到一个很有意思的现象：即使是 Aligned Model，如果不使用它专属的 Chat Template，它也可能表现得不那么"听话"——因为 Alignment 训练时用的数据格式是固定的对话结构，模型学到的"指令跟随"能力和这个格式是绑定的。

---

## 三、用正确的 Chat Template 再对比一次

```python
messages = [{"role": "user", "content": prompt}]
# add_generation_prompt=True 会在末尾补上"等待 assistant 开始回答"的模板标记
chat_input = chat_tok.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)

print("=== Aligned Model（使用 Chat Template）===")
print(generate_raw(chat_model, chat_tok, chat_input))
```

这一次，Aligned Model 会直接输出一封请假邮件的正文，而不会继续讲解"什么是邮件"。

## 四、多组Prompt 批量对比

```python
prompts = [
    "帮我写一封请假邮件。",
    "介绍一下 Transformer。",
    "1+1等于几？",
    "把这句话翻译成英文：今天天气真好。",
]

for p in prompts:
    print(f"\n########## Prompt: {p} ##########")

    print("--- Base ---")
    # Base Model 全程不使用 Chat Template，直接续写原始文本
    print(generate_raw(base_model, base_tok, p, max_new_tokens=40))

    # Aligned Model 每次都套用它专属的 Chat Template，才能发挥出真正的指令跟随能力
    chat_p = chat_tok.apply_chat_template([{"role": "user", "content": p}], tokenize=False, add_generation_prompt=True)
    print("--- Aligned ---")
    print(generate_raw(chat_model, chat_tok, chat_p, max_new_tokens=40))
```

仔细观察这几组输出，你会发现一个规律：Base Model 经常把输入当成一段文章的开头，继续"写下去"（可能开始介绍背景知识，也可能开始编故事）；而 Aligned Model 几乎总是直接**执行**这句话所代表的任务。**知识层面两者几乎没有差别（因为参数几乎一样），真正的差别全部体现在"行为"上**——这正是第1章反复强调的核心结论。
