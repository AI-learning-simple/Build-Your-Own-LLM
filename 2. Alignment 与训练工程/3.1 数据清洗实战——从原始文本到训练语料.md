# 3.1 数据清洗实战——从原始文本到训练语料

> **本节定位**：本节只做实践。归一化、去重、启发式过滤、质量筛选与数据配比的概念和边界见[第3章](<./3.%20数据工程——语料来源、清洗与配比.md>)，这里不重复讲解。

> **硬件要求**：CPU 即可运行。代码只使用 Python 标准库，不训练模型，也不调用模型 API。

本节用 7 条手工样本跑通前三步：保留正文格式 → 生成去重键并精确去重 → 按规则过滤。质量筛选与配比只说明扩展位置，不执行。

## 一、准备样本

```python
raw = [
    {"text": "机器学习是人工智能的一个分支。"},
    {"text": "机器学习是人工智能的一个分支。"},                  # 完全重复
    {"text": "  机器学习是人工智能的一个分支。  "},              # 重复但多了空格
    {"text": "<html><body>广告内容</body></html>"},
    {"text": "请联系我：test@example.com 或 138-0013-8000"},
    {"text": "深度学习"},                                        # 太短
    {"text": "机器学习是人工智能的一个分支，它研究计算机如何利用经验改善系统性能，广泛应用于推荐、搜索与自然语言处理等领域。"},
]
```

## 二、保留正文，生成去重键

正文要保留换行和缩进，去重键才做 Unicode 规范化与空白折叠。两者分开，避免清洗破坏代码和公式。

```python
import re
import unicodedata

def normalize(text):
    return text.replace("\r\n", "\n").replace("\r", "\n")

def dedup_key(text, preserve_layout=False):
    text = normalize(text)
    if preserve_layout:
        return text
    return re.sub(r"\s+", " ", unicodedata.normalize("NFKC", text)).strip()

text = "  机器学习（AI）是人工智能的一个分支。  "
print(repr(normalize(text)))
print(repr(dedup_key(text)))

code = "def f():\n    return 1\n"
assert normalize(code) == code
assert dedup_key(code, preserve_layout=True) == code
assert dedup_key("机器学习（AI）") == dedup_key("机器学习(AI)")
```

预期输出：

```text
'  机器学习（AI）是人工智能的一个分支。  '
'机器学习(AI)是人工智能的一个分支。'
```

第一行保留了正文首尾空格，第二行只是比较用的键。代码、公式、表格等格式敏感数据应显式传入 `preserve_layout=True`；函数不会自动判断文本是不是代码。

## 三、精确去重

对归一化后的键计算 SHA-256，只保留第一次出现的记录。

```python
import hashlib

def dedup_exact(records):
    seen, kept = set(), []
    for ex in records:
        text = normalize(ex["text"])
        preserve_layout = ex.get("preserve_layout", False)
        key = dedup_key(text, preserve_layout=preserve_layout)
        fingerprint = (preserve_layout, hashlib.sha256(key.encode("utf-8")).digest())
        if fingerprint in seen:
            continue
        seen.add(fingerprint)
        kept.append(text)
    return kept

kept = dedup_exact(raw)
print(f"原始 {len(raw)} 条 -> 去重后 {len(kept)} 条")
```

预期输出：

```text
原始 7 条 -> 去重后 5 条
```

7 条里去掉了 2 条重复，其中一条靠规范化后的键识别。返回的是第一次出现的正文，不是去重键。

精确去重只能处理键完全相等的情况；标题改写、转载加免责声明等近似重复需要 MinHash、SimHash 或 n-gram 重叠，本节不实现。

## 四、启发式过滤

用长度、HTML 残留、邮箱与手机号三类规则过滤。

```python
def is_html(t):
    """是否残留 HTML 标签/网页样板"""
    return bool(re.search(r"<html|</?div|</?p>| ", t))

def has_pii(t):
    """是否含个人敏感信息（PII）：邮箱、手机号"""
    return bool(re.search(r"[\w.+-]+@[\w-]+\.\w+|1[3-9]\d-?\d{4}-?\d{4}", t))

def filter_heuristic(texts, min_len=10):
    kept, dropped = [], []
    for n in texts:
        reasons = []
        if len(n) < min_len:
            reasons.append("过短")
        if is_html(n):
            reasons.append("HTML")
        if has_pii(n):
            reasons.append("含PII(邮箱/手机)")
        (dropped if reasons else kept).append((n, reasons))
    return kept, dropped
```

逐条打印判定结果：

```python
for n in kept:
    reasons = []
    if len(n) < 10:            reasons.append("过短")
    if is_html(n):             reasons.append("HTML")
    if has_pii(n):             reasons.append("含PII(邮箱/手机)")
    status = "丢弃:" + ",".join(reasons) if reasons else "保留"
    print(f"  [{len(n):>3}字符] {status}  {n[:38]}")
```

预期输出：

```text
  [ 15字符] 保留  机器学习是人工智能的一个分支。
  [ 30字符] 丢弃:HTML  <html><body>广告内容</body></html>
  [ 37字符] 丢弃:含PII(邮箱/手机)  请联系我：test@example.com 或 138-0013-8000
  [  4字符] 丢弃:过短  深度学习
  [ 55字符] 保留  机器学习是人工智能的一个分支，它研究计算机如何利用经验改善系统性能，广泛应用
```

三类规则都只是教学版本：

- `len()` 数的是字符，不是词元；短问答也可能有价值。
- HTML 过滤器只匹配少量标签，不是解析器；代码教程中的标签可能是正文。
- PII 命中后直接丢弃整条，没有脱敏，也没有覆盖所有隐私实体。

## 五、串成流水线并统计

```python
from collections import Counter

    print("丢弃原因:", dict(reasons))
    return [text for text, _ in accepted]

final = clean_pipeline(raw)
assert len(final) == 2
assert final == [raw[0]["text"], raw[-1]["text"]]
print(f"最终保留 {len(final)} / {len(raw)} 条，清洗掉 {len(raw) - len(final)} 条")
```

预期输出：

```text
去重丢弃 2 条；启发式丢弃 3 条
丢弃原因: {'HTML': 1, '含PII(邮箱/手机)': 1, '过短': 1}
最终保留 2 / 7 条，清洗掉 5 条
```

7 条样本保留 2 条，删除比例约 71%。这是规则演示，不是质量达标证明；真实管线还要分别抽检保留与丢弃样本，并记录每一步的删除原因。

## 六、本节未实现的部分

- **质量筛选**：在 `clean_pipeline` 之后接一个打分函数，对保留文本按规则或模型评分，再用抽检校准阈值。
- **近似去重**：在 `dedup_exact` 之后加 MinHash / SimHash 分桶。
- **数据配比**：准备多个来源的数据，明确按文档、字符还是词元计数，再在固定训练预算下做对照。

这些方法的概念与取舍见第3章，本节不展开。

## 实验边界

- 样例只有 7 条，规则和阈值不能直接外推到真实语料。
- 去重、HTML 检测与 PII 识别都是简化实现，存在漏判和误判。
- 没有训练模型，无法验证清洗对最终效果的影响。
- 配比统计依赖分词器与计数口径，换模型后数字会变化。

## 本节小结

本节跑通了“保留正文 → 生成去重键 → 精确去重 → 启发式过滤 → 统计结果”的最小流程。7 条样本最终保留 2 条，验证的是代码链路和统计方式，不是工业级数据治理效果。
