# 4.2 使用低秩适配（LoRA）微调一个模型——从基础模型（Base）到指令模型（Instruct）

> **本节目标**：第4章讲了 SFT（监督微调）——预训练模型只会"续写"，经过指令微调后才"听得懂人话"。本节，我们真正动手做一次微调：用 LoRA（Low-Rank Adaptation）把一个 Base 模型（未经过指令微调）训练成一个能遵循指令的模型，亲眼对比微调前后的行为差异。
>
> **硬件要求**：这是本书第一次真正的"训练"（而不是纯推理）。用 **QLoRA**（4-bit 量化 + LoRA）微调 `Qwen2.5-1.5B`（Base 版本），**显存占用约 4~6GB，8GB 显卡可以完成训练**（如果显存紧张，可以调小 batch size 或换成 0.5B 模型）。

---

# 一、什么是 LoRA？为什么它能在 8GB 显存里训练？

正常微调需要更新模型的**全部参数**，Qwen2.5-1.5B 有 15 亿参数，全参数微调的显存需求（参数 + 梯度 + 优化器状态）轻松超过 20GB，8GB 显卡根本装不下。

LoRA 的思路很简单：**冻住原模型的全部参数，只在旁边加一个很小的"旁路"矩阵，只训练这个旁路**。原模块是 `y = Wx`，LoRA 把它改成 `y = Wx + (BA)x`，其中 `A` 和 `B` 是两个很小的矩阵（例如 `rank=8`），需要训练的参数只有原模型的 0.1%~1%。QLoRA 更进一步：把冻住的原模型也用 4-bit 量化，进一步压缩显存。

# 三、加载 Base 模型（未做过指令微调）

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig

model_name = "Qwen/Qwen2.5-1.5B"  # 注意：这是 Base 版本，不是 Instruct 版本
quant_config = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_compute_dtype=torch.float16)

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, quantization_config=quant_config, device_map="auto")
```

---

# 四、微调前：先看看 Base 模型有多"不听话"

```python
def generate(prompt, max_new_tokens=60):
    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
    output = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=False)
    return tokenizer.decode(output[0], skip_special_tokens=True)

print(generate("请用一句话介绍 Transformer。"))
```

Base 模型很可能不会直接回答，而是**继续把这句话当成一段文本去续写**（例如输出"请用一句话介绍 Transformer。这是一道常见的面试题......"），这正是第4章讲的：预训练模型只学会了"续写"，没学会"服从指令"。

# 五、准备指令微调数据

用一个公开的小型中文指令数据集（也可以自己写几十条），格式是"指令 → 期望回答"：

```python
from datasets import load_dataset

dataset = load_dataset("shibing624/alpaca-zh", split="train")
dataset = dataset.select(range(2000))  # 只取一小部分,方便在8GB显存上快速跑完
print(dataset[0])
```

数据大致格式类似 `{"instruction": "请介绍一下人工智能", "output": "人工智能是..."}`，正好对应第4章讲的 SFT 数据形式。

# 六、配置 LoRA

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=8,
    lora_alpha=16,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)

model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
```

运行后你会看到类似 `trainable params: 4,718,592 || all params: 1,547,000,000 || trainable%: 0.30`——**只训练了 0.3% 的参数**，这就是 LoRA 能在 8GB 显存里训练 15 亿参数模型的秘密。

---

# 七、开始训练

```python
from transformers import TrainingArguments, Trainer

def format_example(example):
    text = f"指令：{example['instruction']}\n回答：{example['output']}"
    return tokenizer(text, truncation=True, max_length=256)

tokenized = dataset.map(format_example)

args = TrainingArguments(
    output_dir="./lora_output",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    num_train_epochs=1,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=20,
    save_strategy="no",
)

trainer = Trainer(model=model, args=args, train_dataset=tokenized)
trainer.train()
```

在 8GB 显卡上，2000 条数据训练 1 个 epoch 通常只需要 10~20 分钟。

---

# 八、微调后：再问一次同样的问题

```python
print(generate("请用一句话介绍 Transformer。"))
```

微调之后，模型通常会**直接给出简洁的回答**，而不再是"续写题目"式的输出——这正是 SFT 前后最直观的对比，也验证了第4章的核心结论：**Pretraining 决定模型"知道什么"，SFT 决定模型"如何按照人类的方式回应"**。
