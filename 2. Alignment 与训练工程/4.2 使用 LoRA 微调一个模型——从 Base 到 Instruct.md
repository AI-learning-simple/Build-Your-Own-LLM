# 4.2 使用低秩适配（LoRA）微调一个模型——从基础模型（Base）到指令模型（Instruct）

> **本节目标**：把4.1的单轮聊天模板与assistant-only labels接入真实训练，比较未参与训练的问题，并保存可供5.2继续使用的SFT adapter与tokenizer。Base也可能有一定指令跟随能力，不能预设它一定失败或小样本SFT一定改善。
>
> **硬件要求**：本例面向Linux、单张NVIDIA CUDA GPU，以4-bit QLoRA微调 `Qwen/Qwen2.5-1.5B`。8GB仅是可尝试的资源预算，不保证能跑；长度、词表logits、激活、优化器与软件版本都会影响峰值。macOS/CPU可做4.1数据实验，不直接套用本节bitsandbytes训练路径。

# 一、LoRA究竟减少了哪些参数？

全量微调更新全部权重；LoRA冻结原权重，在选中的线性层添加低秩增量。采用列向量约定：\(x\in\mathbb{R}^{d_{in}}\)，\(W\in\mathbb{R}^{d_{out}\times d_{in}}\)，\(A\in\mathbb{R}^{r\times d_{in}}\)，\(B\in\mathbb{R}^{d_{out}\times r}\)。默认LoRA计算为：

\[
y=Wx+\frac{\alpha}{r}BAx.
\]

例如一个 \(1024\times1024\) 的矩阵有1,048,576个权重；取 \(r=8\)，A/B共 \(8\times1024+1024\times8=16,384\) 个可训练参数，是原矩阵的1/64。`lora_alpha=16, r=8` 时增量乘2；它控制增量尺度，并不增加rank。全模型占比还取决于选中了哪些层，不能照搬这个单矩阵比例。

QLoRA进一步把**冻结基座**量化到4-bit，adapter和计算并非全是4-bit。它节省权重及训练状态，但仍要为反向传播保存或重算激活。LoRA也能学习领域信息和任务能力，不只改变风格；是否优于全量微调要看数据、rank、目标层和评估，而不是“学知识必须全量”。

# 三、加载 Base 模型（未做过指令微调）

```python
from pathlib import Path
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig, set_seed

assert torch.cuda.is_available(), "本例需要单卡CUDA环境"
set_seed(42)
RUN_DIR = Path.home() / "llm-labs" / "part2"
SFT_DIR = RUN_DIR / "sft_adapter"
MODEL_NAME = "Qwen/Qwen2.5-1.5B"
TEMPLATE_NAME = "Qwen/Qwen2.5-1.5B-Instruct"
SYSTEM = "你是一个中文助手，请准确回答并遵循用户的格式要求。"
use_bf16 = torch.cuda.is_bf16_supported()
compute_dtype = torch.bfloat16 if use_bf16 else torch.float16
quant_config = BitsAndBytesConfig(
    load_in_4bit=True, bnb_4bit_quant_type="nf4",
    bnb_4bit_use_double_quant=True, bnb_4bit_compute_dtype=compute_dtype,
)
tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME)
template_tok = AutoTokenizer.from_pretrained(TEMPLATE_NAME)
assert tokenizer.get_vocab() == template_tok.get_vocab()
assert template_tok.chat_template
tokenizer.chat_template = template_tok.chat_template
tokenizer.eos_token = template_tok.eos_token
tokenizer.pad_token = template_tok.pad_token
tokenizer.padding_side = "right"
assert tokenizer.eos_token == "<|im_end|>"
model = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME, quantization_config=quant_config, torch_dtype=compute_dtype,
    device_map={"": torch.cuda.current_device()},
)
model.config.eos_token_id = tokenizer.eos_token_id
model.config.pad_token_id = tokenizer.pad_token_id
model.generation_config.eos_token_id = tokenizer.eos_token_id
model.generation_config.pad_token_id = tokenizer.pad_token_id
```

固定到单张卡，不使用面向自动分派的 `device_map="auto"` 来隐式跨卡或offload。若改成0.5B，须在4.1与4.2同步替换Base和同系列Instruct模板，5.2从保存的adapter配置读取基座名称。

# 四、固定未见问题与生成协议

```python
EVAL_PROMPTS = [
    "请用恰好两条建议帮助初学者安排每天十五分钟的编程练习。",
    "请写一句不超过二十字的消息，婉拒周末临时的聚餐邀请。",
    "把这句话改成礼貌的请求：马上把报告给我。",
]

def generate(model, tokenizer, prompt, max_new_tokens=96):
    messages = [{"role": "system", "content": SYSTEM}, {"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, add_special_tokens=False, return_tensors="pt")
    inputs = inputs.to(model.get_input_embeddings().weight.device)
    model.eval()
    with torch.inference_mode():
        ids = model.generate(
            **inputs, max_new_tokens=max_new_tokens, do_sample=False, use_cache=True,
            eos_token_id=tokenizer.eos_token_id, pad_token_id=tokenizer.pad_token_id,
        )
    return tokenizer.decode(ids[0, inputs["input_ids"].shape[1]:], skip_special_tokens=True)
```

这里先定义协议，基线在第六节量化训练准备后采集，以免把dtype处理差异混入训练收益。训练前后都用相同system、模板、贪心解码和token预算，只打印新生成的回答。这个比较衡量的是**同一聊天接口上的行为变化**，不是Base在所有提示方式下的能力上限。

# 五、准备指令微调数据

用一个公开的小型中文指令数据集（也可以自己写几十条），格式是"指令 → 期望回答"：

```python
from datasets import Dataset, load_dataset

MAX_LENGTH = 256

def build_messages(sample):
    instruction = sample["instruction"].strip()
    extra = (sample.get("input") or "").strip()
    user_text = instruction + ("\n\n" + extra if extra else "")
    answer = sample["output"].strip()
    assert instruction and answer
    return [
        {"role": "system", "content": SYSTEM},
        {"role": "user", "content": user_text},
        {"role": "assistant", "content": answer},
    ]

def build_training_sample(sample, tokenizer):
    messages = build_messages(sample)
    assert not any(t in m["content"] for t in tokenizer.all_special_tokens for m in messages)
    prompt = tokenizer.apply_chat_template(messages[:-1], tokenize=False, add_generation_prompt=True)
    full = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=False)
    assert full.endswith(tokenizer.eos_token + "\n")
    full = full[:-1]
    prompt_ids = tokenizer(prompt, add_special_tokens=False)["input_ids"]
    full_ids = tokenizer(full, add_special_tokens=False)["input_ids"]
    assert full.startswith(prompt)
    assert full_ids[:len(prompt_ids)] == prompt_ids, "分词边界变化，不能用长度猜mask"
    answer_ids = full_ids[len(prompt_ids):]
    assert len(answer_ids) > 1 and answer_ids[-1] == tokenizer.eos_token_id
    labels = [-100] * len(prompt_ids) + answer_ids
    assert len(labels) == len(full_ids)
    return {"input_ids": full_ids, "attention_mask": [1] * len(full_ids), "labels": labels}

raw = load_dataset("shibing624/alpaca-zh", split="train").shuffle(seed=42)
raw = raw.select(range(min(2000, len(raw))))
rows, seen_prompts = [], set()
for row in raw:
    if not isinstance(row.get("instruction"), str) or not isinstance(row.get("output"), str):
        continue
    if not row["instruction"].strip() or not row["output"].strip():
        continue
    if row.get("input") is not None and not isinstance(row["input"], str):
        continue
    messages = build_messages(row)
    key = messages[1]["content"]
    if key in seen_prompts or key in EVAL_PROMPTS or row["instruction"].strip() in EVAL_PROMPTS:
        continue
    if any(t in m["content"] for t in tokenizer.all_special_tokens for m in messages):
        continue
    seen_prompts.add(key)
    rows.append(row)
assert len(rows) >= 20
splits = Dataset.from_list(rows).train_test_split(test_size=0.1, seed=42)
tokenized = splits.map(lambda row: build_training_sample(row, tokenizer),
                       remove_columns=splits["train"].column_names)
tokenized = tokenized.filter(lambda row: len(row["input_ids"]) <= MAX_LENGTH)
assert len(tokenized["train"]) > 0 and len(tokenized["test"]) > 0
print("保留的训练/验证样本:", len(tokenized["train"]), len(tokenized["test"]))
```

上面复用4.1的编码逻辑，显式保留 `input`。同prompt去重后再随机切分验证集；固定的生成问题不进入训练集。这里保证的是本次微调未见，并不能判断预训练是否见过相似题。正式实验还应做近重复检查与数据许可核对。

超长样本直接过滤而不盲目截断，避免产生“只有prompt”“EOS丢失”的无效监督；代价是训练分布偏向短回答，要记录过滤比例。2000条只是流程演示规模，不是质量保证。

# 六、量化训练准备与LoRA

```python
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training

model = prepare_model_for_kbit_training(
    model, use_gradient_checkpointing=True,
    gradient_checkpointing_kwargs={"use_reentrant": False},
)
model.config.use_cache = False
lora_config = LoraConfig(
    r=8, lora_alpha=16,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    lora_dropout=0.05, bias="none", task_type="CAUSAL_LM",
)
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
assert any(p.requires_grad for p in model.parameters())
before = {p: generate(model, tokenizer, p) for p in EVAL_PROMPTS}
model.train()
```

`prepare_model_for_kbit_training` 必须在添加adapter之前调用，否则可能把adapter也冻结。它冻结基座并处理低比特训练精度；非重入gradient checkpointing以重算换显存。LoRA默认初始化使增量为零，因此此处训练前的输出是相同预处理配置下的Base基线。可训练参数比例以实际打印值为准。

# 七、开始训练

```python
from transformers import TrainingArguments, Trainer, DataCollatorForSeq2Seq

collator = DataCollatorForSeq2Seq(
    tokenizer=tokenizer, model=None, padding=True,
    label_pad_token_id=-100, return_tensors="pt",
)
probe = collator([
    build_training_sample({"instruction": "计算1+1", "output": "2。"}, tokenizer),
    build_training_sample({"instruction": "用一句话解释梯度下降", "output": "沿损失下降的方向更新参数。"}, tokenizer),
])
assert (probe["attention_mask"] == 0).any()
assert (probe["labels"][probe["attention_mask"] == 0] == -100).all()
for row in probe["labels"]:
    supervised = row[row != -100]
    assert len(supervised) > 1 and supervised[-1].item() == tokenizer.eos_token_id
probe = {k: v.to(model.get_input_embeddings().weight.device) for k, v in probe.items()}
model.eval()
with torch.no_grad():
    assert torch.isfinite(model(**probe).loss)
del probe
model.train()
args = TrainingArguments(
    output_dir=str(RUN_DIR / "sft_checkpoints"),
    per_device_train_batch_size=1, per_device_eval_batch_size=1,
    gradient_accumulation_steps=8, num_train_epochs=1, learning_rate=2e-4,
    bf16=use_bf16, fp16=not use_bf16,
    gradient_checkpointing=True, gradient_checkpointing_kwargs={"use_reentrant": False},
    eval_strategy="epoch", logging_steps=10, save_strategy="no",
    optim="adamw_torch", report_to="none", seed=42, label_names=["labels"],
)
trainer = Trainer(
    model=model, args=args, train_dataset=tokenized["train"], eval_dataset=tokenized["test"],
    data_collator=collator, processing_class=tokenizer,
)
print("训练前验证:", trainer.evaluate())
torch.cuda.reset_peak_memory_stats()
trainer.train()
print("训练后验证:", trainer.evaluate())
print("峰值allocated GiB:", torch.cuda.max_memory_allocated() / 2**30)
```

虽然名字叫 `DataCollatorForSeq2Seq`，这里仅使用它的动态padding及labels补齐能力，`model=None` 不会创建decoder输入。普通 `Trainer` 不会凭空生成labels；少了labels或用其他collator覆盖mask，训练就不是本节定义的assistant-only SFT。单卡有效batch约为 `1×8=8` 条，最后一个累计批次可能更小。训练耗时请实测，不以显卡容量推算固定分钟数。

# 八、对比、保存，并从磁盘重载

```python
import json
import gc
from peft import PeftModel

after = {p: generate(model, tokenizer, p) for p in EVAL_PROMPTS}
for prompt in EVAL_PROMPTS:
    print("问题:", prompt)
    print("Base:", before[prompt])
    print("SFT:", after[prompt])

SFT_DIR.mkdir(parents=True, exist_ok=True)
model.save_pretrained(SFT_DIR)
tokenizer.save_pretrained(SFT_DIR)
protocol = {
    "base_model": MODEL_NAME, "system": SYSTEM, "max_new_tokens": 96,
    "eval_prompts": EVAL_PROMPTS, "sft_prompts": sorted(seen_prompts),
    "before": before, "after": after,
}
(SFT_DIR / "protocol.json").write_text(json.dumps(protocol, ensure_ascii=False, indent=2), encoding="utf-8")
assert (SFT_DIR / "adapter_config.json").is_file()
assert (SFT_DIR / "adapter_model.safetensors").is_file()

saved_template = tokenizer.chat_template
del trainer, model
gc.collect()
torch.cuda.empty_cache()
tokenizer = AutoTokenizer.from_pretrained(SFT_DIR)
assert tokenizer.chat_template == saved_template
assert tokenizer.eos_token == "<|im_end|>"
reloaded_base = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME, quantization_config=quant_config, torch_dtype=compute_dtype,
    device_map={"": torch.cuda.current_device()},
)
reloaded_base = prepare_model_for_kbit_training(reloaded_base, use_gradient_checkpointing=False)
reloaded = PeftModel.from_pretrained(reloaded_base, SFT_DIR, is_trainable=False)
reloaded_answers = {p: generate(reloaded, tokenizer, p) for p in EVAL_PROMPTS}
assert reloaded_answers == after, "重载结果不一致：先检查基座、模板、量化与生成配置"
print("SFT产物与重载检查通过:", SFT_DIR)
```

`adapter_model.safetensors` 不是完整基座权重；它需要匹配的Base才能恢复模型。`protocol.json`保存system、未见问题和生成预算，5.2会读取它，而不是悄悄改为官方Instruct起点。若重载断言失败，先排查环境和数值差异，不把差异当训练效果。

检查每条回答是否遵守条数/字数约束、是否答非所问，并结合独立验证Loss判断。小数据可能改善、无变化或退化；三道题只是定性检查，不足以证明全面提升，更不能证明SFT只能改行为不能学知识。

# 九、资源记录与失败排查

- 记录GPU型号、软件版本、保留样本数、长度、有效batch、耗时、峰值allocated与reserved显存；上述代码仅输出allocated峰值。
- OOM时先检查是否残留另一个模型，再减小长度/评估batch，或改用0.5B并**重新训练对应SFT产物**。序列缩短后仍须保留完整回答及EOS。
- 本节没有实测依据支持“固定4~6GB、10~20分钟”；全量微调也会因混合精度、优化器和offload方案而改变预算。

# 本节小结

本节把4.1的样本契约接入 `Trainer`：labels不缺失、padding不计Loss、回答EOS保留；完成kbit准备、固定格式的前后比较、adapter/tokenizer保存和重载验证代码。只有实际跑完断言和评估后，才能报告此次训练成功及其效果。

主产物链为 **4.1样本 → 4.2 SFT adapter与tokenizer → 5.2 DPO**。先读第5章理解偏好目标；5.1的Reward Model实验是理解PPO-RLHF打分器的旁支，**不是DPO的必需输入**。
