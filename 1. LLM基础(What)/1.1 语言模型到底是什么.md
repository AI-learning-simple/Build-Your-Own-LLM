# 1.1 为什么需要语言模型？

假设现在让你完成一句话。

例如：

> I love ______

你的脑海里可能会出现很多答案：

```
AI
Python
music
cats
```

为什么？

因为你的大脑已经阅读过大量文本，自然而然地知道：

> 在 "I love" 后面，哪些词出现的概率更高。

事实上，人类说话、写作、阅读，本质上都在不断预测后续内容。

例如，当你看到：

```
今天天气很______
```

几乎会立刻想到：

```
好
热
冷
不错
```

而不会想到：

```
键盘
苹果
Transformer
```

为什么？

因为前面的内容已经限制了后续出现的可能性。

这就是**语言的统计规律（Statistical Regularity）**。

---

现代大语言模型（Large Language Model，LLM）的核心目标，与人类非常相似：

> **根据已经看到的内容，预测下一个最可能出现的 Token。**

请注意，这句话几乎可以概括 GPT、Llama、Qwen、Gemini 等所有自回归大语言模型。

后面几百页内容，几乎都是围绕这一句话不断展开。

# 1.2 什么是 Language Model？

Language Model 可以翻译为：

> **语言模型**

很多初学者第一次看到这个名字，会觉得它非常神秘。

实际上，它只有一句定义。

> **Language Model 是一个学习语言统计规律，并预测下一个 Token 概率的模型。**

注意这里有三个关键词。

---

## Language（语言）

这里的 Language，并不仅仅指中文或英文。

对于模型来说：

```
I love AI
```

和：

```
我喜欢AI
```

没有本质区别。

它们都只是：

> 一串有顺序的 Token。

---

## Model（模型）

Model 可以理解成：

> 一个能够学习规律，并根据规律进行预测的数学模型。

它可以非常简单。

例如：

统计：

```
hello 后面经常跟着 world
```

也可以非常复杂。

例如：

GPT-5 包含数千亿参数。

但是：

它们的目标完全一样。

都是：

> 预测下一个 Token。

---

## Next Token Prediction（预测下一个 Token）

这是全书最重要的一句话。

例如：

```
I love
```

模型真正做的事情不是：

```
回答问题
```

不是：

```
聊天
```

不是：

```
翻译
```

而是：

```
预测：

下一个 Token 是什么？
```

例如：

```
Context：

I love
```

模型内部真正计算的是：

| Token  | Probability |
| ------ | ----------: |
| AI     |        0.63 |
| Python |        0.17 |
| music  |        0.08 |
| cats   |        0.04 |
| ...    |         ... |

最后再从这些概率中选择一个 Token。

**注意：**

这里先不要讨论"怎么选择"，例如 Greedy、Top-k、Temperature 等采样策略。

这些内容属于第八章《Sampling》。

本章只需要记住：

> **Language Model 输出的是一个概率分布，而不是一句完整的话。**

---

# 1.3 Training 与 Inference

很多初学者最容易混淆：

> 模型什么时候学习？

什么时候回答问题？

实际上，这是两个完全不同的阶段。

---

## Training（训练）

训练阶段。

模型会阅读大量文本。

例如：

```
Wikipedia
GitHub
Books
News
Code
```

目标只有一个：

> 学习语言中的统计规律。

例如：

```
I love

↓

AI
```

出现很多次。

模型就会逐渐学习到：

```
P(AI | I love)
```

越来越大。

训练结束以后。

模型得到一组参数。

以后不再阅读这些训练数据。

---

## Inference（推理）

推理阶段。

模型已经不会学习。

例如：

用户输入：

```
I love
```

模型只会利用训练阶段学到的规律。

预测：

```
AI
```

然后继续：

```
I love AI
```

预测：

下一步。

整个过程中：

模型参数保持不变。

---

因此：

> **Training 是学习概率；Inference 是使用概率。**

后面的所有章节，都遵循这个原则。

---

# 1.4 Context（上下文）

如果只输入：

```
apple
```

它可以表示：

* 苹果（水果）
* 苹果公司（Apple）
* Apple 芯片
* Apple Watch

模型应该输出什么？

答案：

不知道。

因为：

**Context 太少。**

---

如果输入：

```
I bought an apple yesterday.
```

模型更倾向：

```
水果
```

如果输入：

```
Apple released a new MacBook.
```

模型更倾向：

```
苹果公司
```

因此：

> **Context（上下文）就是模型在当前时刻能够看到的全部信息。**

Context 越丰富。

预测通常越准确。

这一点会在第五章 Self-Attention 中得到真正解决。

---

# 1.5 Autoregressive（自回归）

现在来看一个例子。

用户输入：

```
I love
```

模型预测：

```
AI
```

于是。

新的输入变成：

```
I love AI
```

模型继续预测：

```
because
```

于是：

```
I love AI because
```

继续预测：

```
it
```

整个过程如下：

```text
I love
      │
      ▼
     AI
      │
      ▼
I love AI
      │
      ▼
 because
      │
      ▼
I love AI because
      │
      ▼
   it
      │
      ▼
...
```

这就是：

> **Autoregressive（自回归）**

即：

> **每生成一个新的 Token，就把它加入 Context，继续预测下一个 Token。**

因此：

语言模型虽然一次只能预测一个 Token。

却能够不断生成：

小说、

代码、

论文、

邮件、

甚至一本书。

# 1.7 本章总结

本章我们建立了 Language Model 最核心的思想。

请牢记下面五句话：

1. **Language Model 的目标是预测下一个 Token。**
2. **模型输出的是概率分布，而不是完整答案。**
3. **Training 用于学习统计规律；Inference 用于利用统计规律。**
4. **Context 是模型当前能够看到的信息。**
5. **Autoregressive 让模型能够不断生成新的内容。**

后面的所有技术——Tokenizer、Embedding、Transformer、Attention——都只是为了让这个"预测下一个 Token"的过程更加准确。
