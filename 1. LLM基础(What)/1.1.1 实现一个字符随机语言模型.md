# 实验 1.1：Character Bigram Language Model

> **实验目标**

本实验将实现人生中的第一个 Language Model。

它没有 Transformer，没有神经网络，没有 Attention，没有 GPU。

仅利用统计方法，就能够完成最简单的：

> **Predict Next Character（预测下一个字符）**

虽然它非常简单，但后面所有 GPT 都是在这个模型基础上的不断演进。

---

# 一、准备数据

为了方便观察，我们先使用一段极小的数据。

```python

```

为什么不用几百万文本？

原因很简单：

第一章我们的目标不是训练一个好模型，而是理解：

> **Language Model 到底在做什么。**

所以数据越小越容易观察。

# 三、Bigram 是什么？

Bigram。

就是：

> **利用当前一个字符，预测下一个字符。**

例如：

```
hello
```

里面包含：

| Current | Next |
|----------|------|
| h | e |
| e | l |
| l | l |
| l | o |

如果输入：

```
h
```

模型应该预测：

```
e
```

如果输入：

```
e
```

模型预测：

```
l
```

整个模型只有这一条规则。

# 四、统计所有 Bigram

下面开始真正训练模型。

```python
text = "hello world"

model = {}

for i in range(len(text) - 1):

    current = text[i]
    nxt = text[i + 1]

    if current not in model:
        model[current] = []

    model[current].append(nxt)

print(model)
```

运行：

```
{
'h':['e'],
'e':['l'],
'l':['l','o','d'],
'o':[' ','r'],
' ':['w'],
'w':['o'],
'r':['l']
}
```

恭喜。

这里。

**你的第一个 Language Model 已经训练完成了。**

# 六、生成文本

下面。

开始真正生成文本。

增加：

```python
import random

def generate(start, max_length=20):

    result = start

    current = start

    for _ in range(max_length):

        if current not in model:
            break

        nxt = random.choice(model[current])

        result += nxt

        current = nxt

    return result
```

运行：

```python
print(generate("h"))
```

# 七、完整代码

```python
import random

text = "hello world"

model = {}

for i in range(len(text) - 1):

    current = text[i]
    nxt = text[i + 1]

    if current not in model:
        model[current] = []

    model[current].append(nxt)


def generate(start, max_length=20):

    result = start

    current = start

    for _ in range(max_length):

        if current not in model:
            break

        nxt = random.choice(model[current])

        result += nxt

        current = nxt

    return result


print(generate("h"))
```

总代码：

**不到 40 行。**

但是：

已经能够生成文本。

# 九、为什么它叫 Language Model？

请重新观察整个程序。

训练阶段。

它没有：

- 理解英文
- 学习语法
- 学习单词
- 学习知识

它只是：

统计：

```
当前字符

↓

下一字符
```

推理阶段。

根据统计结果。

预测：

```
Next Character
```

这就是：

Language Model。

因此：

> **Language Model 的本质，并不是理解语言，而是学习语言中的统计规律。**

这是第一章最重要的一句话。

# 十、本实验的局限性

虽然我们的模型已经能够生成文本。

但是它存在很多问题。

例如：

```
I love AI
```

它只能看到：

```
A

↓

I
```

却不知道：

```
I love
```

这个整体。

也就是说。

它一次只能看到：

```
一个字符。
```

这种模型。

叫：

> **Bigram Language Model**

下一节。

我们将升级它。

让它真正输出：

> **Probability Distribution（概率分布）**

也就是：

```
love

60%

like

40%
```

这一步。

将真正接近现代 GPT。
