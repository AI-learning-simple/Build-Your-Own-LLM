# 8.7 从一个 Token 到整个句子——Attention Matrix（注意力矩阵）

上一节，我们学习了 Self-Attention：每一个 Token 都会查看整个句子。但我们始终站在**一个 Token 的视角**。而 Transformer 真正计算的时候，不是一个一个算，而是**整个句子一次完成**。

---

# 把所有结果放到一起

假设句子有 4 个 Token：`The cat is sleeping`。每一个 Token 作为 Query，都会对所有 Token 计算一次注意力，把结果排成一张表：

```text
                被关注(Key)
             The  cat  is  sleeping
Query  The    ?    ?    ?      ?
       cat    ?    ?    ?      ?
       is     ?    ?    ?      ?
  sleeping    ?    ?    ?      ?
```

这就是 **Attention Matrix（注意力矩阵）**，矩阵中每个数字表示**当前 Query 对某个 Token 的关注程度**。

一个具体例子：继续用本章的 `The cat is sleeping` 和 8.2 节定义的 Embedding，对每一个词都重复一次 8.3~8.4 节做过的计算（自己和自己、和其它三个词分别做 Dot Product，再 Softmax），就得到完整的 4×4 矩阵（`cat` 这一行就是 8.4 节已经算出的结果）：

```text
              The   cat   is  sleeping
The         0.263  0.251  0.243  0.243
cat         0.114  0.398  0.109  0.379
is          0.248  0.243  0.261  0.248
sleeping    0.114  0.391  0.114  0.380
```

第二行 `cat` 这一行说明：处理 `cat` 时，主要关注自己（0.398），其次关注 `sleeping`（0.379）。第四行 `sleeping` 也呈现出类似的模式：主要关注 `cat`（0.391），其次是自己（0.380）。而 `The`、`is` 这两个功能词，对所有 Token 的注意力几乎是"平均分配"的（每个格子都接近 0.25），说明模型没有找到明显应该关注的对象——这正符合它们本身没有太多实际语义的直觉。

---

# 为什么每一行都等于 1？

因为每一行都经过了 Softmax，天然就是一个概率分布，表示**当前 Query 把多少注意力分配给每一个 Token**。

---

# Experiment 8.7：用代码验证整张 Attention Matrix

上面的矩阵不是拍脑袋写的，而是四次 Dot Product + Softmax 算出来的。把 8.2 节的做法对每一行都重复一遍：

```python
import numpy as np

embedding = np.array([
    [0.1, -0.2],   # The
    [1.0,  0.5],   # cat
    [-0.1, 0.1],   # is
    [0.9,  0.6],   # sleeping
])

scores = embedding @ embedding.T   # 所有 Query × 所有 Key 的 Dot Product
exp = np.exp(scores - scores.max(axis=1, keepdims=True))
attention = exp / exp.sum(axis=1, keepdims=True)
print(np.round(attention, 3))
```

输出：

```text
[[0.263 0.251 0.243 0.243]
 [0.114 0.398 0.109 0.379]
 [0.248 0.243 0.261 0.248]
 [0.114 0.391 0.114 0.38]]
```

和上面手算的结果完全一致——这就是 Self-Attention 真正的计算方式：`embedding @ embedding.T` 一次性算出所有 Query 和所有 Key 的 Dot Product，再对每一行做 Softmax。

---

# 为什么叫 Matrix？

之前一直计算"一个 Query → 所有 Key"，现在整个句子一起计算，变成"所有 Query → 所有 Key"，结果自然是一个二维矩阵。矩阵中每个格子都来自一次 Dot Product（例如 `cat × sleeping`）。如果一句话有 N 个 Token，总共需要 `N × N` 次比较，因此 Self-Attention 的时间复杂度是 **O(N²)**，这也是 Transformer 最大的计算瓶颈。

---

# Transformer 为什么能并行？

RNN 必须 `Token1 → Token2 → Token3` 一步一步计算，不能跳过，因为后一个 Hidden State 依赖前一个。而 Transformer 的 Attention Matrix 一次计算"所有 Query × 所有 Key"，整个句子可以一次送进 GPU 统一完成。这就是 Transformer 能够高效并行训练的根本原因。

---

# 本节总结

本节，我们完成了从"一个 Token 的 Attention"到"整个句子的 Self-Attention"的跨越：✅ 每个Token 都会形成一行 Attention Weight ✅ 所有行组合起来，就是Attention Matrix ✅ 每一行都是 Softmax 后的概率分布 ✅ Self-Attention 的计算复杂度是 O(N²) ✅ Transformer 能够并行，是因为整个矩阵可以一次计算

观察两句话：`Apple released a new iPhone.` 和 `Apple tastes sweet.`——对于 `Apple`，第一句应该关注 `iPhone`，第二句应该关注 `sweet`，甚至还需要关注 `released`。有没有可能**同时从多个不同角度理解一句话**？这就是 Transformer 的第二个核心创新：**Multi-Head Attention（多头注意力）**。
