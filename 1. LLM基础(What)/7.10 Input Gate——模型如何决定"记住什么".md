# 7.10 Input Gate——模型如何决定"记住什么"

上一节，我们学习了 Forget Gate，它回答的是"哪些旧的信息应该保留？"。现在 Cell State 已经腾出了空间，新的问题来了：**哪些新的信息值得写进去？** 答案就是 **Input Gate（输入门）**。

---

# Forget 之后为什么还需要 Input？

假设当前 Cell State 是 `Alice、教授、北京大学`。模型读到"Alice 获得了图灵奖"，这条信息显然应该加入长期记忆；但如果读到"今天下雨了"，大多数情况下不需要写入。因此模型需要第二个能力：**决定哪些新的信息值得长期保存**。

Forget Gate 控制"旧 Memory"，Input Gate 控制"新 Memory"，但请注意：**Input Gate 并不决定"写什么"，它只决定"允许多少信息进入 Cell State"**。

---

# Candidate Memory（候选记忆）

如果 Input Gate 负责"写多少"，那么谁负责"写什么"？答案是 **Candidate Memory（候选记忆）**——模型根据当前输入生成的一份"建议写入内容"。例如输入"Alice 获得图灵奖"，模型可能生成候选内容 `Alice、图灵奖、成就`，但真正写入多少，还要经过 Input Gate。

一个类比：系统自动生成一条建议（Candidate），但真正是否保存，还需要你点击"保存"或"忽略"，Input Gate 就像这个"保存按钮"。

---

# Experiment 7.10：体验 Input Gate

延续 7.9 节：Forget 之后剩下 `kept = [6.4, 2.0]`。现在假设模型生成的候选记忆和 Input Gate 分别是：

```python
import numpy as np

kept = np.array([6.4, 2.0])     # 来自 7.9 节
candidate = np.array([3, 6])     # 候选记忆（Candidate Memory）
input_gate = np.array([0.5, 0.5])  # Input Gate

written = input_gate * candidate
print(written)  # [1.5 3. ]
```

输出 `[1.5, 3.0]`——候选记忆只写入了一半。

---

# Forget + Input 合起来

现在把 Forget 和 Input 连接起来：

```
新的 Cell State = 保留的旧 Cell + 写入的新 Candidate
```

论文中写成：

```
Cₜ = fₜ × Cₜ₋₁ + iₜ × C̃ₜ
```

其中 `Cₜ₋₁` 是旧 Cell，`fₜ` 是 Forget Gate，`iₜ` 是 Input Gate，`C̃ₜ` 是 Candidate Memory。翻译成一句话：**保留一部分旧记忆，再加入一部分新记忆。**

---

# Experiment 7.11：模拟一次完整更新

```python
new_cell = kept + written
print(new_cell)  # [7.9 5. ]
```

计算过程：保留 `[6.4, 2.0]`，新增 `[1.5, 3.0]`，最终 `new_cell = [7.9, 5.0]`。这就是一次完整的 Cell State 更新，我们会在 7.11 节继续用它计算 Output Gate。

---

# 本节总结

✅ Input Gate 控制"写多少" ✅ Candidate Memory 决定"写什么" ✅ Cell State 更新公式：`新 Cell = 保留旧 Memory + 加入新 Memory`

到这里，LSTM 最复杂的部分已经结束。下一节，我们只剩最后一个问题：**Cell State 保存了这么多信息，最终输出的时候，到底输出哪些？** 这就是 **Output Gate（输出门）**。
