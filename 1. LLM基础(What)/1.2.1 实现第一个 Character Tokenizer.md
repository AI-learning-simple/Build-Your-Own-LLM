# 二、设计 CharacterTokenizer

先思考一个问题。

Tokenizer 应该有哪些能力？

至少应该支持：

```
文本

↓

Token ID
```

以及：

```

↓

```

因此：

它至少应该有三个函数：

```
build()

encode()

decode()
```

于是：

整个类定义如下：

```python
class CharacterTokenizer:

    def __init__(self, text):

        self.build(text)

    def build(self, text):
        ...

    def encode(self, text):
        ...

    def decode(self, ids):
        ...
```

是不是比散落的几个函数更清晰？

以后：

WordTokenizer、

BPETokenizer、

# 三、实现 build()

Tokenizer 的第一件事情：

建立 Vocabulary。

增加：

```python
class CharacterTokenizer:

    def __init__(self, text):

        self.build(text)

    def build(self, text):

        chars = sorted(set(text))

        self.stoi = {
            ch: i
            for i, ch in enumerate(chars)
        }

        self.itos = {
            i: ch
            for ch, i in self.stoi.items()
        }
```

这里：

Vocabulary 已经建立完成。

例如：

```
hello world
```

得到：

```

'e':2,
'h':3,
'l':4,

```

# 四、实现 encode()

Tokenizer 最重要的功能。

就是：

```

↓

Token IDs
```

```python
def encode(self, text):

        self.stoi[ch]
```

# 六、完整代码（tokenizer.py）

```python
class CharacterTokenizer:

    def __init__(self, text):

        self.build(text)

    def build(self, text):

        chars = sorted(set(text))

        self.stoi = {
            ch: i
            for i, ch in enumerate(chars)
        }

        self.itos = {
            i: ch
            for ch, i in self.stoi.items()
        }

    def encode(self, text):

        return [

            self.stoi[ch]

            for ch in text

        ]

    def decode(self, ids):

        return "".join(

            self.itos[i]

            for i in ids

        )
```

总代码：

**不到 30 行。**

但是：

已经完成了第一个 Tokenizer。
