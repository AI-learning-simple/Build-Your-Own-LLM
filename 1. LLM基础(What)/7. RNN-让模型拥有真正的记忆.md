# 7.0 固定窗口的问题

上一章的模型依赖固定 Context Window，例如窗口大小为 2，句子 `I love AI today`，模型只能看到 `[I love] → AI`、`[love AI] → today`——始终只能看到最近两个 Token，永远看不到整个句子。

再看一个更长的句子：`The book that I bought yesterday from my best friend is interesting.`。最后的 `interesting` 真正描述的是 `book`，但如果窗口只有 4，模型看到的 Context 是 `my best friend is`，`book` 早已消失，模型根本不知道 `interesting` 修饰的是什么。

这种"真正相关的信息距离很远"的现象，在 NLP 中叫做：

> **Long-Term Dependency（长距离依赖）**

中文同样存在这个问题：`昨天在北京参加人工智能大会并发表主题演讲的张教授今天回到了上海。`——"张教授"与"回到了上海"之间隔了很多 Token，固定窗口依然无法覆盖。

# Experiment 7.0：观察 Context Window 的局限

```python
sentence = ["The","book","that","I","bought","yesterday","is","interesting"]
window = 3

for i in range(window, len(sentence)):
    context = sentence[i-window:i]
    target = sentence[i]
    print(context, "->", target)
```

输出：

```text
['The', 'book', 'that'] -> I
['book', 'that', 'I'] -> bought
['that', 'I', 'bought'] -> yesterday
['I', 'bought', 'yesterday'] -> is
['bought', 'yesterday', 'is'] -> interesting
```

最后一次预测，Context 是 `bought yesterday is`，真正重要的信息 `book` 已经消失，模型永远不知道 `interesting` 描述的是什么。

**思考题**：如果窗口改成 4 或 100，是否能彻底解决问题？窗口不断增大，又会付出什么代价？
