# 7.9 Forget Gate——模型如何决定"忘记什么"

上一节，我们已经知道 LSTM 中真正长期保存信息的是 Cell State。现在新的问题来了：**Cell State 会不会越来越大？** 如果模型把所有内容全部保存，Memory 将越来越大，而很多内容其实已经没有意义（例如"今天天气很好"到句子结束通常已经没有价值）。因此模型需要一种能力：**主动忘记**。这就是 **Forget Gate**。

---

# 为什么叫 Gate（门）？

Forget Gate 不是一个 Memory，也不是普通的神经网络层，它更像一道门：`Cell State → [Gate] → 输出`。门可以打开，也可以关闭，于是 Memory 就能够选择哪些继续保存、哪些丢弃。

**一个例子**：笔记本记录着 `Alice、教授、北京大学、天气很好、今天下雨、午饭吃面`。论文结束后，大多数人会保留 `Alice、教授、北京大学`，删除后面的琐事。Forget Gate 做的就是这个决定。

---

# Forget Gate 不是简单的"删或留"

Forget Gate 输出的是一个 **0~1 之间的数字**：`1.0` 表示全部保留，`0` 表示全部删除，更多时候是 `0.82、0.35、0.91、0.12` 这样的中间值，表示保留一部分。所以 Forget Gate 其实是一个**保留比例（Keep Ratio）**。

---

# Experiment 7.9：体验Forget Gate

延续本章的例子：假设模型处理完 `I love AI` 后，LSTM 的 Cell State 是一个 2 维向量（与前面 RNN 部分的 Hidden Size 保持一致）：

```python
import numpy as np

cell = np.array([8, 4])       # 当前 Cell State
forget = np.array([0.8, 0.5])  # Forget Gate，每一维有不同的保留比例

kept = forget * cell
print(kept)  # [6.4 2. ]
```

第一维保留了 80%（`8→6.4`），第二维只保留了 50%（`4→2.0`）——这意味着 LSTM 不是整体忘记，而是**按特征维度选择性遗忘**。这组 `kept = [6.4, 2.0]`，我们会在 7.10 节继续使用。

---

# Forget Gate 从哪里来？

Forget Gate 这个数字是谁决定的？答案是：**神经网络自己计算**。模型会同时观察当前输入 `xₜ` 和上一时刻 Hidden State `hₜ₋₁`，然后输出一个 0~1 之间的向量：

```
fₜ = σ(Wf · [hₜ₋₁, xₜ] + bf)
```

其中 `σ`（Sigmoid）保证输出一定在 0~1 之间，`Wf`、`bf` 是需要学习的参数。因此 Forget Gate 不是程序员写死的固定值，而是模型训练出来的——什么时候应该接近 1，什么时候应该接近 0。

---

# 为什么先 Forget？

因为如果 Memory 已经满了，新的信息根本放不进去。因此必须先决定哪些旧信息可以释放空间，然后下一步才能决定**哪些新的信息值得加入**——这就是下一节：**Input Gate（输入门）**。

---

# 本节总结

✅ Forget Gate 的作用 ✅ Gate 本质上是一个"控制开关" ✅ Forget Gate 输出的是 0~1 的保留比例 ✅ Forget Gate 按特征维度工作，而不是整体删除 ✅ Forget Gate 的值由神经网络学习得到，而不是人工设定
