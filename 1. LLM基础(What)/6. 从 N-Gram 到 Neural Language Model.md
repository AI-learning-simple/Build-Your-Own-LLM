# 6.1 从 N-Gram 到 Neural Language Model

上一章，我们学习了 Context Window，例如 `[I love] → AI`，已经能够利用前面的上下文进行预测。但这里仍然存在一个问题：传统 N-Gram 保存的是"`I love` 出现 100 次，其中 AI 40 次、Python 30 次、NLP 20 次"这样的统计次数。模型只是查表（Lookup），它不会学习、不会泛化，更不会理解 `love AI` 和 `love Python` 之间的关系。

于是研究人员想到：为什么不用神经网络代替统计表？于是世界上第一个 Neural Language Model 诞生了。

| Neural Language Model（2003） | GPT                |
| --------------------------- | ----------------------- |
| 固定 Context Window           | 长 Context（数千到数百万 Token） |
| Embedding                   | Embedding               |
| MLP                         | Transformer Block       |
| Softmax                     | Softmax                 |
| Cross Entropy               | Cross Entropy           |
| 梯度下降训练                      | 梯度下降训练                  |
| 下一 Token 预测                 | 下一 Token 预测             |
