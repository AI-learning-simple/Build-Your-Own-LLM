# 实验 3.1：为什么 Token ID 不能直接输入神经网络？

> **实验目标**
>
> 第二章中，我们已经能够把文本转换成 Token ID，例如 `I love AI` 编码为 `[2, 3, 1]`。一个很自然的问题来了：**为什么不能直接把 `[2,3,1]` 输入神经网络？** 本实验将通过几个简单实验，理解为什么神经网络无法直接学习 Token ID，并自然推导出 One-Hot Encoding。

---

# 一、回顾第二章

目前我们的整个工程如下：`Text → Tokenizer → Token IDs`。例如 `I love AI` 经过 Tokenizer 得到 `I→2, love→3, AI→1`，最终 `[2,3,1]`。很多初学者第一次都会产生一个想法：**既然已经是数字了，那为什么不能直接送进神经网络？** 这是一个非常好的问题。

---

# 二、做一个最简单的实验

假设 Vocabulary 如下：

| Token  | ID |
| ------ | -: |
| apple  |  0 |
| banana |  1 |
| cat    |  2 |
| dog    |  3 |

如果直接输入神经网络，观察这些数字隐含的数学关系：`3 > 2 > 1 > 0`，甚至 `dog - cat = 1`，`cat - banana = 1`。这些关系是真的吗？当然不是。

---

# 三、Token ID 只是编号

换一个角度：假设学校里`张三→1001`，`李四→1002`，`王五→1003`，难道 `1003 > 1002` 说明王五比李四"更大"？当然不是，学号只是**唯一编号（Identifier）**，没有任何数学意义。Token ID 也是一样，它只是 Vocabulary 中的位置。

---

# 四、修改编号会发生什么？

原来 `apple→0, banana→1, cat→2, dog→3`。现在重新排序：`dog→0, cat→1, banana→2, apple→3`。语言发生变化了吗？没有，真正变化的只有编号。说明 Token ID 本身没有任何语义。

---

# 五、神经网络真正需要什么？

神经网络能够学习的是**连续空间（Continuous Space）**，例如 `[0.15,0.72,-0.31]`，而不是 `3`。因为连续向量之间可以计算欧氏距离、余弦相似度、点积、方向。例如 `cat → [0.21,0.34,-0.55]`，`dog → [0.20,0.37,-0.52]`，两个向量非常接近，于是模型可以学习 `cat ≈ dog`。但如果只有 `2` 和 `3`，模型无法知道为什么 `2 和 3` 比 `2 和 100` 更接近——因为编号本身没有意义。

---

# 六、第一个解决方案：One-Hot Encoding

既然 `2` 不能直接输入，有没有一种方式，既能保留 Token 的唯一身份，又不会引入大小关系？答案就是：

> **One-Hot Encoding**

例如 Vocabulary `apple, banana, cat, dog`：

```text
apple  → [1,0,0,0]
banana → [0,1,0,0]
cat    → [0,0,1,0]
dog    → [0,0,0,1]
```

所有 Token 都是等距离的，不存在 `dog > cat` 这种错误关系。

---

# 七、为什么叫 One-Hot？

观察 `[0,0,1,0]`，只有一个位置是 `1`，其它全部是 `0`，因此叫 One-Hot，意思是**只有一个位置是激活（Hot）的**。

---

# 八、完整数据流

到这里，整个系统已经演进成：

```mermaid
flowchart LR
    A[Text] --> B[Tokenizer] --> C["Token ID"] --> D[One-Hot] --> E[Neural Network]
```

是不是比 `Token ID → Neural Network` 合理很多？

---

# 九、One-Hot 真的是最终方案吗？

GPT 的 Vocabulary 大约有 100,000 个 Token。如果每个 Token 都是 One-Hot，那么一个 Token 就是 100000维向量，是不是非常浪费？事实上，现代 GPT **几乎不会真正生成 One-Hot 向量**，它采用了一种更加高效的方法：

> **Embedding Matrix**

下一节，我们就会发现 Embedding Matrix 其实就是 One-Hot 的一种优化实现。

---

# 实验代码

```python
vocab = ["apple", "banana", "cat", "dog"]

token_id = 2
one_hot = [0] * len(vocab)
one_hot[token_id] = 1
print(one_hot)  # [0,0,1,0]

token_id = 0
one_hot = [0] * len(vocab)
one_hot[token_id] = 1
print(one_hot)  # [1,0,0,0]
```

---

# 实验收获（Takeaways）

✅ 理解 Token ID 只是编号，没有语义。
✅ 理解神经网络需要连续向量，而不是离散编号。
✅ 理解 One-Hot Encoding 消除了 Token ID 的大小关系。
❌ One-Hot 维度过高，不适合现代大模型。
