# 2.1 第一章留下的问题

回顾第一章，我们训练模型时使用的是：

```python
text = "hello world"
```

训练代码：

```python
current = text[i]
next = text[i+1]
```

生成时：

```python
print(generate("h"))
```

整个程序一直在处理：

```text
'h'

'e'

'l'

'l'

'o'
```

看起来没有问题。

但是。

如果训练数据变成：

```text
I love AI.
```

我们的模型实际上看到的是：

```text
I

(space)

l

o

v

e

(space)

A

I

.
```

请注意。

这里：

```
love
```

已经被拆成：

```text
l

o

v

e
```

模型完全不知道：

```
love
```

其实是一个完整的词。

---

再来看一句中文：

```text
我喜欢人工智能
```

Character Model 看到的是：

```text
我

喜

欢

人

工

智

能
```

虽然比英文好一点。

但是：

它仍然不知道：

```
人工智能
```

其实是一个整体概念。

所以：

Character Language Model 有一个天然的问题：

> **它只能学习字符之间的关系，而不能学习更高层次的语言结构。**

# 2.2 为什么不能直接使用单词（Word）？

很多同学第一次想到：

既然 Character 太小。

那直接用：

```
Word
```

是不是就好了？

例如：

```text
I love AI
```

切成：

```text
I

love

AI
```

看起来非常合理。

但是。

真正训练 GPT 时。

Word Tokenizer 很快就会遇到三个问题。

---

## 问题一：新词（Out-of-Vocabulary）

假设训练时：

只有：

```text
cat

dog
```

后来。

用户输入：

```text
cats
```

怎么办？

词表里面：

根本没有：

```
cats
```

模型：

直接无法处理。

这就是：

> **Out-of-Vocabulary（OOV）**

现代 NLP 最经典的问题之一。

---

## 问题二：词表会无限增长

例如：

英文：

```text
play

playing

played

player

players

playing's

...
```

如果：

每一个都是：

一个 Word。

Vocabulary 会越来越大。

对于中文。

情况更严重。

例如：

```text
人工智能

生成式人工智能

多模态生成式人工智能

……
```

理论上：

新词永远都会出现。

---

## 问题三：浪费训练数据

例如：

```
play
playing
played
```

其实：

都来自：

```
play
```

如果：

完全切成不同 Word。

模型：

无法共享：

```
play
```

这个词根。

于是：

学习效率下降。

---

所以。

Character 不行。

Word 也不行。

现代 LLM：

采用：

> **Subword（子词）**

---

# 2.3 什么是 Token？

很多初学者。

会认为：

```
Token

=

Word
```

实际上：

完全不是。

Token。

真正的定义是：

> **Tokenizer 切分出来、供模型学习的最小语言单位。**

请注意：

这里没有说：

字符。

也没有说：

单词。

例如：

一句：

```text
playing
```

Character：

```
p

l

a

y

i

n

g
```

Word：

```
playing
```

Subword：

可能：

```
play

ing
```

也可能：

```
pla

ying
```

甚至：

```
playing
```

这完全取决于：

Tokenizer。

所以：

Token：

不是固定的。

而是：

Tokenizer 的输出。

---

# 2.4 Tokenizer 的职责

到这里。

我们终于可以正式定义：

Tokenizer。

> **Tokenizer 的职责，就是把人类能够理解的文本，转换成模型能够处理的 Token ID。**

整个流程如下：

```text
Text
 │
 ▼
Tokenizer
 │
 ▼
Token
 │
 ▼
Vocabulary
 │
 ▼
Token ID
 │
 ▼
Language Model
```

请注意：

从这里开始。

Language Model。

已经再也不会看到：

```text
hello world
```

它真正看到的是：

```text
[3,2,4,4,5,0,7,5,6,4,1]
```

第二章实验。

我们就会亲手实现：

```
Text

↓

Token

↓

Token ID
```

这条流水线。
