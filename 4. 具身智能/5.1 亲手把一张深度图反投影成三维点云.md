# 二、合成一张已知场景的深度图

我们不用真实相机，而是**反过来**：先假设场景里有一个已知位置、已知半径的球体，用几何公式算出"如果真的架一台相机拍它，每个像素的深度值应该是多少"，从而生成一张"标准答案"式的深度图——这样反投影出来的点云对不对，就有了精确的验证依据。

```python
import numpy as np

# 相机内参（数量级与真实 RGB-D 相机一致，比如 Intel RealSense）
fx, fy = 500.0, 500.0
cx, cy = 320.0, 240.0
width, height = 640, 480

# 场景设定：球心在相机正前方 3 米处，半径 0.5 米
sphere_center = np.array([0.0, 0.0, 3.0])
sphere_radius = 0.5

def render_depth_image():
    """给定针孔相机模型和已知球体，解析计算每个像素的深度值（Z-buffer）"""
    us, vs = np.meshgrid(np.arange(width), np.arange(height))
    a = (us - cx) / fx
    b = (vs - cy) / fy

    # 沿像素对应的视线方向 (a, b, 1)，与球面求交：
    # (a*z)^2 + (b*z)^2 + (z - Zc)^2 = R^2  （球心 x=y=0，只有 z=Zc）
    A = a ** 2 + b ** 2 + 1.0
    B = -2.0 * sphere_center[2]
    C = sphere_center[2] ** 2 - sphere_radius ** 2

    discriminant = B ** 2 - 4 * A * C
    valid = discriminant >= 0

    depth = np.full((height, width), np.inf)
    sqrt_disc = np.sqrt(np.maximum(discriminant, 0))
    z_near = (-B - sqrt_disc) / (2 * A)   # 取距离相机更近的那一个交点
    depth[valid] = z_near[valid]
    return depth

depth_image = render_depth_image()
print("图像正中心像素 (u=320, v=240) 的深度值:", depth_image[240, 320])
```

**这一步可以先手工验证**：正中心像素满足 `a=0, b=0`（因为 `u=cx, v=cy`），代入方程：`A=1, B=-6, C=9-0.25=8.75`，判别式 `= 36 - 35 = 1`，`z = (6-1)/2 = 2.5`。这正是几何直觉告诉我们的答案——球心在 `Z=3.0` 米处，半径 `0.5` 米，那么球面上离相机最近的一点，深度应该正好是 `3.0 - 0.5 = 2.5` 米。

**预期输出**：

```
图像正中心像素 (u=320, v=240) 的深度值: 2.5
```

# 三、反投影：把深度图还原成三维点云

```python
def backproject(depth_image):
    """深度图 -> 三维点云，严格按照5.3节的反投影公式"""
    us, vs = np.meshgrid(np.arange(width), np.arange(height))
    valid_mask = np.isfinite(depth_image)

    Z = depth_image[valid_mask]
    U = us[valid_mask]
    V = vs[valid_mask]

    X = (U - cx) * Z / fx
    Y = (V - cy) * Z / fy

    points = np.stack([X, Y, Z], axis=1)
    return points

point_cloud = backproject(depth_image)
print("反投影得到的点云中的点数:", point_cloud.shape[0])
```

**预期输出**：由于球在图像上只占据一个圆形区域（半径大约为 `fx · R / Z ≈ 500 × 0.5 / 2.5 = 100` 像素左右），有效点数应该在几万个点的量级（约 `π × 100² ≈ 31400` 个像素左右，实际数字取决于圆形区域离散化后的精确像素个数）：

```
反投影得到的点云中的点数: 31401   （精确数字取决于圆形边界的像素离散化，量级应与此一致）
```

# 四、验证：还原出来的点云是否真的落在球面上

这是本节实验最关键的一步——**如果反投影公式写对了，点云里的每一个点，到球心的距离都应该严格等于球的半径 `0.5`**（因为我们一开始就是用"球面方程"生成的深度图）：

```python
distances = np.linalg.norm(point_cloud - sphere_center, axis=1)

print("到球心距离 - 均值:", distances.mean())
print("到球心距离 - 标准差:", distances.std())
print("到球心距离 - 与真实半径0.5的最大误差:", np.abs(distances - sphere_radius).max())
```

**预期输出**（这是一个解析验证实验，理论上除了浮点数运算的舍入误差外不应该有任何偏差）：

```
到球心距离 - 均值: 0.5
到球心距离 - 标准差: 0.0 （量级在 1e-10 ~ 1e-15，属于浮点数精度范围）
到球心距离 - 与真实半径0.5的最大误差: 0.0 （同样是浮点数精度范围内的极小值）
```

如果这三个数字确实如此（均值精确等于 `0.5`，标准差和最大误差都是浮点精度级别的极小值），就完整验证了"深度图 → 点云"反投影公式的正确性——这也正是本章 5.3 节公式在代码层面的严格证明。

# 五、思考题

本节的深度图是"完美"的——没有任何传感器噪声、没有遮挡、没有缺失值。真实的 RGB-D 相机在物体边缘、强反光表面（如玻璃、金属）附近，经常会产生噪声很大或者完全缺失（值为0或无穷大）的深度读数。可以思考一下：如果直接把这样一张带噪声的深度图反投影成点云，会对后续的抓取点估计造成什么影响？有哪些常见的方法可以缓解这个问题（提示：可以考虑"多帧融合"和"深度补全网络"这两个方向）？
