# 8.1 对比 Sparse Reward 与基于势函数的 Reward Shaping

> **本节目标**：复用 3.1 节的网格世界环境，精确验证"稀疏奖励下，Q 表在第一次到达终点之前完全不会更新"这个可以严格证明的结论；再实现基于势函数的奖励塑形，计算具体的塑形奖励数值，验证它从第一步开始就能区分"朝目标前进"和"背离目标"两种动作；最后亲手实现一次最简版的 Policy Gradient（REINFORCE），体会连续动作空间下"直接优化策略参数"是怎么做到的。

---

# 一、环境准备

复用 3.1 节的 4×4 网格世界：起点 `(0,0)`，终点 `(3,3)`，陷阱 `(1,1)`。

```python
import random

GRID_SIZE = 4
START = (0, 0)
GOAL = (3, 3)
TRAP = (1, 1)
ACTIONS = ["up", "down", "left", "right"]

def move(state, action):
    r, c = state
    if action == "up":
        r = max(0, r - 1)
    elif action == "down":
        r = min(GRID_SIZE - 1, r + 1)
    elif action == "left":
        c = max(0, c - 1)
    elif action == "right":
        c = min(GRID_SIZE - 1, c + 1)
    return (r, c)
```

---

# 二、方案 A：纯稀疏奖励

```python
def step_sparse(state, action):
    next_state = move(state, action)
    if next_state == GOAL:
        return next_state, 10.0, True
    if next_state == TRAP:
        return next_state, -10.0, True
    return next_state, 0.0, False    # 除了终点/陷阱，其余时刻奖励严格为0
```

**精确验证：Q 表在第一次到达终点/陷阱之前，完全不会发生任何更新**

```python
def q_learning_track_first_nonzero_update(step_fn, episodes=2000, alpha=0.1, gamma=0.9):
    Q = {(r, c, a): 0.0 for r in range(GRID_SIZE) for c in range(GRID_SIZE) for a in ACTIONS}
    first_success_episode = None
    first_qtable_change_episode = None

    for ep in range(episodes):
        state = START
        done = False
        steps = 0
        while not done and steps < 100:
            epsilon = 1.0   # 全程用纯随机探索，专门用来验证"随机撞对之前Q表完全不变"这一结论
            action = random.choice(ACTIONS)
            next_state, reward, done = step_fn(state, action)

            best_next_q = max(Q[(*next_state, a)] for a in ACTIONS)
            td_target = reward + gamma * best_next_q * (0 if done else 1)
            td_error = td_target - Q[(*state, action)]

            if abs(td_error) > 1e-12 and first_qtable_change_episode is None:
                first_qtable_change_episode = ep + 1

            Q[(*state, action)] += alpha * td_error
            state = next_state
            steps += 1

        if done and first_success_episode is None and next_state in (GOAL, TRAP):
            first_success_episode = ep + 1

        if first_qtable_change_episode is not None:
            break

    return first_success_episode, first_qtable_change_episode

random.seed(0)
first_success, first_change = q_learning_track_first_nonzero_update(step_sparse)
print("第一次到达终点/陷阱是第几轮episode:", first_success)
print("Q表第一次发生非零更新是第几轮episode:", first_change)
```

**预期输出**：这两个数字**必然完全相等**——这是一个可以严格证明的数学事实，不依赖任何随机种子：在纯稀疏奖励下，只要还没有经历过一次到达终点或陷阱的完整回合，每一步观察到的奖励都严格是 `0`，而 Q 表的初始值也全部是 `0`，因此 `TD Target = 0 + γ×0 = 0`，`TD Error = 0 - 0 = 0`，更新量恒为0。**Q 表第一次发生变化，必然精确地发生在第一次到达终点或陷阱的那个回合、且是这个回合的最后一步（因为只有终点/陷阱的转移，奖励才不是0）。**

```
第一次到达终点/陷阱是第几轮episode: 7     （具体数字取决于随机种子，每次运行会不同）
Q表第一次发生非零更新是第几轮episode: 7    （这个数字必然和上面完全相等）
```

（如果把网格从 4×4 换成更大的网格，比如 8×8 甚至更大，纯随机游走"凭运气"撞对终点所需要的期望回合数会急剧增加，这正是稀疏奖励在大规模状态空间下训练极其低效的根本原因。）

# 三、方案 B：基于势函数的奖励塑形

用"到终点的负曼哈顿距离"作为势函数 `Φ(s)`：

```python
def manhattan_distance(state, goal):
    return abs(state[0] - goal[0]) + abs(state[1] - goal[1])

def potential(state, goal=GOAL):
    return -manhattan_distance(state, goal)

def step_shaped(state, action, gamma=0.9):
    next_state = move(state, action)

    if next_state == GOAL:
        base_reward, done = 10.0, True
    elif next_state == TRAP:
        base_reward, done = -10.0, True
    else:
        base_reward, done = 0.0, False

    shaping = gamma * potential(next_state) - potential(state)   # F(s,s') = γΦ(s') - Φ(s)
    return next_state, base_reward + shaping, done
```

**手工验证几个具体的塑形奖励数值**，直接感受它如何从第一步就区分"好动作"和"坏动作"：

```python
gamma = 0.9

# 情况1：从起点(0,0)出发，向右走到(0,1) —— 到终点(3,3)的曼哈顿距离 从6减少到5，朝目标靠近
s, s_next = (0, 0), (0, 1)
shaping_toward = gamma * potential(s_next) - potential(s)
print(f"朝目标前进一步 {s}->{s_next}: Φ(s)={potential(s)}, Φ(s')={potential(s_next)}, 塑形奖励={shaping_toward:.2f}")

# 情况2：假设智能体在(0,1)时选择向左走回(0,0) —— 距离从5变回6，背离目标
s, s_next = (0, 1), (0, 0)
shaping_away = gamma * potential(s_next) - potential(s)
print(f"背离目标一步 {s}->{s_next}: Φ(s)={potential(s)}, Φ(s')={potential(s_next)}, 塑形奖励={shaping_away:.2f}")
```

按公式手工计算：`Φ((0,0)) = -6`，`Φ((0,1)) = -5`。

朝目标前进：`shaping = 0.9×(-5) - (-6) = -4.5+6 = 1.5`

背离目标：`shaping = 0.9×(-6) - (-5) = -5.4+5 = -0.4`

**预期输出**：

```
朝目标前进一步 (0, 0)->(0, 1): Φ(s)=-6, Φ(s')=-5, 塑形奖励=1.50
背离目标一步 (0, 1)->(0, 0): Φ(s)=-5, Φ(s')=-6, 塑形奖励=-0.40
```

**这正是奖励塑形的核心价值**：智能体从训练的第一步开始，"朝目标前进"就能拿到 `+1.5` 的正向反馈，"背离目标"则会拿到 `-0.4` 的负向反馈——**完全不需要等到真正抵达终点，学习信号从第一步就存在，而且方向完全正确**。可以把这两个具体数值代入 `q_learning_track_first_nonzero_update(step_shaped)` 重新运行一遍上一节的验证函数，会发现 Q 表在第一轮 episode、第一步之内就会发生更新——这与稀疏奖励下"必须等到第一次撞对终点"形成了极其鲜明的对比。

# 四、实现最简 Policy Gradient（REINFORCE）

前面两节的 Q-Learning 依赖一张能被完整列举的表格，但第8.4节讲过，真实机器人的连续动作空间根本没办法列表。这里我们用一个最简化的"连续动作老虎机"任务，亲手实现一次 Policy Gradient，直观感受"直接优化一个连续分布的参数"是怎么做到的。

**任务设定**：动作 `a` 是一个连续实数，从一个高斯分布 `a ~ N(μ, σ²)` 中采样（`σ` 固定为1.0，只训练均值 `μ`），奖励是"离一个目标值 `target=3.0` 有多近"：`r(a) = -(a - target)²`。直觉上，只要 `μ` 越接近 `3.0`，采样出来的动作 `a` 平均而言就越接近目标，拿到的奖励也就越高——**理论上的最优解，就是让 `μ` 精确等于 `3.0`**。

```python
import numpy as np

np.random.seed(0)

target = 3.0
sigma = 1.0     # 固定标准差，只训练均值 mu
mu = 0.0        # mu 的初始值，故意设置得离目标很远
lr = 0.05

mu_history = [mu]
for step in range(500):
    a = np.random.normal(mu, sigma)          # 从当前策略 π(a|mu, sigma) 中采样一个动作
    reward = -(a - target) ** 2               # 计算这个动作的奖励

    grad_log_pi = (a - mu) / (sigma ** 2)     # 高斯分布对均值的对数似然梯度：∂log π(a|μ,σ)/∂μ = (a-μ)/σ²
    mu += lr * grad_log_pi * reward           # Policy Gradient 更新：∇J(θ) = E[∇log π(a|s)·G_t] 的单步蒙特卡洛估计

    mu_history.append(mu)

print("初始 mu:", mu_history[0])
print("训练后 mu:", mu_history[-1])
print("目标 target:", target)
```

**预期趋势**：`mu` 应该从初始值 `0.0` 逐渐增大，最终收敛到目标值 `3.0` 附近（因为每次采样到的奖励，会把 `mu` 向"能拿到更高奖励的方向"推动——如果某次采样的 `a` 比 `mu` 更靠近 `target`（也就意味着这次的奖励相对较高），梯度更新就会把 `mu` 向这个 `a` 的方向拉近）。由于整个过程依赖随机采样，具体的收敛曲线每次运行都会有所不同，但500步之后，`mu` 应该已经明显偏离初始值 `0.0`、大幅向 `3.0` 靠近（收敛的精确程度取决于学习率和步数，通常最终会落在 `3.0` 附近小范围内波动）。

```python
print("\n倒数10步的 mu 变化:", [round(v, 3) for v in mu_history[-10:]])
```

这短短十几行代码，就是本章"从表格到连续动作"这一节讲的 Policy Gradient / REINFORCE 算法的完整核心——**Actor-Critic 只是在这个基础上多加了一个 Critic 网络来降低方差，PPO 只是再加了一层"更新幅度不能太大"的限制，数学骨架完全一样。**

# 五、思考题

上面手工验证的势函数 `Φ(s) = -曼哈顿距离`，恰好是这个网格世界的"真实最优价值函数"的一个很粗糙的近似（真正的最优价值函数还需要考虑陷阱的位置）。可以思考一下：如果势函数设计得很糟糕——比如错误地把陷阱 `(1,1)` 也当成了一个"更靠近目标"的位置（势函数在陷阱附近设计成正值），会发生什么？这种情况下，基于势函数的塑形理论保证"不改变最优策略"是否还成立？为什么在实践中，一个"方向错误"的势函数，即使理论上不改变最优策略，也可能严重拖慢实际的学习速度？

✅ 严格验证了纯稀疏奖励下"Q 表第一次发生更新"和"第一次到达终点/陷阱"这两个事件精确地同时发生——这是一个数学上必然成立、不依赖随机种子的结论 ✅ 通过手工计算验证了基于势函数的奖励塑形，能够从训练的第一步开始，就为"朝目标前进"和"背离目标"两种动作给出方向正确、幅度合理的差异化奖励信号 ✅ 用不到15行代码实现了最简版的 Policy Gradient（REINFORCE），验证了连续动作分布的参数可以直接通过采样和梯度更新收敛到最优值，不需要任何表格 ✅ 直观理解了为什么"设计一个好的奖励函数"，往往是决定强化学习训练效率最关键的一步
