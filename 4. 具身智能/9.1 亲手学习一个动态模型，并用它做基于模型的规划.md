# 二、任务与真实动态

沿用之前几章的2D导航场景：一个点状机器人，状态是位置 `s=(x,y)`，动作是一个二维单位方向向量 `a`，每一步按固定步长移动：

```python
import numpy as np

np.random.seed(0)

STEP_SIZE = 0.3

def true_dynamics(s, a):
    """真实环境的动态方程：下一状态 = 当前状态 + 步长 × 动作方向（未知，机器人不能直接看到这个公式）"""
    return s + STEP_SIZE * a
```

**注意**：和第4章不同，这里我们**假装完全不知道** `true_dynamics` 这个公式——机器人只能通过"执行一个动作、观察结果"来积累数据，然后自己学习出这个动态关系。

# 三、第一步：收集随机交互数据

```python
def collect_random_data(n=1000):
    S = np.random.uniform(-5, 5, size=(n, 2))
    angles = np.random.uniform(0, 2 * np.pi, size=n)
    A = np.stack([np.cos(angles), np.sin(angles)], axis=1)   # 随机单位向量动作
    S_next = np.array([true_dynamics(s, a) for s, a in zip(S, A)])
    return S, A, S_next

S, A, S_next = collect_random_data(1000)
Delta = S_next - S    # 状态的变化量
```

---

# 四、第二步：从数据中学习动态模型

因为状态变化量 `Δs = s' - s` 只依赖于动作 `a`（`Δs = STEP_SIZE × a`），这是一个精确的线性关系，可以直接用最小二乘回归学出来：

```python
# 用最小二乘拟合 Delta ≈ A @ W
W, residuals, rank, singular_values = np.linalg.lstsq(A, Delta, rcond=None)

print("学到的动态模型权重矩阵 W:\n", W)
print("\n理论真值 (STEP_SIZE × 单位矩阵):\n", STEP_SIZE * np.eye(2))
```

**预期输出**：因为这是一个完全没有噪声的精确线性关系，且采样的动作方向覆盖了完整的360°，最小二乘解应该能几乎精确地恢复出真实的动态方程（浮点数精度范围内的误差）：

```
学到的动态模型权重矩阵 W:
 [[0.3 0. ]
 [0.  0.3]]

理论真值 (STEP_SIZE × 单位矩阵):
 [[0.3 0. ]
 [0.  0.3]]
```

```python
def learned_dynamics(s, a):
    """学到的动态模型，之后的规划完全基于这个模型，不再调用真实环境的 true_dynamics"""
    return s + a @ W
```

---

# 五、第三步：用随机打靶（Random Shooting）做 MPC 规划

```python
def plan_action_random_shooting(s, goal, n_candidates=200, horizon=5):
    best_action = None
    best_final_dist = np.inf

    for _ in range(n_candidates):
        angles = np.random.uniform(0, 2 * np.pi, size=horizon)
        candidate_actions = np.stack([np.cos(angles), np.sin(angles)], axis=1)

        # 关键：全部用"学到的模型"在脑海中模拟，完全不接触真实环境
        s_sim = s.copy()
        for a in candidate_actions:
            s_sim = learned_dynamics(s_sim, a)

        final_dist = np.linalg.norm(s_sim - goal)
        if final_dist < best_final_dist:
            best_final_dist = final_dist
            best_action = candidate_actions[0]   # MPC 只取规划序列的第一个动作

    return best_action
```

# 六、完整的规划-执行循环

```python
goal = np.array([0.0, 0.0])
s = np.array([3.0, 4.0])   # 起点，到目标的距离恰好是 sqrt(3²+4²) = 5.0
trajectory = [s.copy()]

for step in range(20):
    a = plan_action_random_shooting(s, goal, n_candidates=200, horizon=5)
    s = true_dynamics(s, a)     # 注意：这一步是在真实环境里执行，不是模拟
    trajectory.append(s.copy())

print("初始到目标的距离:", np.linalg.norm(trajectory[0] - goal))
print("最终到目标的距离:", np.linalg.norm(trajectory[-1] - goal))
print("是否单调接近目标（每一步距离是否基本递减）:",
      [round(np.linalg.norm(p - goal), 2) for p in trajectory])
```

**预期结果**：起点到目标的距离精确为 `sqrt(3²+4²)=5.0`。每一步的执行动作，都是"从200条随机采样的5步候选序列中，挑选出用学到的模型预测最终最接近目标的那一条"——由于学到的动态模型已经近乎精确，"脑海中模拟"和"真实执行"几乎完全一致，200条候选里大概率能找到一条方向足够接近"直指目标"的序列。步长是0.3，理论上大约需要 `5.0/0.3 ≈ 17` 步就能非常接近目标，因此20步之后，到目标的距离应该已经大幅下降（具体的下降曲线会因为"随机打靶"每一步的采样质量有一定波动，但整体趋势必须是持续接近目标，不应该出现越走越远的情况）。

**这里最值得强调的一点是**：从头到尾，我们没有训练任何一个"策略网络"来直接输出"该往哪走"——**唯一被训练的，只有一个"给定状态和动作，预测下一个状态"的动态模型**，决策能力完全来自于"用这个模型做规划搜索"，而不是靠一个专门学出来的策略函数。这正是 Model-Based 方法和第3、4章 Model-Free / 模仿学习方法在能力来源上的根本区别。

# 七、思考题

本节的动态模型之所以能被几乎精确地学出来，是因为真实动态本身就是一个简单的线性关系。可以思考一下：如果真实的机器人动态是高度非线性的（比如涉及碰撞、摩擦力、接触力的突变），线性回归模型还能不能准确拟合？这种情况下，"基于一个不准确的动态模型做长时间规划"会带来什么风险？这与第9.4节讨论的"动态模型不准确导致的误差累积"是同一个问题的具体体现。
