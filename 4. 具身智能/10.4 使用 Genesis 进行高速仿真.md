# 一、安装与基础用法（参考代码，具体接口请以官方文档为准）

```bash
pip install genesis-world
```

```python
import genesis as gs

gs.init(backend=gs.cpu)   # 没有独立显卡也可以用 CPU 后端运行；有 NVIDIA 显卡可以换成 gs.gpu 获得更快的速度

scene = gs.Scene(show_viewer=False)   # show_viewer=False 表示不打开可视化窗口，适合无显示器环境

# 添加一个地面和一个球体（Genesis 提供了一批基础几何体，也支持加载URDF/MJCF等标准机器人模型文件）
plane = scene.add_entity(gs.morphs.Plane())
ball = scene.add_entity(gs.morphs.Sphere(radius=0.1, pos=(0, 0, 1.0)))

scene.build()

for i in range(100):
    scene.step()
    if i % 20 == 0:
        pos = ball.get_pos()
        print(f"step={i}: 球的位置 = {pos}")
```

**预期趋势**：这是一个最基础的"自由落体"仿真——一个初始高度为1.0米的球，在重力作用下应该逐渐下落，`球的位置`里的高度分量（通常是 z 轴）应该随着 `step` 的增加持续减小，直到落到地面（`z≈0.1`，等于球的半径）附近趋于稳定。这和第 9 章我们手写的"点导航"环境的核心区别在于：**这里的下落速度、加速度、与地面碰撞后的反弹或静止行为，全部由 Genesis 内置的物理引擎根据真实的重力常数、材质属性自动计算，不需要我们手写任何运动方程。**

# 二、大规模并行：与 Isaac Lab 同样的能力，更轻量的实现

```python
scene_batch = gs.Scene(show_viewer=False)
plane = scene_batch.add_entity(gs.morphs.Plane())
ball = scene_batch.add_entity(gs.morphs.Sphere(radius=0.1, pos=(0, 0, 1.0)))
scene_batch.build(n_envs=1000)   # 一次性并行构建1000个独立的场景副本

for i in range(50):
    scene_batch.step()

print("并行环境数量:", scene_batch.n_envs)
```

**这与10.3节 Isaac Lab 的 `num_envs=4096` 是同一个思路——用 GPU（或多核 CPU）的并行计算能力，一次性仿真大量独立的环境副本**，只是 Genesis 用一个体积更小、安装更简单的 Python 包实现了类似的能力，这也是它自发布以来迅速获得关注的原因之一。
