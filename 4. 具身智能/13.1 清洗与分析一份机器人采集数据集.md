# 二、模拟一份混合来源的采集数据集

```python
import numpy as np
import pandas as pd

np.random.seed(0)

def simulate_data_collection(n_teleop=50, n_policy_assisted=150, policy_success_rate=0.6):
    records = []
    episode_id = 0

    # 遥操作数据：人类专家远程操控，假设全部成功（这是遥操作数据质量高的典型特征）
    for _ in range(n_teleop):
        records.append({
            "episode_id": episode_id, "method": "teleop",
            "success": True, "num_steps": int(np.random.randint(15, 25)),
        })
        episode_id += 1

    # 策略辅助采集数据：用当前还不完美的策略自主执行并采集，会包含真实的失败案例
    for _ in range(n_policy_assisted):
        success = bool(np.random.random() < policy_success_rate)
        records.append({
            "episode_id": episode_id, "method": "policy_assisted",
            "success": success, "num_steps": int(np.random.randint(10, 40)),
        })
        episode_id += 1

    return pd.DataFrame(records)

df = simulate_data_collection()
print("采集数据集总览:\n", df.groupby("method")["success"].agg(["mean", "count"]))
```

**预期输出**：`teleop` 的成功率理论上精确等于 `1.0`（因为代码里设定为必然成功），`policy_assisted` 的成功率理论概率是 `0.6`，实际采样150条会有一定统计波动（标准差约为 `sqrt(150×0.6×0.4)/150 ≈ 0.04`，所以实际数值大致会落在 `0.56~0.64` 之间）：

```
采集数据集总览:
                    mean  count
method
policy_assisted  0.593     150
teleop           1.000      50
```

# 三、朴素的做法：只保留成功数据

```python
naive_training_set = df[df["success"] == True]
print(f"朴素筛选（只留成功案例）后训练集大小: {len(naive_training_set)} / {len(df)}"
      f"  ({len(naive_training_set) / len(df):.1%})")
```

**预期输出**（`50 + 150×0.6 ≈ 140`，实际数值会因抽样波动有小幅出入）：

```
朴素筛选（只留成功案例）后训练集大小: 139 / 200  (69.5%)
```

这种做法在很多项目的早期阶段很常见——但正如 13.3 节强调的，**这样做直接丢掉了大约30%的"策略辅助采集"数据，而这部分恰恰是最能暴露当前策略薄弱环节的数据**。

# 四、数据飞轮的做法：失败数据单独归档，作为高优先级复核对象

```python
failure_set = df[(df["method"] == "policy_assisted") & (df["success"] == False)]
print(f"\n失败样本数量: {len(failure_set)}")
print("这些样本不应被丢弃，而应该：")
print("  1. 优先交给人类专家复核，标注'正确应该怎么做'（对应第4章的 DAgger 纠正步骤）")

print("  3. 用改进后的策略，开始下一轮数据采集，形成飞轮")

# 简单的数据清洗示例：剔除步数异常短的episode（很可能是传感器故障或提前中断导致的脏数据）
MIN_VALID_STEPS = 5
clean_df = df[df["num_steps"] >= MIN_VALID_STEPS]
print(f"\n剔除步数少于{MIN_VALID_STEPS}步的异常episode: {len(df) - len(clean_df)} 条被移除")
```

**预期输出**（失败样本数量约为 `150×0.4≈60` 条，实际数值随抽样波动；本例中 `num_steps` 最小值设定为10，不会低于`MIN_VALID_STEPS=5`，所以异常剔除数量应为0，这一步用来展示"数据清洗检查该怎么写"，即使这次示例数据里没有真正触发）：

# 五、思考题

本节用"是否成功"这一个单一标准来判断数据是否有价值，但真实的失败案例里，也存在"轻微偏差、几乎成功"和"完全跑偏、南辕北辙"这两种性质完全不同的失败。可以思考一下：如果要对失败样本做进一步的优先级排序（比如优先把最有限的人工复核精力，投入到哪一类失败样本上），可以设计哪些量化指标（提示：可以考虑"距离目标状态有多近""策略对该状态的自信程度/不确定性有多高"这两个方向，这与第 9 章讨论过的"用模型集成估计不确定性"是同一个思路）？
