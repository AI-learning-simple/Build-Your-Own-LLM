# 二、加载一个内置的 CartPole 模型

PyBullet 自带一批标准的机器人/物理模型文件（URDF 格式），`cartpole.urdf` 就是其中之一——这正是强化学习文献里最经典的"小车顶一根杆子"任务，第3章末尾提到过它在 Gymnasium 里的对应环境 `CartPole-v1`，这里我们改用一个真实的物理引擎来驱动它，而不是简化的解析公式：

```python
import pybullet as p
import pybullet_data

# DIRECT 模式没有可视化窗口，适合服务器/无显示器环境；本地想看动画效果可以把 p.DIRECT 换成 p.GUI
physics_client = p.connect(p.DIRECT)
p.setAdditionalSearchPath(pybullet_data.getDataPath())   # 让 PyBullet 找到自带的模型文件
p.setGravity(0, 0, -9.8)

plane_id = p.loadURDF("plane.urdf")
cartpole_id = p.loadURDF("cartpole.urdf")

print("CartPole 的关节数量:", p.getNumJoints(cartpole_id))
for i in range(p.getNumJoints(cartpole_id)):
    joint_info = p.getJointInfo(cartpole_id, i)
    print(f"  关节{i}: 名称={joint_info[1].decode()}, 类型={joint_info[2]}")
```

**预期输出**：`cartpole.urdf` 由两个关节组成——一个滑动关节（控制小车左右移动）和一个旋转关节（控制杆的摆动角度）：

```
CartPole 的关节数量: 2
  关节0: 名称=slider_to_cart, 类型=1   （类型1 = PRISMATIC，对应第2章讲过的移动关节）
  关节1: 名称=cart_to_pole, 类型=0     （类型0 = REVOLUTE，对应第2章讲过的旋转关节）
```

（这正是第2章讲过的两种关节类型，在一个真实模型文件里的具体体现。）

# 三、施加一个恒定的力，观察真实物理仿真的动力学

```python
for step in range(200):
    # 给小车（关节0）施加一个恒定的水平力，模拟一个"不做任何平衡控制"的开环系统
    p.setJointMotorControl2(cartpole_id, 0, controlMode=p.TORQUE_CONTROL, force=5.0)
    p.stepSimulation()

    if step % 40 == 0:
        cart_state = p.getJointState(cartpole_id, 0)
        pole_state = p.getJointState(cartpole_id, 1)
        cart_pos = cart_state[0]
        pole_angle = pole_state[0]
        print(f"step={step:3d}:  小车位置={cart_pos:.3f} m,  杆的角度={pole_angle:.3f} rad")

p.disconnect()
```

**预期趋势**：因为我们施加的是一个持续不变的力、且完全没有任何平衡控制逻辑，小车会持续朝力的方向加速移动，而杆由于惯性会逐渐向后倾倒——`小车位置`应该随时间稳步增大，`杆的角度`应该逐渐偏离 `0`（竖直状态）且偏离幅度越来越大，最终大概率会超过一个较大的角度（可以理解为"杆已经倒下"）。**具体的数值曲线取决于 PyBullet 内部真实的质量、惯性、摩擦参数**，这是它和第3章手写网格世界最本质的区别：**网格世界的每一次状态转移都是我们自己用 `if/elif` 写死的规则；而这里的每一次状态变化，都是物理引擎基于牛顿力学方程真实计算出来的结果**——这正是"仿真器"这个基础设施相比"手写规则环境"的核心价值：**只需要描述清楚物体的质量、形状、关节约束，剩下的动力学演化完全由物理引擎自动计算，不需要我们自己推导任何运动方程。**

# 四、思考题

如果想让这根杆保持竖直不倒，需要在每一步根据"杆当前的角度和角速度"计算出一个合适的力，反向施加给小车——这正是一个典型的控制问题（可以用第8、9章讨论过的强化学习或基于模型的规划来求解，也可以用经典控制论里的 LQR 控制器）。可以尝试自己写一个简单的比例控制器：`force = -K × pole_angle`，调整增益 `K`，看看能不能让杆保持较长时间不倒（这和第11.1节将会讨论的"比例增益控制系统"是完全同一类问题）。
