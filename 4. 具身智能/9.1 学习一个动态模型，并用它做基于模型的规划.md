# 二、任务与真实动态

沿用之前几章的2D导航场景：点状机器人的状态是位置 `s=(x,y)`，动作是长度不超过 1 的二维向量 `a`，每一步按比例移动，最大位移为 `STEP_SIZE`。辨识时用单位向量覆盖方向，规划时也允许短动作和零动作：

```python
import numpy as np

np.random.seed(0)

STEP_SIZE = 0.3

def true_dynamics(s, a):
    """真实环境的动态方程：下一状态 = 当前状态 + 步长 × 动作方向（未知，机器人不能直接看到这个公式）"""
    return s + STEP_SIZE * a
```

**注意**：和第4章不同，这里我们**假装完全不知道**`true_dynamics` 这个公式——机器人只能通过"执行一个动作、观察结果"来积累数据，然后自己学习出这个动态关系。

# 三、第一步：收集随机交互数据

```python
def collect_random_data(n=1000):
    S = np.random.uniform(-5, 5, size=(n, 2))
    angles = np.random.uniform(0, 2 * np.pi, size=n)
    A = np.stack([np.cos(angles), np.sin(angles)], axis=1)   # 随机单位向量动作
    S_next = np.array([true_dynamics(s, a) for s, a in zip(S, A)])
    return S, A, S_next

S, A, S_next = collect_random_data(1000)
Delta = S_next - S    # 状态的变化量
```

---

# 四、第二步：从数据中学习动态模型

因为状态变化量 `Δs = s' - s` 只依赖于动作 `a`（`Δs = STEP_SIZE × a`），这是一个精确的线性关系，可以直接用最小二乘回归学出来：

```python
# 用最小二乘拟合 Delta ≈ A @ W
W, residuals, rank, singular_values = np.linalg.lstsq(A, Delta, rcond=None)

print("学到的动态模型权重矩阵 W:\n", W)
print("\n理论真值 (STEP_SIZE × 单位矩阵):\n", STEP_SIZE * np.eye(2))
```

**预期输出**：因为这是一个完全没有噪声的精确线性关系，且采样的动作方向覆盖了完整的360°，最小二乘解应该能几乎精确地恢复出真实的动态方程（浮点数精度范围内的误差）：

```
学到的动态模型权重矩阵 W:
 [[0.3 0. ]
 [0.  0.3]]

理论真值 (STEP_SIZE × 单位矩阵):
 [[0.3 0. ]
 [0.  0.3]]
```

```python
def learned_dynamics(s, a):
    """学到的动态模型，之后的规划完全基于这个模型，不再调用真实环境的 true_dynamics"""
    return s + a @ W
```

# 五、第三步：用随机打靶（Random Shooting）做 MPC 规划

```python
def plan_action_random_shooting(s, goal, n_candidates=200, horizon=5):
    # 本节把动作扩展为长度 <= 1 的向量，包含零动作以允许停留。
    angles = np.random.uniform(0, 2 * np.pi, size=(n_candidates, horizon))
    lengths = np.random.uniform(0, 1, size=(n_candidates, horizon, 1))
    candidates = lengths * np.stack([np.cos(angles), np.sin(angles)], axis=-1)
    candidates = np.concatenate([np.zeros((1, horizon, 2)), candidates])
    best_action, best_cost = np.zeros(2), np.inf
    for candidate_actions in candidates:
        s_sim, cost = s.copy(), 0.0
        for a in candidate_actions:
            s_sim = learned_dynamics(s_sim, a)
            cost += np.sum((s_sim - goal) ** 2) + 0.01 * np.sum(a ** 2)
        cost += np.sum((s_sim - goal) ** 2)  # 阶段代价 + 终点代价
        if cost < best_cost:
            best_cost, best_action = cost, candidate_actions[0]
    return best_action
```

# 六、完整的规划-执行循环

```python
goal = np.array([0.0, 0.0])
s = np.array([3.0, 4.0])   # 起点，到目标的距离恰好是 sqrt(3²+4²) = 5.0
trajectory = [s.copy()]

epsilon = 0.1
for step in range(80):
    if np.linalg.norm(s - goal) <= epsilon:
        break  # 用执行后的状态确认到达，不是只看模型预测
    a = plan_action_random_shooting(s, goal, n_candidates=200, horizon=5)
    s = true_dynamics(s, a)     # 在本节定义的环境中执行
    trajectory.append(s.copy())

distances = np.array([np.linalg.norm(p - goal) for p in trajectory])
print("初始/最终距离:", distances[0], distances[-1])
print("成功/步数:", distances[-1] <= epsilon, len(trajectory)-1)
print("实际是否单调不增:", bool(np.all(np.diff(distances) <= 1e-10)))

# 已知模型的直达控制仅作 oracle 基准，不属于学习规划器。
s_oracle = trajectory[0].copy()
for oracle_steps in range(80):
    if np.linalg.norm(s_oracle - goal) <= epsilon:
        break
    a = (goal - s_oracle) / max(STEP_SIZE, np.linalg.norm(goal - s_oracle))
    s_oracle = true_dynamics(s_oracle, a)
print("直达基准最终距离:", np.linalg.norm(s_oracle - goal))
```

**如何解释输出**：初始距离为 5，单步最大位移为 0.3，所以直达基准约需 17 步。随机 MPC 优化的是整段累计代价，不是首步距离；即使模型精确，也不保证每一步更接近、更不保证 20 步内成功。只用终点代价时还可能选中“先绕远、后靠近”的序列。新版加入阶段代价、零动作和 `epsilon` 停止，改善目标附近抖动的处理，但仍没有一般的单调收敛证明。应报告实际成功与超时、路径长度、最终距离，并用多个种子与零动作/直达基准比较；这里不沿用旧版的结果承诺。

**这里最值得强调的一点是**：从头到尾，我们没有训练任何一个"策略网络"来直接输出"该往哪走"——**唯一被训练的，只有一个"给定状态和动作，预测下一个状态"的动态模型**，决策能力完全来自于"用这个模型做规划搜索"，而不是靠一个专门学出来的策略函数。这正是 Model-Based 方法和第3、4章 Model-Free / 模仿学习方法在能力来源上的根本区别。

# 七、思考题

本节的动态模型之所以能被几乎精确地学出来，是因为真实动态本身就是一个简单的线性关系。可以思考一下：如果真实的机器人动态是高度非线性的（比如涉及碰撞、摩擦力、接触力的突变），线性回归模型还能不能准确拟合？这种情况下，"基于一个不准确的动态模型做长时间规划"会带来什么风险？这与第9.4节讨论的"动态模型不准确导致的误差累积"是同一个问题的具体体现。

# 本实验总结

- 完全没有训练策略网络，仅从随机交互数据中学习了一个动态模型，就能通过随机打靶规划完成导航任务
- 验证了在动态关系足够简单、数据覆盖足够充分的情况下，学到的动态模型可以精确到与真实动态几乎一致
- 直观体会了 Model-Based 强化学习"决策能力来自于对模型的规划搜索，而非直接学习策略"这一核心特征
