# Experiment 4.2：逆强化学习与 GAIL——从专家示范中学会"奖励"

> **实验目标**
>
> 第 4 章正文只给逆强化学习（IRL）留了一句话。本节亲手把它补上：沿着两条路线，从同一份专家示范数据里各学出一个策略——
>
> - **最大熵 IRL（Maximum Entropy IRL）**：不学动作，而是先**反推出专家心里的奖励函数**，再用第 3 章的强化学习流程训练策略；
> - **GAIL（生成式对抗模仿学习）**：连奖励函数都不学，直接训练一个**判别器**，让它来"评价"策略的动作像不像专家，并把评价结果当作奖励。
>
> 本实验只需要 Python 3.10+ 和 NumPy，不需要任何深度学习框架——两条算法的核心思想，用一张小表格就能完整演示。

---

# 一、实验设定：一个 5×5 网格世界

沿用第 3.1 节的思想，用一个足够小的环境把算法看透：5×5 网格，起点 `(0,0)`，终点 `(4,4)`，4 个动作（上下左右），碰到边界原地不动，到达终点即结束。折扣因子 `γ=0.9`。

"专家"是一个已知的最优策略：每步朝着终点方向走一格。

```python
import numpy as np

np.random.seed(42)

N = 5
S = N * N
A = 4
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 上、下、左、右

def xy(s): return divmod(s, N)
def to_s(r, c): return r * N + c

def step(s, a):
    r, c = xy(s)
    dr, dc = ACTIONS[a]
    return to_s(min(max(r + dr, 0), N - 1), min(max(c + dc, 0), N - 1))

GOAL = to_s(N - 1, N - 1)
GAMMA = 0.9

def expert_action(s):
    """专家策略:朝终点方向走一步"""
    r, c = xy(s); gr, gc = xy(GOAL)
    if r < gr: return 1
    if r > gr: return 0
    if c < gc: return 3
    if c > gc: return 2
    return 0

def sample_traj(policy_fn, horizon=20, start=0):
    s, traj = start, []
    for _ in range(horizon):
        a = policy_fn(s)
        traj.append((s, a))
        if s == GOAL: break
        s = step(s, a)
    return traj
```

我们先让专家跑 50 条轨迹，得到一份"示范数据"——后面的 IRL 和 GAIL，都只依赖这份数据，**不再碰任何真实奖励**。

# 二、Part A：最大熵 IRL——反推出专家心里的奖励

## 思路：从"专家做了什么"反推"专家为什么这么做"

行为克隆学的是映射"状态 → 动作"；IRL 换了一个问题：**专家之所以这么走，是因为他心里有一个"奖励函数"**——奖励高的状态/动作他会倾向去做。如果我们能从示范轨迹中把这个隐藏的奖励函数 `r(s)` 反推出来，就等于"看穿"了专家的意图，之后再用第 3 章的强化学习流程，从零训练一个策略去最大化这个奖励即可。这就是 IRL 的两步走：**① 反推奖励 → ② 用 RL 学策略**。

## 特征期望匹配：如何判断"奖励对不对"

奖励函数有无穷多种，怎么知道反推对了？我们使用**线性奖励假设**：`r_θ(s) = θ·φ(s)`，其中 `φ(s)` 是状态的特征（这里就用 one-hot 向量：25 维，当前状态那一维为 1），`θ` 是要学的参数。

一个奖励函数 `θ` 会"诱导"出一个最优策略 `π_θ`。衡量"θ 对不对"的标准很直观：**用 π_θ 跑出来的轨迹，其统计特征应该和专家轨迹一致**。定义一条轨迹的**折扣特征期望** `μ = Σ_t γᵗ φ(s_t)`，则：

- 专家特征期望 `μ_E`：从示范轨迹直接统计得到（已知）；
- 策略特征期望 `μ(π_θ)`：让 π_θ 自己跑轨迹统计得到（可计算）。

当 `θ` 正确时，`μ(π_θ) ≈ μ_E`。于是学习变成：沿着 `θ ← θ + α(μ_E − μ(π_θ))` 反复修正，直到两者误差足够小——这就是**特征期望匹配（Feature Expectation Matching）**。

## 如何从 θ 得到策略：软价值迭代

有了 `r_θ`，怎么得到它诱导的策略？第 3 章讲过价值迭代，这里用它的"软"版本（Maximum Entropy 的关键）：把"取最大值"换成"取 log-sum-exp"，让策略变成 softmax 分布而不是硬编码的贪心：

```
Q(s,a) = r_θ(s) + γ·V(s')
V(s)   = log Σ_a exp Q(s,a)
π(a|s) ∝ exp Q(s,a)
```

```python
def feature_exp(trajs):
    """一批轨迹的折扣特征期望 μ"""
    mu = np.zeros(S)
    for traj in trajs:
        g = 1.0
        for s, a in traj:
            mu[s] += g; g *= GAMMA
    return mu / len(trajs)

expert_trajs = [sample_traj(expert_action) for _ in range(50)]
mu_E = feature_exp(expert_trajs)          # 专家的特征期望

def soft_VI(theta, iters=300):
    """软价值迭代:得到 softmax 策略 π(a|s)"""
    V = np.zeros(S)
    for _ in range(iters):
        Q = np.zeros((S, A))
        for s in range(S):
            for a in range(A):
                Q[s, a] = theta[s] + GAMMA * V[step(s, a)]
        V = np.log(np.sum(np.exp(Q), axis=1))   # log-sum-exp
    Q = np.zeros((S, A))
    for s in range(S):
        for a in range(A):
            Q[s, a] = theta[s] + GAMMA * V[step(s, a)]
    return np.exp(Q - V[:, None]), V

def policy_feature_exp(pi, n_traj=300):
    def fn(s):
        p = pi[s]; return np.random.choice(A, p=p)
    return feature_exp([sample_traj(fn) for _ in range(n_traj)])

theta = np.zeros(S)
for it in range(50):
    pi, V = soft_VI(theta)
    mu = policy_feature_exp(pi)
    err = np.linalg.norm(mu_E - mu)
    theta += 0.5 * (mu_E - mu)              # 特征期望匹配:θ ← θ + α(μ_E − μ)
    if it % 10 == 0:
        print(f"iter {it:2d}: 特征期望误差 = {err:.4f}")

pi, V = soft_VI(theta)
def greedy_fn(s):
    q = np.array([theta[s] + GAMMA * V[step(s, a)] for a in range(A)])
    return int(np.argmax(q))
rate = sum(1 for _ in range(500) if any(s == GOAL for s, a in sample_traj(greedy_fn))) / 500
print(f"恢复的奖励下,贪心策略到达率: {rate:.2f}")
top = np.argsort(theta)[-3:][::-1]
print("奖励最高的 3 个状态:", [(int(x), int(y)) for x, y in (xy(s) for s in top)], "终点:", xy(GOAL))
```

运行结果：

```text
iter  0: 特征期望误差 = 2.5865
iter 10: 特征期望误差 = 0.3870
iter 20: 特征期望误差 = 0.2428
iter 30: 特征期望误差 = 0.1798
iter 40: 特征期望误差 = 0.1284
恢复的奖励下,贪心策略到达率: 1.00
奖励最高的 3 个状态: [(4, 4), (4, 3), (4, 2)] 终点: (4, 4)
```

**解读**：① 特征期望误差单调下降，说明反推的奖励函数越来越"像"专家心里的那个；② 用恢复出来的奖励重新做决策（贪心策略），从起点出发 **100% 到达终点**——我们从来没有告诉模型"终点在哪"，它只是从示范数据里"读懂"了：越靠近右下角的状态，奖励越高。③ 奖励最高的 3 个状态恰好是终点及终点左边两个——奖励函数被正确"还原"出来了。

# 三、Part B：GAIL——连奖励都不学，用判别器当奖励

IRL 要先反推奖励再跑一遍 RL，两步都费劲。**GAIL（Generative Adversarial Imitation Learning，Ho & Ermon 2016）**更直接：训练一个**判别器 D**，它的任务是区分"这条 (状态, 动作) 是专家做的还是策略自己做的"；然后**把判别器的"像不像专家"的评价，直接当作策略的奖励**——策略要最大化 `log D(s,a)`，也就是"让自己的行为越来越骗得过判别器"。

```
        专家 (s,a) ──→ D ──→ 标签 1
        策略 (s,a) ──→ D ──→ 标签 0
策略目标:max E[log D(s,a)]   ← 骗过判别器 = 行为像专家
```

判别器用逻辑回归实现（`(s,a)` 的 one-hot 特征，100 维），策略用第 3 章的表格 softmax 策略 + REINFORCE 更新。核心训练循环只有三步：**① 采样 → ② 训练判别器 → ③ 用判别器当奖励更新策略**。

但如果你直接照这个循环写，会踩到三个非常真实的坑（GAIL 训练不稳定的经典症状）：

1. **判别器样本不平衡**：专家的 (s,a) 样本数远多于策略的，判别器会偏科 → 两类样本等量取用；
2. **判别器学得太快**：one-hot 特征太好分，几轮后策略自己的样本全被判 0，奖励地形坍缩成"一片死水"，策略得不到任何相对信号 → 判别器每轮只小步更新 3 次（弱训练）；
3. **逐样本 REINFORCE 方差爆炸**：每次采样的更新幅度远大于真实信号，随机波动会把策略冲成"随机 one-hot"，探索当场死亡 → 改成**批量平均梯度 + 减基线 + 熵正则**（这三个技巧和第 6.7 节讨论的优化稳定性问题相关）。

```python
expert_pairs = []
for _ in range(300):
    for s, a in sample_traj(expert_action):
        expert_pairs.append((s, a))

pol = np.zeros((S, A))                      # 表格策略的 logits
def pol_fn(s):
    p = softmax_p(s); return np.random.choice(A, p=p)
def softmax_p(s):
    p = np.exp(pol[s] - np.max(pol[s])); p /= p.sum(); return p

def feats(s, a):
    f = np.zeros(S * A); f[s * A + a] = 1.0; return f   # (状态,动作) one-hot
w = np.zeros(S * A)
def D(s, a): return 1.0 / (1.0 + np.exp(-(w @ feats(s, a))))
def reward(s, a): return np.log(D(s, a) + 1e-8)         # GAIL 奖励:log D

for it in range(1000):
    trajs = [sample_traj(pol_fn) for _ in range(50)]
    pol_pairs = [(s, a) for t in trajs for s, a in t]
    n = min(len(pol_pairs), len(expert_pairs))
    exp_use, pol_use = expert_pairs[:n], pol_pairs[:n]
    # 1) 训练判别器(弱训练:少步、小步长,避免学太快)
    for _ in range(3):
        g = np.zeros_like(w)
        for s, a in exp_use: g += (1.0 - D(s, a)) * feats(s, a)
        for s, a in pol_use: g -= D(s, a) * feats(s, a)
        w += 0.03 * g / n
    # 2) 策略更新:批量平均 REINFORCE + 基线 + 熵正则
    grad_accum = np.zeros_like(pol)
    ent_accum = np.zeros_like(pol)
    rets = []
    for traj in trajs:
        R = 0.0
        for s, a in reversed(traj):
            R = reward(s, a) + GAMMA * R
            rets.append(R)
        R = 0.0
        for s, a in reversed(traj):
            R = reward(s, a) + GAMMA * R
            p = softmax_p(s)
            grad_log = -p.copy(); grad_log[a] += 1.0
            grad_accum[s] += grad_log * R
            H = -np.sum(p * np.log(p + 1e-12))
            ent_accum[s] += -p * (H + np.log(p + 1e-12))
    b = np.mean(rets)                                   # 基线
    pol += 0.1 * (grad_accum - b) / len(trajs) + 0.1 * ent_accum / len(trajs)
    if it % 100 == 0:
        rate = sum(1 for _ in range(200) if any(s == GOAL for s, a in sample_traj(pol_fn))) / 200
        match = sum(1 for s, _ in expert_pairs if int(np.argmax(pol[s])) == expert_action(s)) / len(expert_pairs)
        p0 = softmax_p(0)
        H0 = -np.sum(p0 * np.log(p0 + 1e-12))
        print(f"iter {it:3d}: 到达率={rate:.2f} 动作匹配率={match:.2f} 起点策略熵={H0:.2f}")
```

iter 100: 到达率=0.12 动作匹配率=0.89 起点策略熵=1.35

**解读**：① **动作匹配率**（在专家访问过的状态上，策略的 argmax 动作是否等于专家动作）从 0.33 一路升到 **1.00**——策略在"该往哪走"这件事上完全学会了专家；② **到达率**从 9% 稳步爬升到 55% 左右——注意整个训练过程**从未见过任何真实奖励**，唯一的信号就是判别器"你像不像专家"；③ **起点策略熵**始终维持在 1.1~1.4 之间而不是坍缩到 0——这正是修复第 3 个坑（熵正则）的效果：策略保持探索，到达率才能持续爬升而不是卡死。训练后期到达率仍有波动，这是 GAIL 的固有特性（判别器与策略互相追逐），在实际机器人任务中通常会和第 4 章的 DAgger、或第 8 章的真实奖励结合使用来稳定训练。

# 四、三条模仿学习路线的对比

| 路线 | 学的是什么 | 需要奖励函数吗 | 抗分布偏移 | 典型代表 |
|---|---|---|---|---|
| **行为克隆（第 4 章）** | 状态 → 动作的映射 | 不需要 | ❌ 弱（误差滚雪球） | BC，大量机器人基线 |
| **逆强化学习（本节 Part A）** | 先反推奖励，再学策略 | 不需要（奖励是学出来的） | ✅ 较强（学的是"目标"而非"动作"） | 最大熵 IRL、学徒学习 |
| **GAIL（本节 Part B）** | 直接让策略骗过判别器 | 不需要（判别器当奖励） | ✅ 较强（策略在真实状态上被评判） | GAIL、AIRL 等生成式路线 |

一句话总结：**BC 学"专家做了什么"；IRL 学"专家为什么这么做"；GAIL 直接和专家"对答案"，让策略自己长出专家的行为。**

# 五、思考题

1. 如果把专家轨迹换成"次优策略"产生的数据（比如 70% 概率走对、30% 概率乱走），IRL 恢复出的奖励会发生什么变化？提示：特征期望 μ_E 会被"稀释"。
2. 把折扣因子 `γ` 从 0.9 调大（如 0.99）或调小（如 0.5），IRL 的误差收敛曲线和恢复的奖励形状分别会怎么变？

# 本实验总结

✅ 最大熵 IRL 用"特征期望匹配"从示范轨迹中反推出奖励函数，恢复的奖励下策略能 100% 到达终点，且最高奖励状态恰好落在终点附近 ✅ GAIL 不学奖励，用判别器"像不像专家"的评价当奖励，动作匹配率从 0.33 升到 1.00、到达率从 9% 升到 55% ✅ GAIL 训练有三大经典坑：样本不平衡、判别器学太快导致奖励地形坍缩、逐样本更新方差爆炸导致探索死亡——分别用等量采样、弱训练、批量平均+基线+熵正则修复 ✅ BC 学动作、IRL 学目标、GAIL 学分布，三条路线互补

> **奖励函数不是模仿学习的必需品——专家示范本身就是最好的"奖励说明书"。**
