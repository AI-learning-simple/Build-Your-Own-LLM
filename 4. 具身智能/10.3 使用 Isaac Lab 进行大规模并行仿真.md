# 二、参考代码：从 16 个 CartPole 开始的并行随机交互

```python
# Isaac Lab v2.3.0 参考代码；先小规模确认接口，再增加并行数。
from isaaclab.app import AppLauncher

app_launcher = AppLauncher(headless=True)   # headless=True 表示不需要显示渲染窗口，适合服务器训练
simulation_app = app_launcher.app

import gymnasium as gym
import torch
import isaaclab_tasks
from isaaclab_tasks.utils import parse_env_cfg

NUM_ENVS = 16
env_cfg = parse_env_cfg("Isaac-Cartpole-v0", device="cuda:0", num_envs=NUM_ENVS)
env = gym.make("Isaac-Cartpole-v0", cfg=env_cfg)
try:
    observation, info = env.reset()
    base_env = env.unwrapped
    print("并行环境数量:", base_env.num_envs)
    print("观测张量形状:", observation["policy"].shape)
    with torch.inference_mode():
        for step in range(100):
            # Isaac Lab 接收目标设备上的 torch.Tensor，不是 Box.sample 的 ndarray。
            actions = 2 * torch.rand(env.action_space.shape, device=base_env.device) - 1
            observation, reward, terminated, truncated, info = env.step(actions)
finally:
    env.close()
    simulation_app.close()
```

**待验证的输出契约**：`observation["policy"].shape[0]` 应等于 `env.unwrapped.num_envs`（示例先取 16，扩大后才是 4096）。动作应是相同设备上的 torch 批量张量；这里用随机动作推进仿真，没有优化器或学习更新，不能称作“4096 个环境同时训练成功”。

# 三、实验观察

这段代码验证的是**并行规模**：`num_envs` 控制一次仿真多少个独立环境，`env.step()` 返回批量张量。它不改变算法本身，Q-Learning、奖励塑形等方法仍按前面章节使用；本节不比较不同算法的训练效果。
