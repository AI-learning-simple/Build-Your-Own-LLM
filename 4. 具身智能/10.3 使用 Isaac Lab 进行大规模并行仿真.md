# 二、参考代码：4096 个环境同时训练一个 CartPole

```python
# 以下代码展示 Isaac Lab 典型的使用模式，具体导入路径和 API 可能随版本变化
from isaaclab.app import AppLauncher

app_launcher = AppLauncher(headless=True)   # headless=True 表示不需要显示渲染窗口，适合服务器训练
simulation_app = app_launcher.app

import gymnasium as gym
import isaaclab_tasks   # 导入后会自动注册一批 Isaac Lab 内置的机器人任务
from isaaclab_tasks.utils import parse_env_cfg

# 关键参数：num_envs=4096，一次性在GPU上并行仿真4096个完全独立的CartPole实例
env_cfg = parse_env_cfg("Isaac-Cartpole-v0", num_envs=4096)
env = gym.make("Isaac-Cartpole-v0", cfg=env_cfg)

observation, info = env.reset()
print("并行环境数量:", env.num_envs)
print("观测张量形状:", observation["policy"].shape)   # 预期形如 (4096, 观测维度)

for step in range(100):
    actions = env.action_space.sample()   # 一次性为全部4096个环境采样动作
    observation, reward, terminated, truncated, info = env.step(actions)

env.close()
simulation_app.close()
```

**观察输出**：`observation["policy"].shape` 的第一维应为 `4096`，说明每次 `env.step(actions)` 都在批量推进 4096 个独立环境，观测和奖励也都是批量张量。

# 三、实验观察

这段代码验证的是**并行规模**：`num_envs` 控制一次仿真多少个独立环境，`env.step()` 返回批量张量。它不改变算法本身，Q-Learning、奖励塑形等方法仍按前面章节使用；本节不比较不同算法的训练效果。
