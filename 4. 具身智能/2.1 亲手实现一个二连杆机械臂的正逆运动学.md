# 二、实现正运动学（Forward Kinematics）

直接翻译 2.5 节的公式：

```python
import math

def forward_kinematics(theta1, theta2, l1=1.0, l2=1.0):
    """已知两个关节角度（弧度），求末端执行器在平面上的 (x, y) 坐标"""
    x = l1 * math.cos(theta1) + l2 * math.cos(theta1 + theta2)
    y = l1 * math.sin(theta1) + l2 * math.sin(theta1 + theta2)
    return x, y
```

# 三、实现逆运动学（Inverse Kinematics）

同样直接翻译 2.6 节的余弦定理推导，并显式处理"目标超出工作空间"的情况：

```python
def inverse_kinematics(x, y, l1=1.0, l2=1.0, elbow_up=True):
    """已知目标位置 (x, y)，求两个关节角度（弧度）。elbow_up 控制选择哪一个解。"""
    d_squared = x**2 + y**2
    d = math.sqrt(d_squared)

    # 工作空间检查：机械臂最长能伸到 l1+l2，最短能缩到 |l1-l2|
    if d > l1 + l2 or d < abs(l1 - l2):
        return None  # 无解：目标点超出工作空间

    cos_theta2 = (d_squared - l1**2 - l2**2) / (2 * l1 * l2)
    cos_theta2 = max(-1.0, min(1.0, cos_theta2))  # 防止浮点误差导致越界

    sign = 1 if elbow_up else -1
    theta2 = sign * math.acos(cos_theta2)

    theta1 = math.atan2(y, x) - math.atan2(l2 * math.sin(theta2), l1 + l2 * math.cos(theta2))

    return theta1, theta2
```

# 四、验证：FK 和 IK 是否互为逆运算

用一个具体目标点 `(1.5, 0.5)` 走一遍完整流程，`l1 = l2 = 1.0`（机械臂最大能伸到 `l1+l2=2.0`）：

```python
target = (1.5, 0.5)

for elbow_up in [True, False]:
    result = inverse_kinematics(*target, elbow_up=elbow_up)
    theta1, theta2 = result
    x, y = forward_kinematics(theta1, theta2)
    label = "肘部向上 (elbow-up)" if elbow_up else "肘部向下 (elbow-down)"
    print(f"[{label}] theta1={math.degrees(theta1):.2f}°, theta2={math.degrees(theta2):.2f}°  "
          f"-> FK还原位置=({x:.3f}, {y:.3f})  目标位置={target}")
```

**预期输出**（IK 公式是解析解，不涉及随机性，下面的数值是严格按照 2.6 节公式手工推导验证过的，实际运行结果应与此一致，仅浮点精度可能在小数点后第3位略有差异）：

```
[肘部向上 (elbow-up)] theta1=-19.32°, theta2=75.52°  -> FK还原位置=(1.500, 0.500)  目标位置=(1.5, 0.5)
[肘部向下 (elbow-down)] theta1=56.19°, theta2=-75.52°  -> FK还原位置=(1.500, 0.500)  目标位置=(1.5, 0.5)
```

**两组完全不同的关节角度，FK 还原出来的却是同一个末端位置**——这正是 2.6 节强调的"逆运动学通常不止一个解"在代码层面的直接体现。真实机械臂在两个解都可行时，通常会选择离当前姿态更近的那一个（减少运动幅度），这也是工业机器人控制器里"IK 求解器"要做的一项额外工作。

# 五、验证：超出工作空间会发生什么

```python
out_of_reach_target = (2.5, 0.0)   # l1+l2 = 2.0，目标距离 2.5 已经超出最大伸展范围
result = inverse_kinematics(*out_of_reach_target)
print("超出工作空间的目标:", out_of_reach_target, "-> IK结果:", result)
```

**预期输出**：

```
超出工作空间的目标: (2.5, 0.0) -> IK结果: None
```

`d = 2.5 > l1 + l2 = 2.0`，触发了函数里的工作空间检查，直接返回 `None`。这在真实机器人系统里是一个非常重要的安全检查——如果没有这一步，`cos_theta2` 会计算出一个大于1的非法值，传给 `math.acos()` 会直接抛出 `ValueError` 导致程序崩溃（读者可以自己尝试注释掉工作空间检查那两行，验证这一点）。

# 六、思考题

如果把这个二连杆机械臂换成一个真实的 6-DOF 机械臂，正运动学的计算方式（连乘每个关节的坐标变换）本质上不会变得更难，只是从"三角函数"升级成了"齐次变换矩阵连乘"；但逆运动学会变得复杂得多——6个自由度意味着解空间可能有无穷多组解，通常没有解析解，需要用数值迭代方法（如雅可比矩阵法）来求近似解。可以思考一下：为什么自由度越多，逆运动学反而越难，而不是越容易？

# 本实验总结

✅ 正运动学是唯一确定的映射：关节角 → 末端位置 ✅ 逆运动学通常有多个解（肘部向上/向下），需要额外的规则来选择 ✅ 逆运动学存在"无解"的情况——目标超出机械臂的物理工作空间，代码必须显式处理这种边界情况，这也是真实机器人系统里非常重要的安全校验
